黄色 = 相对左边方法发生变化

前两个是原始短历史基线；论文四方法对照从 No-History 开始。下面按“上一列 → 下一列”只列改动。

① 原版 DP起点：当前两帧观测 + ChiTransformer。所有动作位置都能读取两帧观测
② DP-PTP编码器、Decoder、参数量不变。只改 cross-attention mask：未来观测不可见
③ No-History仍然没有长期历史。加 task embedding；换 LongMemPTP 接口，但 Tm=0
④ Direct当前观测路径和 PTP Decoder 保持。新增四路视觉空间历史：16帧 → 1024 token
⑤ Direct-token2与 Direct 共用同一历史视觉编码器。新增无参数 AvgPool：1024 → 2 token
⑥ VPWEMDecoder 仍接收 2 个 memory token。把固定池化换成 FIFO + 两层可学习 Q-Former

核心科学问题普通短历史 DP时间对齐是否重要不用长期历史能多好全部保留是否更好简单压缩是否足够学习式压缩是否更好
重要边界：VPWEM 这一列不只是把 AvgPool 换成 Q-Former；当前 1M 实验还同时从 raw-image、effective batch 64 变成了 dp_emb、effective batch 256，所以它不是严格单变量替换。
