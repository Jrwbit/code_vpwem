标定板在末端，相机固定外部，因此使用eye-to-hand。还需要确认板所在的是左臂还是右臂。采集命令必须选择同一条臂：

```bash
cd /home/bit-bhr/handeye_offline
# 仅在相机权限问题解除、确认标定板位于左臂后运行：
bash online.sh --robot-ip 192.168.71.161 --session datasets/left_handeye --once
# 如果板位于右臂，则改为：
bash online.sh --robot-ip 192.168.71.160 --session datasets/right_handeye --once
```
