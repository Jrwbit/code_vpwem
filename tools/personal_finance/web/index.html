统计口径与数据边界
收入与花费

收入仅合计归类为「收入」的记录。净支出 = 已归类支出 − 退款 − AA / 报销回款。为本人购买的商品纳入花费，包括亲情卡等他人代付；退款和回款按到账月份冲减，不回改原消费月。因此单月净支出可能为负。「收入 − 净支出」仅为比较差额，因消费包含他人代付，不代表银行余额或资产变化。

去重与内部流转

同一笔交易的银行扣款与支付平台记录合并计算，保留所有证据。本人账户间转账、充值、提现、还款等内部流转不计为消费。来源筛选包含该来源参与核对的交易，同一交易可出现在多个来源视图中，各来源小计不能相加。

待确认与本地审核

类型为「待确认」的金额不纳入收入或净支出，按方向单列。其他类型若带待复核标记，仍按当前类型计入。月份和来源影响汇总，搜索、类型与审核开关只筛选明细。修正保存在当前浏览器，并可导出审核 JSON。

本页面不发送网络请求。导入、统计和导出均在本地进行；共享导出的 HTML、JSON 或 CSV 会同时共享其中的账单信息。
