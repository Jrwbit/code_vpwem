## 1. 精确复现阶段衔接问题

离线重放失败任务 `03bc68a7b9534f24a5bcc713a766c6e6` 的原始输入，记录每个阶段的首末11轴向量，同时保留原连续性拒绝检查。重放找到7个走廊候选，唯一超出连续性门限的接缝为：

`左臂保持，恢复检测初始／工作腰姿 → home → 左侧中转避障`

最大差值为左臂J1约0.037944187°。其他阶段接缝为0或浮点数级误差，包括走廊接近、插入、退出和返回衔接。因此此次原失败不是“接线盒位置运动学不可达”的证据。

根因为 `detection_initial_segments()` 在左臂距home小于0.1°时跳过收臂，但后续走廊始终从精确保存home出发：腰部校正末点保留实测左臂位置，与后续精确home存在微小断点。

修复为补齐这条经过原规划器检查的实际反馈→精确home连接，连续性门限仍为1e−8 rad，没有靠增大容差或跳过检查解决。同时在拒绝消息中显示相邻阶段名与最大关节差，便于后续定位。

- 原手眼矩阵、保存的工作腰姿、工具矩阵及工位配置不改写；不是将当前位置保存为新的标准腰姿。

- 起始home微连接仍保留并检查；后续搜索从该已检查前缀的真实终点开始，允许GPU提议后由原CPU模型逐段复核。
