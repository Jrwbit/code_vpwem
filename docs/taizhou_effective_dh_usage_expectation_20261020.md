## 接线盒不动时应看到什么

如果接线盒、相机与底盘位置、手眼标定、工具/TCP和检测工作腰姿等条件相同，视觉对应的期望检测目标不应随更换DH而人为平移。改变的是从期望目标反算出的关节角。机器人实际执行新的关节目标后，末端相对之前旧模型指令的位置可能有小幅变化，目的是修正模型不一致造成的定位偏差。

采用归档视觉任务`20261020_111400_108779`和完整路线`97890770d64940489b9fab7dcc7dcbac`，与此前在同一输入下生成的有效DH候选比较：

| 数值比较 | 结果 |
| --- | --- |
| 新旧检测终点最大单关节变化 | 0.61027° |
| 两套目标关节均按当前有效DH回算：法兰位置差 | 1.49239 mm |
| 同样回算：工装中心位置差 | 1.55465 mm |
| 同样回算：姿态差 | 0.31385° |

以上是两套目标关节在当前有效模型下的计算比较，未包含真实反馈到位残差、实物测量、手眼和工具误差，不能直接保证实机必定移动1.55 mm或此前约3 mm偏差一定消失。该变化也不是固定XYZ补偿，随姿态改变。

如果仍执行原来的相同关节目标，改软件DH不会自动让真实机器人换位置。只有新生成的检测完整路线使用新的逆解关节目标后，才是在验证DH修正后的检测定位。
