- 优先三型号共用一组固定工作腰姿；不能用“分别为每个型号换腰”或“160单独有终点”替代。
- 优先保持当前相机、机器人和电机安装条件，不默认要求抬高相机或电机；必须调整时给数值依据。
- 要覆盖移动、倾斜工况，但已通过有限样本不能宣传任意摆放都可行。
- 界面简单，参数可见、可保存且重启后继续生效；扫码沿用保存参数，不暗换默认值。
- 手动示教用于校准、核验和留档；历史示教记录已改为可选，不应重新增加启动门槛。
- 每次实测与判断写入既有飞书报告，保留旧文并更正；代码／报告按任务范围提交 Git。不要复制会话凭据。

## 必须保持的坐标与参数语义

- `A_T_B`把B系坐标变换到A系；齐次矩阵平移用m，界面位置通常用mm；关节模型用rad，展示deg。
- 盒原点是四角孔矩形中心；物理LT→RT为+X、LT→LB为+Y、+Z=X×Y。接地螺丝所在近边用于物理上边消歧，不直接按画面上下猜轴。外框推导点不等于实测孔中心。
- 外置固定相机：`W_T_C=W_T_L(reference_waist)×Lref_T_C`；`Lnow_T_box=inverse(W_T_L(current_waist))×W_T_C×C_T_box`。保留原始`camera_T_box`，不得跨腰姿直接复用旧`base_T_box`。
- 工装目标：`W_T_F=W_T_box×box_shift×inverse(TCP_T_fixture_adjusted)×inverse(F_T_TCP)`。UR输出TCP、珞石输出法兰，不能直接比较或重复补偿。
- 腰J2模型角=控制器原始角+π/2，不能把模型角数组直接作为SDK命令。
- 15组ANDREFF活动标定SHA：`e8a7ee509c0764c6214df5d424f40d1f93f28e0d02232443a322ffdb8d2d2c9b`。旧会话名日期不代表仍用7组PARK。
- 已应用控制器有效DH，没有向控制器重新写DH。模型／SDK笛卡尔回显一致不代表独立实物精度。
- 最新现场证据：安装`Rz(-90°)`；JL132额外Z补偿0；JL100额外Z补偿−18mm；JM160盒局部X−2mm。原工装矩阵仍保留，尤其JL132原29.23mm高度没有删除。发布默认YAML不一定等于现场活动参数。
- 方案4源码为`rokae_depth_multiplane`（100／132），方案5为`rokae_depth_fast_recovery`（100／132／160）。10月13日个别流程文档的4/5映射有误。

## 2026-10-22结论基线

| 对象 | 已有证据 | 未完成 |
|---|---|---|

| 132倾斜约13.65° | 视觉成功、合法终点；端子模板与搜索已修 | 完整通路仍失败，不能当作任意摆放已验收 |
| 160 | 扫码定位成功，变腰及共用腰姿有合法终点 | 当前实际姿态无合格完整路线；候选末端约5mm被8mm最终检查拒绝 |
| 100 | 型号／工装接入，估计盒位有合法终点 | 同条件实测目标缺失；约4.23mm末端间隙被8mm检查拒绝 |
| 电测 | 目标已明确 | 当前名义零间隙对位，额外压入0、电测未连接；历史4mm不是自动退让量，停留20秒不是电测成功 |

1. **P0：J4保持／反馈链异常。** 10月22日进入共用腰姿时，下电退出116帧J4继续变化，`SAFE_EXIT_UNCONFIRMED`并锁存，偏候选约20.36°；后续记录约−158.32°，出现过未解释的单帧跳变。不能据此直接确诊抱闸坏，不能靠清锁、放宽速度或容差闭环。
2. **P1：真实几何与终点／路径判据。** 共用候选模型腰角`[-25.507413,15.901926,35.563485,-122.916206]°`，只是研究候选。160最差对为`tool_pin_JM160/box_wall_ny`；100为`box_wall_nx/AR5-5_07L_link7`。非配合件不能随意加入接触豁免。先测几何／安装，再统一生成和最终CPU判据，保留最终复核。
3. **P1：真实100数据及完整三型号路线。** 100由132沿世界Z降低100mm估计，来自用户40/35/25按cm理解；旧32mm假设已废弃。三个末端解、30mm局部生成均不能替代完整去返和腰姿进入验收。
4. **P2：绝对精度及工艺闭环。** 约3mm历史偏差尚无独立量具验收结论；不可把平面RMSE、IK残差、SDK回显或重复性当实物精度，更不能直接相加不同误差指标。

旧共用腰姿`[-33.78,35.11,6.84,-46.09]°`没有丢；旧−120°安装下三终点能复现，改真实−90°足以重现160搜索失败。不能回滚为错误安装角来恢复仿真。当前−158.3°下的相机禁入侵入与候选−122.916°下的5mm/8mm问题要分开。
