# 单目标条件：候选关联、策略表示与动作辅助训练

目标保持active。本轮保持28条train/8条dev及原代理标签，比较候选相邻对应、冻结原图动作策略表示和自预测动作计划辅助训练。第五组仍未对齐/评分，不以开发分数替代新轨迹或闭环结果。

## 相邻候选对应

只用当前/上一观测的检测类别、框IoU和128维外观余弦距离做一对一Hungarian关联，门限在搜索前固定：同类、cost=.6*(1-IoU)+.4*(1-cosine)不超过.75，且IoU>=.1，或cosine>=.85且中心距<=.3。间隔超过16步、候选缺失或不可信匹配均无历史。

每个候选增加12维公开特征：匹配标记、时间间隔、框坐标变化、外观相似、前次置信度、观测表面到手距离变化和深度有效标记。它只建立相邻对应，不宣称跨遮挡长期追踪。未知标签帧仍可提供已观测的过去信息，目标GT不参与关联或特征。

geometry/rich_geometry两视图、MLP64/ExtraTrees leaf5、三个种子，共12次拟合；各比较空槽偏置0/+4，加控制共25条记录。最好新且通过旧V4开发门槛的配置geometry_tracking_mlp_seed200_bias4.0正确369/408、召回369/418=88.28%，取碗错类2；原模型370/410、取碗错类0。8次主体切换首帧正确7、旧类滞留1，原模型8/0。原模型保留。

旁路审计仅在相邻两帧代理主体相同、上一帧存在合格目标提案时评分当前合格目标提案：train为1199关联到前次合格目标框、50未匹配、33关联其他框；dev为328、19、10。分母是当前合格提案数，不是帧数；“其他框”可能仍属于同一实例但质量不足，不能直接声称实例ID切错。关联可行不等于操作目标判断已经解决。

## 冻结原图动作策略表示

原ROI/global特征主要来自boxed检查点的RGB浅层。新增比较使用既有原图No-History动作策略的EMA观测编码器，严格加载其保存配置、归一化统计与权重；六种公开输入为主RGB、腕部RGB、两路深度、proprio和scan，时刻max(0,t-1)、t，各输出256维，合计512维，含原生5任务embedding。未输入真实动作或未来观测，整个策略保持冻结，不把这份观测表示称为“模型已预测出操作意图”。

## 自预测动作计划辅助训练

新增ActionPlanPointer，从公开观测预测8x10的短命令计划，再用“观测潜变量+自己预测的计划”查询候选。训练时也不把真实计划喂给目标头；真实actions[t:t+8]仅作辅助损失标签，末端padding显式屏蔽。推理forward没有真实动作、未来观测或接触标签输入，不能把这一辅助头当作已部署的扩散策略。

## 验证、边界与下一步

31项本地测试通过，5项已有依赖弃用警告。新增测试覆盖关联一对一/同类门限、前缀因果和episode隔离、未来/GT标签不参与特征、策略传感器时刻及padding、动作标签末端mask与无未来动作输入的预测接口。

还检查了原HDF是否有阶段意图标注：demo_45只有actions/dones/obs/next_obs/rewards/states/task_successes，task_successes为终局0/1（本例第1052步变真），没有可直接替代弱监督的子阶段目标ID。现有物理冲突待复核仍不能被当成已知真实意图错误。

下一轮优先核验碗/碗架关键帧的监督语义与候选对应的腕部局部交互证据。全局腕部特征、更多历史和动作辅助都未证明优于当前模型；不能继续靠单帧开发差异宣布成功。保持第五组隔离、历史V4失败以及四源范围和闭环验证缺口。
