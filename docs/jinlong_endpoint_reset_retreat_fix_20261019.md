# 检测终点复位先撤离：实现与现场部署（2026-10-19）

用户确认复位应先沿原完整路线撤离，再回home。本次已实现、部署并生成现场复位预览，没有启动真实运动、上下电或清警，没有放宽碰撞、限位及漂移保护。

## 实现行为

- 独立复位读取HMI仍加载的原检测计划，识别其检测到位暂停段已经完整执行且返回段未执行的状态；即使检测侧任务已被失败复位任务替换，也可恢复原返回依据。
- 校验加载计划SHA256与归档一致，工具和工位参数、源标定摘要、视觉相机坐标矩阵一致，原计划有碰撞检查回执；头部和右臂变化超过原1°门限、执行进度不符时拒绝复用。
- 从当前实际关节反馈起步，按原路线逐段重新检查撤离、返回。只有原插接撤离段使用原JL132插接区规则；后续恢复普通避障与调姿检查。不扩大豁免范围。
- 先保持当前腰姿撤离并收臂home，再按原目标选择检查是否还需要腰部恢复；不在检测区域先调整腰部。当前位置偏离原起点超过1°、路径不连续、任一碰撞或限位检查失败时拒绝生成。
- 生成是预览／加载操作；执行仍需要原页面确认和启动、当前反馈及控制权限检查。
