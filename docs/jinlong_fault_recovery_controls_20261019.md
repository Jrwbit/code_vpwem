# 接线盒页面故障恢复控件（2026-10-19）

已在机械臂运行面板增加“故障恢复”，并部署到金龙工控机。用户刷新页面后可使用。

## 操作与约束

1. 安全退出未确认时，现场核对全身停止、下电、故障原因和当前报警，勾选确认后点击“核对停止状态并恢复控制”。新 HMI `/motion/recover` 使用当前停止代次、实时状态和独立 SDK 读数检查全身下电／手动／空闲、关节与头部有限速度、控制器身份、碰撞反馈。核对过程中再次停止、反馈过期、活动任务或身份不符均拒绝解除锁定。该接口不调用上电或运动，不清除报警，不自动继续旧计划；历史执行结果保留，旧预览令牌和检测路线失效。
2. “恢复腰部定位…”沿用已有绑定当前标定的保存姿态预检和 `/waist/reset/start`。弹窗列出四个控制器目标角，用户核对路径后才启动。保存基准缺失或与标定不兼容时禁用，不以零位替代。
3. 选择左臂或右臂，点击“检查关节限位”，显示关节编号、当前角、上下限和向内退回 3°的目标。勾选本次退让路径确认后才能执行。沿用 HMI `/limit/recover/preview`、`/limit/recover/start` 和原生单关节手动退让；超过限位 1°拒绝，要求示教器处理。预览绑定部位、令牌和有效期，一次消费；切换部位、页面隐藏、状态过期后需重新检查。

恢复动作复用现有全局停止、启动代次、部件权限和心跳续租机制。只在执行需要时启动运动；本次部署和验证没有调用真实恢复控制、腰部复位、退限位 start 或任何上电操作。
