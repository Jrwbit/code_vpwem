# 单目标框选择原型：已实测，尚未接入动作策略

2026-11-01（北京时间）。按用户“只输入机器人要接触的那个物体框，试试”的要求，实际实现并运行了接触目标弱监督、候选框指针网络和连续观测回放。代码初版提交e3cd751。

结论：先用一个小型选择器读取候选对象，再仅向动作策略提供一个选中框，是值得继续验证的路线。本轮确实选出了框并展示了抽屉把手到碗的切换，也出现选错对象、切换滞后和拒选。当前是离线选框原型，尚未将目标框token接入扩散策略、未训练新的DP、未执行闭环机器人控制。不能把下述指标写成真实接触目标识别率或任务成功率。

## 标签及输入

原始HDF5含RGB、depth、proprio、actions和完整仿真states，没有现成的接触目标ID/人工阶段标签。离线恢复记录状态，不推进物理仿真：提取碗平移和门/架/抽屉关节运动，再要求事件开始附近夹爪碰撞表面距离不超过5cm。得到26条episode的157个运动片段，另21个未通过接近检验。片段可能是同一操作的多段变化，不代表157次独立有效接触。

监督定义为“当前运动的对象；否则未来2秒内最先发生的受接近证据支持的运动对象”。多对象同时运动和无证据区间不强行标目标。抽屉碰撞link不能区分把手与抽屉面板；运动也可能来自碰撞或失败动作，所以这些只是代理标签，不是记录的接触力或人工操作意图。未来事件只用于训练标签和离线评分，不进入选择器输入。

使用原555帧仿真辅助参考，按episode划分16条train、4条dev、6条test；四种任务数据，未覆盖全部十数据集的有效性验收。有代理标签358帧：train248、dev45、test65；剩余197帧不作为正确“无目标”计分。目标事件覆盖碗、洗碗机门把手、碗架、抽屉把手，不能外推为任意六类目标均已验证。

选择器输入是当前及t-8原图的冻结视觉特征、当前proprio及其变化、任务ID、最多8个候选的ROI特征/类别/框/置信度。128/32宽两层MLP为每个候选打分，另设null分支；只输出一个具体实例框或空。检测仍会处理多个候选，减少的是未来传给动作模型的对象条件数，不是取消外部检测计算。特征导出程序不接收GT或事件文件。标准化及任务类别先验只在train拟合，checkpoint只按dev选取，不按test选模型。

## 稀疏帧结果

目标需类别一致且IoU>=0.5匹配指定实例。下表分母是65个有代理标签且目标可见的测试帧，本次65帧均有可匹配候选；不是全555帧准确率，更不是接触意图的人工验收率。

| 方法 | 选对帧数 | 比例 |
|---|---:|---:|
| 最高检测置信度 | 33/65 | 50.77% |
| 最大框 | 20/65 | 30.77% |
| 任务类别先验×检测置信度 | 56/65 | 86.15% |
| 小网络seed100（主报告） | 59/65 | 90.77% |
| 小网络seed200 | 60/65 | 92.31% |
| 小网络seed300 | 60/65 | 92.31% |

三个seed固定同一训练配方，按各自dev最早最优epoch选择，分别epoch11/12/15。对应dev仅31/45、33/45、34/45，即68.89%–75.56%，说明不同episode表现差异明显。65个相邻/相关样本不足以证明稳定90%以上；seed重复不等于新增独立数据。

早先目录pilot_seed200/pilot_seed300误用默认seed100，已排除；真实重复为pilot_seed200_actual/pilot_seed300_actual，实际seed保存在result.json和checkpoint中。未挑选test最好的seed替换主报告。

## 连续观测回放

固定seed100模型，不再训练或调阈值。在table_setup_from_dresser_expert/demo_18（593帧）、unload_dishwasher_to_dresser_suboptimal/demo_56（852帧）上，按策略节奏每8步取一次当前观测，共182次。仍是先前使用过的检测测试episode，不是新独立holdout。

131次有代理标签，其中130次目标在画面可见；127次存在可匹配检测框，检测候选上限127/130=97.69%。未标注意图区间不计入分母。

| 方法 | 选对数/可见目标数 | 含漏检的目标框召回 |
|---|---:|---:|
| 最高置信度 | 41/130 | 31.54% |
| 任务类别先验×检测置信度 | 97/130 | 74.62% |
| 小网络 | 108/130 | 83.08% |
| 小网络+IoU保持/切换分数差 | 108/130 | 83.08% |

在已检出目标的127次里，小网络选对108次，即条件选框准确率85.04%。简单目标保持没有额外收益，不能声称目标切换问题已经解决。未标注区间的误选/错误null尚未得到可靠度量，null目前表示代理目标不可选，不能解释为已学会“现在不操作物体”。

人工可查看的证据包括全部6个稀疏测试失败以及每类前两个成功例；由助手目视检查，不作为独立人工GT。可见错误包括：该选碗时仍选抽屉把手、该选碗架时选碗、返回抽屉操作时仍盯着碗。另有正确选中类别但位置偏差的风险。连续视频黄框为离线代理参考，青框为预测，模型预测先写盘，再读GT绘制和评分；两视频按实际物理时间2.5fps播放。
