# 新共同工位是否需要移动相机及现场验证办法

2026-10-23，北京时间16:29完成离线对照。对应修正实物方向后的53秒候选视频，非已撤回的57秒旧视频。

## 结论

**照53秒视频这一组工位、腰姿、共同等待位和路线落地，需要重新布置相机。** 本轮只读取得工控机活动标定，把标定推导的原相机位置代入同一工位，完整重建相机实体、禁入体及派生禁调区，保持三型号电机、工装安装和全部关节路点不变。结果：三型号盒口投影均有部分出画面；共同等待位330条采样视线均被左臂link4模型遮挡；三条保存路线也均未通过相机相关规划约束。

这不证明“相机固定就绝对无解”。保留相机是另一项布局约束，需要重新搜索共同电机工位、机器人安装／腰姿、等待位和路径；不能把本次仅替换相机的失败推广到所有布局。

当前标定文件不等于对现场相机支架的新测量。如果相机或机器人底盘已移动却未更新外参，下述相对位移不能直接作为实物搬动指令。应先核实实际安装，再按视觉、标定、规划、非接触实机的顺序验证。

## 现场如何验证

1. **先核实原位，不先拆支架。** 保留当前标定，记录镜头光心到台面、固定底座的相对位置及相机朝向，确认机器人底盘是否移动。仅腰姿改变时，已有固定外置相机链能按实际腰姿换算，不要求相机跟腰动。腰应在受监控会话中保持，不能假定下电仍固定。
2. **三型同一定位底座做纯视觉验证。** 电机轴平行桌面、盒口朝上、盒在远机器人侧，换型不移底座、不变台面高度。检测页“视觉流程工作台／一键全流程”不触发机器人运动，方案五支持三型号。每型先做5次独立采集，保存原始RGB-D、识别结果和`camera_T_box`；核对实际二维码可读、四角孔完整、六柱排向正确、接地点可见、关键区域深度有效。100连续三柱必须平行电机轴。5次是初步诊断建议，不是生产可靠性验收标准。当前模型外参代入已失败，应先调整设计布局或相机后再做同样验证，不能靠换型挪电机凑画面。
3. **相机移动／转角后重新标定并独立验收。** 活动15组ANDREFF标定的`independent_validation.accepted=false`，原因为没有未参与标定的独立实测点。新手眼解算后需明确导入新外参，再以至少3个不同且不共线、未参加拟合的独立实测点核验，建议覆盖三个盒高；使用实际测量依据，不能以待验外参反算出的点当真值。机器人底盘相对外置相机移动也需重新建立有效外参。旧观测与旧路线不能直接继续用。
4. **用新观测重算完整去返，再做低速非接触实机验证。** 输入新三型盒位、相机外参、共同底座、固定工作腰姿、真实−90°工装及实扫几何。检查从同一等待位出发、对位、撤离、返回的全部路径和拍照无遮挡。页面“预览工装悬停目标”是只计算功能，“生成检测完整路线”与执行分开；新视频实扫模型／共同工位候选尚未部署为生产方案，不能假设点击现有网页就会使用本候选模型。离线通过后才验证低速非接触去返，测实际中心、方向和净空。

视频“60mm”是从现场名义配合目标沿盒法向退60mm，不是套筒距盒口60mm；实机首次接近应依据现场净空设置。接触、地针压入和电测仍是后续独立验收，160地针对槽问题未关闭。

## 对旧结论的澄清

此前“160约5mm间隙，不达8mm，所以完整路线未通过”是旧简化盒模型与当时最终检查规则下的结果。5mm不是相机实测净空，8mm未找到厂家或用户规定的依据。它不能证明160无解，也不能用来判断相机必须搬。本轮的失败依据是同一新工位下的取景、等待位遮挡与相机相关路径约束；新相机方案目前通过的是离线非接触去返，并非完整插接／电测。
