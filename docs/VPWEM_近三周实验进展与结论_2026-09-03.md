# VPWEM 近三周实验进展与结论

统计区间：2026-08-14—2026-09-03（Asia/Shanghai）  
更新时间：2026-09-03  
口径：只把已产生 checkpoint、逐回合结果或正式分析文件的运行列为实验；方案文档、代码实现和未完成队列不冒充实验结果。

## 一、结论先行

近三周不是“所有 memory 方案都没用”，而是得到了一条更清楚的证据链：

1. **继续只改 retention 很难成为稳定涨点创新。** delta-PER、learned retention、random/reservoir 的严格复验均没有跨任务稳定优势。
2. **VPWEM 的 memory 确实会因果性地改变动作。** 在 ShellGameTouch 中，正确记忆与错误记忆之间存在很大的成功率和分支选择差距；这说明 memory 不是完全被策略忽略。
3. **当前 matched counterfactual 监督没有表现出足够的“方法特异性”。** 它有时优于 VPWEM，但通常没有优于 random-CF 或 unmatched-CF，因此还不能作为已成立创新。
4. **六类文献方案已经全部迁移到 DP-VPWEM 并完成同协议筛选。** 正确的物理 hold、100 回合评测中，GMP 暂时最好（13% 对 VPWEM 9%），但所有差值都很小，且只有一个训练 seed，尚无可靠涨点结论。
5. **主要瓶颈与 benchmark 的基础能力有关。** ShellGameTouch 可训练到 97%—98%，适合研究 memory usage；RememberColor5 当前约 10%—15%，接近五分类机会水平，现阶段不适合用小幅 memory 改动验证创新。

因此，当前最稳妥的研究方向不是再堆一个 retention 名词，而是：在基础成功率已足够高的 memory-intensive benchmark 上，做能够超过强控制组的 action-relevant memory usage，并用多训练 seed 验证。

## 二、第一周：Retention 与复现审计（8月14日—8月20日）

### 2.1 Learned retention 单 seed 筛选

任务为 Robomimic Transport/mh；训练 seed 100；每方法 10k adaptation；统一评测 100 回合。

| 方法 | 成功率 | 相对 FIFO | 结论 |
| --- | ---: | ---: | --- |
| FIFO Q-Former | 38% | 0 | 基线 |
| delta-PER | 35% | -3pp | 无正信号 |
| Learned retention | 39% | +1pp | 与 FIFO 实质持平 |
| Random retention | 51% | +13pp | 当时是候选信号，需拆分混杂 |

离线 Oracle 排序保留 99.56% 的未来动作重要度，learned retention 为 80.43%，delta 为 60.92%，random 为 49.08%。但 learned head 与标签的验证相关系数只有约 0.035，且离线排序优势没有转化为在线成功率。

**判断：** 当前 learned objective 停止扩 seed；“离线能排序”不能等价为“在线控制会涨点”。

### 2.2 Random retention 三训练 seed 复验

任务仍为 Transport/mh；训练 seed 100/200/300；每个 checkpoint 使用相同的 100 个评测回合。

| 训练 seed | FIFO | Random | 差值 |
| ---: | ---: | ---: | ---: |
| 100 | 38% | 51% | +13pp |
| 200 | 36% | 58% | +22pp |
| 300 | 39% | 44% | +5pp |
| pooled episodes | 37.7% | 51.0% | +13.3pp |

逐回合 pooled CI 为 `[+5.7,+20.7]pp`，但统计上的真正重复单位是训练 seed，只有 3 个 seed，而且原比较同时混入 raw/Q-Former 表示差异，因此不能据此宣称 retention 普遍有效。

### 2.3 Random 机制拆分

| 方法 | 成功率 | 作用 |
| --- | ---: | --- |
| FIFO Q-Former bank8 | 38% | 原基线 |
| Q-Former random-evict bank8 | 38% | 只改淘汰规则，没有提升 |
| Recent-2 raw | 46% | raw 两帧基线 |
| Reservoir-2 raw | 51% | 只增加长历史覆盖，+5pp |

**判断：** 原 +13pp 主要是混杂结果；单独更换 Q-Former bank 的淘汰规则为 0pp，raw 表示下覆盖增益只有 +5pp，尚不显著。

### 2.4 Corrected Reservoir-2 跨任务严格复验

Recent-2 与 Reservoir-2 使用同样的两个 raw embeddings、相同策略结构和每组 100 个配对回合。

| Benchmark | Recent-2 | Reservoir-2 | 差值 |
| --- | ---: | ---: | ---: |
| LongSquare/ph | 0% | 0% | 0pp |
| Square/mh | 71% | 72% | +1pp |
| Transport/ph | 84% | 82% | -2pp |

**判断：** 没有跨 benchmark 稳定 coverage 增益，random/reservoir 不再作为论文性能创新。

### 2.5 delta-PER 跨基准复验

本周补跑了服务器 seed 200 与跨基准配对评测，并与此前正式结果合并审计。

- Transport/mh：3 训练 seed × 300 回合，FIFO 39.67%，PER 42.56%，`+2.89pp`，主检验不显著（p=0.203）。
- MIKASA 三任务宏平均：FIFO 37.67%，PER 36.33%，`-1.33pp`；其中 ShellGameTouch 为 90%→78%，`-12pp`。
- MoMaRT 九个完整配对任务宏平均：62.33%→62.44%，`+0.11pp`。
- 跨基准 12 任务 pooled：56.17%→55.92%，`-0.25pp`，p=0.916。

**判断：** delta-PER 降级为负结果/消融，不能写成稳定涨点贡献。

### 2.6 失败视频与评测配置诊断

- RememberColor3 8-layer、30 回合、默认 action chunk：1/30，3.33%。
- 固定 60-step 后，chunk 1/2/4 均为 6/30，20%；chunk 3 为 4/30，13.33%。
- LongSquare paper-strict 8-layer：7/30，23.33%；本地 4-layer 变体：5/30，16.67%。

**判断：** action horizon、episode length 和 evaluator 会显著改变表面成功率；此前的部分 0% 不能直接归因于 memory 模块。该组主要是协议诊断，不作为方法涨点证据。

## 三、第二周：NCM / 因果记忆监督（8月21日—8月27日）

### 3.1 ShellGameTouch Stage-1：物理 neutral-hold 协议

重新采集 1000 回合，其中 996 回合完成物理 hold；current-branch probe 为 33.03%，接近三分类机会水平，而 target-action probe 为 98.69%。这说明 hold 后当前观测存在状态混叠，但示范动作仍能反映隐藏分支。

四个方法从同一个 VPWEM 600k checkpoint 初始化，训练 10k，并用同一组 100 个 episode、四类 memory intervention 评估。

| 方法 | Correct Success | Correct BranchAcc | Matched-wrong Success | Correct−Wrong Success gap | 离线 ΔCF |
| --- | ---: | ---: | ---: | ---: | ---: |
| VPWEM | 17% | 39% | 4% | 13pp | 0.214 |
| Random-CF | 16% | 32% | 4% | 12pp | 0.265 |
| Unmatched-Branch-CF | 16% | 30% | 3% | 13pp | 0.267 |
| Matched-CF | 13% | 30% | 5% | 8pp | 0.291 |

Matched-CF 相对 VPWEM：Success `-4pp`，95% CI `[-11,+3]pp`；BranchAcc `-9pp`，95% CI `[-17,-1]pp`。

**判断：NO-GO。** 错误 memory 会改变动作，但 matched-CF 没有超过控制组，不能继续把 necessity gate 或 compact belief 建立在这次结果之上。

### 3.2 ShellGameTouch 的后续 20k 对照

为排除训练预算和初始化方式影响，又跑了三组正式 follow-up：

| 设置 | VPWEM Success / BranchAcc | Matched-CF | 对 VPWEM | 关键结论 |
| --- | ---: | ---: | ---: | --- |
| Transfer-100 | 56% / 65% | 62% / 74% | +6pp / +9pp | 优于 VPWEM，但与 Unmatched-CF 的 62%/74% 相同，只比 Random-CF 高 +1pp/+2pp |
| Full-base-600 | 46% / 59% | 46% / 65% | 0pp / +6pp | Branch 有改善，Success 不涨；未过 +10pp gate |
| Directional donor-action | 56% / 65% | 57% / 66% | +1pp / +1pp | 基本持平 |

Transfer-100 中 Matched-CF 相对 VPWEM 的 +6pp Success 和 +9pp BranchAcc 在这 100 个配对回合上为正，但它没有超过 random/unmatched 强控制，因此无法把提升归因于“matched counterfactual”本身。

**判断：** NCM 有“监督/适配可能有效”的信号，但缺少方法特异性，预注册 gate 仍为 NO-GO。

### 3.3 RememberColor5 NCM 迁移

20k Transfer-100 正确评测：

| 方法 | Success | BranchAcc | Correct−Matched-wrong Success gap |
| --- | ---: | ---: | ---: |
| VPWEM | 18% | 24% | 2pp |
| Random-CF | 15% | 20% | 2pp |
| Unmatched-CF | 15% | 22% | 2pp |
| Matched-CF | 15% | 23% | 1pp |

Matched-CF 相对 VPWEM 为 `-3pp Success / -1pp BranchAcc`，且正确与错误 memory 几乎没有差距。

**判断：NO-GO。** 当前 RememberColor5 策略既没有可靠学会任务，也没有形成可测的 memory reliance。

### 3.4 基础策略能力与 benchmark 筛选

- ShellGameTouch 从物理数据 scratch 训练：400k 时 Correct Success 98%、BranchAcc 100%；600k 时 97%/99%。替换为 matched-wrong memory 后仅 3%/2%，证明该任务可以形成很强的 memory dependence。
- RememberColor5 从物理数据 scratch 或 transfer 的多个 checkpoint，Correct Success 多在 10%—15%，BranchAcc 约 17%—25%，接近五分支机会水平。
- 因此 ShellGameTouch 适合继续做因果 memory 方法；RememberColor5 当前首先是基础策略/数据/任务建模问题，而不是 memory module 的小修小补问题。

### 3.5 无效或中止结果

- 早期 ACSM 评测没有执行真实的前 10 步 neutral hold，出现过 VPWEM correct 76%、zero 91% 等反常数字；这些结果只用于发现 evaluator 问题，**不得作为性能结果引用**。
- RememberColor5 一次 Stage-1 分析使用了不共享的 counterfactual donor table，分析器已标记 `analysis_valid=false`，随后用共享表重跑。
- 一次 zero-gripper oracle 采集因不是物理 neutral hold 被主动中止，不计入结论。

## 四、第三周：六类 Memory 方案迁移到 DP（8月28日—9月3日）

### 4.1 已实现并实际训练的方案

以 VPWEM-DP 为共同底座，实现并训练了六个最小迁移版本：

- GMP：learned gate 控制 memory read。
- AEM：视觉—动作历史编码形成 compact memory。
- DSSP：SSM/recurrent history memory，并加入未来演化辅助约束。
- VQ-Memory：离散化低维任务阶段记忆。
- Cycle：历史感知与进度辅助预测。
- Chameleon：action-relevant / control-indexed memory 辅助目标。

所有方法均从同一 400k 基础 checkpoint 初始化，在 RememberColor5 上做 5k adaptation；这是一轮低成本筛选，不是论文级训练预算。

### 4.2 正确 hold evaluator 的 100 回合结果

评测协议：真实执行前 10 步 neutral hold；同一 eval seed 和同一组 100 个 episode；只评 correct memory。这里是 **1 个训练 seed × 100 个评测回合**，不是 100 个训练 seed。

| 方法 | Success | 相对 VPWEM | BranchAcc | 相对 VPWEM |
| --- | ---: | ---: | ---: | ---: |
| VPWEM | 9% | 0 | 14% | 0 |
| GMP | **13%** | **+4pp** | 17% | +3pp |
| Chameleon | 12% | +3pp | 16% | +2pp |
| AEM | 11% | +2pp | **18%** | **+4pp** |
| VQ-Memory | 11% | +2pp | **18%** | **+4pp** |
| Cycle | 10% | +1pp | 15% | +1pp |
| DSSP | 8% | -1pp | 15% | +1pp |

与 VPWEM 的配对 McNemar 精确检验均未显著：GMP Success p=0.125；Chameleon p=0.375；AEM p=0.727；VQ p=0.5；Cycle 与 DSSP p=1.0。

**判断：** 六个方案都已跑完；DSSP 和 Cycle 也已完成，并非仍在排队。当前排序是 GMP > Chameleon > AEM≈VQ > Cycle > VPWEM > DSSP，但差异很小、基础成功率过低，不能据此宣称任何方法 work。

### 4.3 被作废的旧 30 回合评测

最初的通用 evaluator 没有执行前 10 步 hold，曾得到 VPWEM 0/30、GMP 1/30、AEM 2/30、DSSP 3/30、VQ 2/30、Cycle 3/30、Chameleon 1/30。该结果与目标任务协议不一致，**整组作废**；本报告只采用上面的 correct-hold 100 回合结果。

## 五、三条创新线现在处于什么状态

| 创新线 | 当前证据 | 状态 |
| --- | --- | --- |
| 事件/learned retention | Transport 有局部趋势，但严格拆分和跨任务复验为 0 或负；离线 ranking 不转化为 rollout | 停止作为主性能创新 |
| Counterfactual / necessity-aware memory usage | Shell 上确认 memory 因果作用；Matched-CF 偶有 +6pp/+9pp，但没有超过 random/unmatched 控制 | 保留问题定义，当前方法需重做 |
| Compact/recurrent/discrete/progress memory | 六类最小迁移已跑；最好 GMP +4pp，均为单 seed 小样本且不显著 | 仅完成筛选，尚无成立方案 |

更准确的说法不是“三个创新点全都不 work”，而是：**第一个已被证伪为稳定涨点方法；第二个的问题成立但当前实现不成立；第三类刚完成低预算筛选，还没有足够证据判断。**

## 六、建议的下一步

1. 暂停在 RememberColor5 上直接扩六方案多 seed。9% 的 VPWEM 基线使 +2pp—+4pp 很难解释，首先应把基础策略提升到明显高于 20% 的机会水平。
2. 将 ShellGameTouch 作为 memory usage 主战场：它已有 97%—98% 的基础能力和很大的 correct/wrong memory gap，可以排除 motor failure。
3. 在 Shell 上优先做 GMP 与 action-relevant auxiliary 的组合，但必须保留 VPWEM、Random-CF、Unmatched-CF 三个强控制；目标不是只超过 VPWEM，而是超过所有控制。
4. 单 seed 筛选只有在 Success 或 BranchAcc 至少提升 8—10pp，且 matched 方法优于 random/unmatched 时，才扩到至少 3—5 个训练 seed。
5. 论文当前可写的可靠发现是：bounded memory 的调用链成立；memory 会因果改变动作；naive retention proxy 和无特异性的 counterfactual loss 不能稳定提升成功率。新的性能贡献仍需下一轮实验建立。
