# 2026-10-23 相机仅竖直抬高：三型号共同工位验证

## 结论与本轮范围

可以作为候选。保持相机水平位置和朝向，只沿实验室竖直方向抬高80mm，160、132、100从同一等待位出发、换姿、接近、撤离并返回的完整非接触路线已通过离线检查。三型共用同一底座定位、同一台面高度，循环中腰部变化0°。40mm也找到完整非接触解，但折臂换姿较多；本轮选择80mm作为演示候选，不宣称它是最小抬升量或全局最优高度。

此前“原相机条件下，共同等待位连接仍未通过”的结论保留。用户随后询问能否抬高相机，本轮只评估这一设计变更，没有把此前移动相机XY和朝向的旧视频恢复为推荐方案。未移动实机、未拍摄新RGB-D、未写控制器或覆盖活动标定。

通过范围仍是非接触路线。终点为名义配合目标沿盒法线退出40mm，不是距盒口或真实接触面40mm。实际底脚到实扫盒体的平移尚未独立配准，160地针跨槽约4.316mm残差仍未解决，插接、压入补偿及电测均未通过验收。

## 固定项及相机变化

采用已纠正的实扫六柱／盒体、100的2×3三柱排向平行电机轴、真实工装Rz(−90°)安装。没有增加90°转接件，没有缩小相机禁入体或放宽间隙规则。三型号轴平行桌面，盒口朝上、盒位于远机器人一侧；不按型号移位、旋转或垫高。

抬高会把相机本体、顶部禁入体及相关高度界限一起上移，为手臂换姿增加部分空间；XY禁调范围和电机／台面障碍仍在。因此不能只由终点有解推断整条路线可行，本轮重新检查了所有共同连接和往返段。
