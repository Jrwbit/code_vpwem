## 已尝试的修复及结果

1. **端点审计**：最终检测点及盒外10 mm点存在合法关节解；正式扩展端点审计53次尝试、41次收敛、33次合法。次数不是独立路线数。
2. **互斥端子模板修正**：原模型将JL100/JL132/JM160三种电机端子叠加在同一盒体位姿。离线发现非当前JM160端子和实际工具的虚假干涉。现按当前JL132选择端子模型；实际工具上的所有工装头、当前电机端子、盒壁、机器人、相机和未知障碍仍保留。没有放宽碰撞门限。修正后20–50 mm范围出现合法悬停解；60 mm的已审计初值未找到合法解。
3. **补充普通逆解和不同肘姿**：原悬停搜索仅用偏低肘的解法，漏掉普通arm_ik分支；改为先收集普通解并优先尝试腕部余量较大的不同分支。
4. **扩大有限搜索**：20–200 mm悬停、更多侧向/反向、正负坡度、最远600 mm通道；逐批尝试完整连接。5 mm间隔跟踪，并在TCP朝向保持不变时利用冗余肘姿改善腕部余量。
5. **空旷中转调姿规则保留**：中转位须满足原至少20 mm模型净空和禁调区规则，home连接、法向接近、原路退出/返回须全通过才能导出。本次两批都没有通路候选，尚未形成可执行的新中间调姿方案。
6. **有界失败**：扩展预算600秒、外围原900秒超时；保存search_diagnostics.json，明确区分端点无解与端点有解但通路未通过，避免把未完成一直显示为运行。

原约束仍保留：腕部联合指标 `(J6/60°)^2 + (J7/90°)^2 <= 0.95`，肘相对肩高≤0.1 m，普通模型净空≥10 mm、普通关节限位余量≥0.05 rad；实际导出关节线继续稠密复核碰撞、限位、腕部、阶段连续性及末端直线/朝向误差。相机禁入区、当前右臂和工具均纳入模型。
