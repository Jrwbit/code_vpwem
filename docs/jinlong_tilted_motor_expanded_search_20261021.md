# 倾斜电机：端点审计、扩展搜索与现场验证（2026-10-21）

本轮承接用户对“检查不同肘姿、扩大悬停与侧向候选、在空旷处调姿后接近”的实施请求。沿用三维任务20261021_154432_bc2834、JL132和现有手眼标定。平面相对相机倾角约13.6514°；不重新标定，也不通过改变目标姿态伪造可达。

## 已证实的遗漏

1. 最终检测位和盒外10 mm接近位存在合法逆解。原模型端点审计各88次收敛、33次合法；这不是33条完整路线，也不是33个去重分支。没有依据把原失败称为“检测点必然不可达”。
2. 原快速CPU搜索只用压低肘部/阶段优化的逆解，遗漏普通arm_ik保留下来的合法悬停分支。普通解也须满足原肘高上限、腕部联合限位、软限位余量和碰撞要求。
3. 仿真在同一盒体位姿叠加JL100、JL132、JM160三种互斥电机端子模板；原scene.py注释明确当前工位只选其中一种电机。原先仅插入阶段忽略其他电机端子，普通通路却同时把三种模板当障碍。20 mm悬停附近曾记录非当前JM160端子与实际工具凸台/弹簧针的虚假干涉。
4. 离线只选择当前JL132端子后，20/25/30/35/40/50 mm悬停分别找到18/25/25/25/17/3次合法解；60 mm仍无合法解。当前工具上的所有工装头、真实JL132端子、盒壁、相机、机器人和未知障碍都保留。该改动是选择互斥场景模型，不是测得现场物理净空，也不是取消真实碰撞检查。

## 已实现的搜索行为

- 保留原快速GPU/CPU和复用入口；快速路线失败后再审计端点并按批扩大搜索。
- 收集普通逆解的不同分支，优先尝试腕部余量更大的候选；原低肘和阶段优化仍作为补充。
- 扩大20–200 mm悬停、侧向/反向方向、正负坡度及最远600 mm通道候选。每批先尝试完整连接，失败后再进入下一批，候选不等同于可执行路线。
- 增加5 mm间隔的分支跟踪；在工具朝向不变时尝试利用冗余肘姿改善腕部余量。优化产生的配置必须通过原硬约束；每一段实际关节线仍做碰撞、限位、腕部、末端直线偏离和朝向误差检查。
- 中转位仍须至少20 mm模型净空且满足原禁调区规则。home到中转位的调姿连接、最终沿盒法向接近、原路退出和返回home全部通过后才能导出。不允许在盒前禁调区强行旋转工具；未找到合法中转位时，不能宣称“增加中间调姿”已经形成可执行方案。
- 扩展搜索预算600秒，外围任务原有900秒超时仍保留。失败时保存search_diagnostics.json，并区分“最终检测点未找到合法关节解”和“最终检测点有合法解，但进退通路未通过”。预算耗尽不证明数学上绝对无解。
- 碰撞检查与低侧净空报告使用一致的当前电机端子集合；禁调区仍沿用原保守定义。
