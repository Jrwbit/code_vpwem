# 检测全流程误差来源与解决顺序（2026-10-20）

已追加至[飞书全流程报告](https://feishu.cn/docx/I2GAdun3nofskUxAOjWcxVwjnJO)，回读核对新增正文及表格（27个单元格），原有282个顶层块顺序保留；本次无新增图像或附件。本报告基于已有实验及后续运动学核对，不是新一次实机实验；本轮没有采图、运动、部署或修改标定。

## 当前结论

现场此前观察约3 mm左右偏差。现有证据更支持稳定的系统偏差，并已查明旧规划采用理论DH、控制器采用本机有效DH这一不一致；但不能把全部3 mm归给DH、视觉或手眼，也不能宣称有效DH部署后误差已经消失。缺少更新模型后的独立实物对位测量。

三轮完整往返复用了同一视觉和目标，SDK法兰停留均值最大相差约0.003874 mm，腰部变化对检测点的名义模型影响最大约0.024167 mm。这些记录不支持当时的毫米级随机到位变化或明显腰部滑移是主因。它们不能代表实物达到微米精度，也不能评价重新拍照的重复性。

**对旧结论的更正：** 后续78个动作核对发现，SDK笛卡尔getter更接近指令关节的有效DH正解。因此不能把SDK位姿当成独立的实际末端测量，也不能把旧的“理论正解减SDK”全部叫作纯DH误差。应分别比较模型、反馈关节与指令关节，并最终用外部实物测量验收。

## 误差为什么会沿流程产生

链路为：图像/深度 → 接线盒中心与朝向 → 相机到固定世界坐标 → 当前腰姿下的左臂基座 → 工装目标换算法兰目标 → 逆解关节 → 运动到位/停止/下电 → 实际接触和电测。

期望工装目标与实际工装位置是两条链的比较：目标依赖视觉及相机外参，实际位置依赖腰部安装、手臂运动学和工具安装。任何一段存在固定偏差，机器人都可能每次稳定到达同一个偏位置。各项通常是平移、旋转和关节残差的耦合，不能把几个误差模长相加或从3 mm中依次扣除。

| 环节 | 为什么会有误差 | 当前证据与解决办法 |
| --- | --- | --- |
| 图像和深度 | 遮挡、反光、边缘深度、内参/深度尺度或中心定义偏差；姿态错误也会改变工装目标 | 历史两次视觉中心差约0.0355 mm、平面RMSE约0.19 mm，只说明特定条件下的重复性及平面拟合。固定场景重新多次拍摄，用独立测量的盒角/孔中心核验中心、尺寸和朝向，统一外框中心与端子基准的定义 |
| 手眼与左右臂转换 | 右臂持板解算再转左臂，依赖左右基座安装关系；标定内部拟合可通过但外部位置仍有偏差 | 在实际左臂坐标中测至少3个未参与标定、非共线且覆盖作业区的点；真值不能用待验矩阵反算。根据残差决定重测安装关系或重标定 |
| 腰部及固定安装坐标 | 采图与作业腰姿不同，名义URDF安装误差会影响空间转换；相机/底盘移动会使旧观测失效 | 既有流程使用原始camera_T_box和标定参考腰姿建立固定目标，不是直接照搬旧base_T_box。本轮小幅腰部变化不足以解释3 mm，但名义安装几何和稳定挠曲仍未验收；用同一实物基准跨腰姿核验 |
| 理论DH与有效DH | 同一组关节角通过不同模型会得到不同位置，导致逆解目标不一致 | 已查明并修正：软件正解、逆解、碰撞几何使用各臂控制器有效DH。78个动作同反馈关节下的纯模型差为约0.927–1.906 mm；这是法兰计算差，不是实物偏差。需重新生成路线后测量效果 |
| TCP与工装 | 安装角、偏心、工装高度、中心偏置或补偿重复；型号与实物不一致 | 历史已发现约30°安装角与JL132高度补偿定义问题，并有后续现场示教更新，不能继续当作当前未改参数。独立测量现用TCP、工装接触面及型号，采用多姿态工具标定，避免用单点综合补偿代替分项核验 |
| 关节到位与反馈语义 | 运动完成事件不等于毫米精度；实际关节残差、停止/制动/下电变化可能留在末端 | 三轮检测位J1稳定差约0.07°，有效DH反馈与指令正解在一例中差约0.81 mm。记录到位、停止、下电前后关节及外部末端，先定位残差形成阶段，再与厂家核实getter语义、控制和负载设置；不能只收紧软件门限或反向加关节补偿 |
| 负载和接触 | 工具、支架和传动挠曲未必被编码器体现；姿态角误差经工具长度放大，接触后还会受装配间隙影响 | 多姿态、不同负载和有无接触分别测量，检查工装刚度与固定。小角度下横向影响约为力臂乘角误差，例如200 mm力臂、0.5°约1.75 mm，这是量级示例，不是本机实测 |
| 任务与版本绑定 | 相机/工件移动或更换标定、TCP、DH后继续用旧结果/旧目标，会混淆修正效果 | 每次保存视觉、标定、工具、模型、腰姿及计划摘要；变化后重新生成/校验对应计划。新版提速及持续上电改变了执行时序，旧三轮记录不能代替新版本的精度验收 |

## 推荐解决顺序

1. **先量清当前偏差。** 固定盒、相机、底盘、型号和工作腰姿；将现场左右映射到明确的盒局部轴，测自动到位与正确对位之间的有符号差值及姿态差。记录测量工具、分辨率、间隙和上/下电状态；保留原始任务和参数摘要。
2. **验证已修正的DH。** 确认新计划使用有效DH且重新逆解，比较同条件下更新前后的实物误差。历史同输入计算预期工装中心变化约1.55 mm、姿态约0.314°，实际变化和方向必须现场测量；重新执行旧关节目标不构成验证。
3. **分离视觉/外参/工具。** 先做相机下的独立几何核验，再做左臂坐标独立点验收，随后多姿态标定TCP与工装；跨腰姿检查安装转换。每次只改变一个因素并保留未参与拟合的验证点。至少3个点是最低检查规模，不代表充分覆盖整个工作空间。
4. **查稳定关节残差。** 在到位、停止及下电各阶段配对记录反馈与外部测量，确认约0.8 mm量级残差的形成阶段；依据厂家确认结果处理控制、负载或制动问题。以有效DH和反馈关节计算的工装误差可用于在线诊断，最终仍需独立实物验收。
5. **最后验收和局部补偿。** 在约定毫米/角度标准下覆盖多个位置、朝向、重复采图及完整往返，报告各轴偏差、最大误差和重复性。若残余偏差在限定工位内确实稳定，再建立有明确坐标系、版本和适用范围的补偿，并用未参与拟合的点验证。未经定向测量，不直接给X/Y加3 mm。

最优先的下一步是：在新有效DH路线下，取得一次可追溯的实物对位误差和相应反馈，再决定查工具、外参还是到位控制；继续重复相同旧路线很难区分这些来源。
