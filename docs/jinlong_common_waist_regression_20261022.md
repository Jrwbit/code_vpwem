用户指出，原仿真不是分别为各工装找腰姿，而是已经找到同一腰姿使100、132、160均可解。本轮按这一要求找回原报告和场景实算，不用“换一组腰姿让160可解”替代三工装共用要求。

## 归档条件差异

当前现场失败样本仍为视觉任务`20261022_110716_20e2e9`、路线`290616353cc640708739055f2daa0e11`。

- 旧盒心world XYZ为`[0.446189040, 0.015516981, 0.862500370] m`；当前为`[0.416377393, -0.070580683, 0.926988973] m`，差`[-29.812, -86.098, +64.489] mm`，总距离111.626 mm，盒姿角差约7.199°。这是归档目标差异，尚未判定由实物摆放、视觉或坐标换算各贡献多少，不能直接说用户物理挪动了同样距离。
- 旧工具安装为`flange_T_tcp=Rz(-120°)`；现场经过此前安装修正后使用−90°，差30°。此修正同时改变法兰目标朝向、工具盘/全部工具头碰撞几何的安装角。
- 旧场景未应用controller_kinematics，为名义运动学；当前应用控制器有效DH。当前J7规划限位±89°，旧为约±90°；右臂静态姿态也有差别。
- 旧/新相机模型中心仅相差约2.577 mm；两场景保留的相机旋转矩阵相同，但不能因此认为完整标定、视觉输入和目标均相同。

这些差异需要区分作用，不能仅凭其存在就宣布根因。

## 控制变量实算

固定原共用腰姿，使用相同旧场景与模型作为基线。只更新盒位时，将盒体和motor_body障碍及三个法兰目标按`delta = world_T_box_new @ inv(world_T_box_old)`同步刚体迁移，相机/桌面及其他条件不动。

| 对照条件 | 终点结果 |
|---|---|
| 旧盒位、旧−120°工具、名义DH | 100/132/160全部有合法终点 |
| 只换为当前盒位，其余仍旧条件 | 100/132/160仍全部有合法终点；分别尝试55/1/3次（按100/132/160顺序） |
| 当前盒位、旧−120°安装，仅加入有效DH | JM160有合法终点，3次尝试；腕部指标0.943567 |
| 当前盒位，仅把安装从−120°改为−90°，仍用名义DH | JM160共294次尝试、121次报告收敛、0次合法 |
| 当前盒位，−90°安装并加入有效DH | JM160共294次尝试、121次报告收敛、0次合法 |

上述160对照采用相同历史悬停/中转种子和96组固定随机种子，依次调用arm_ik、ik_low_elbow、ik_stage；找到合法终点即停止，否则完成294次尝试。安装角对照用configure_geometry同步旋转真实工具盘凸包和全部工具头，再按`T_final_new = T_final_old @ Rz(-120°) @ inv(Rz(-90°))`重算法兰目标；没有只改目标而不改工具几何。隔离对照保留旧端子模板策略、旧限位和右臂/相机模型，不声称等同所有当前生产条件。

两组−90°安装下，82次收敛结果存在碰撞，其中80次最小配对为相机禁入区/左臂link4；还存在限位余量、腕部和肘高拒绝。有限样本的0合法解不是数学不存在性的证明，但该受控对照显示：**当前盒位下，安装角从旧−120°修正为真实使用的−90°，足以重现原共用腰姿方案在JM160上的搜索失败；仅盒位改变或仅有效DH修正并不能解释这一回归。**

因此，更正上一轮的解读：原共用腰姿没有丢失，原三工装终点成功可以复现；“放开腰姿160就能解”只是一组新实验，不能代替原三工装共用设计。后续应保留真实−90°安装依据，对当前条件联合验证三工装工作区和求解分支，核实是否需要调整共用方案；不能仅为恢复旧仿真结果把安装角回滚成−120°。本轮没有求出新的三工装共用腰姿，也没有修改生产配置或执行实机。
