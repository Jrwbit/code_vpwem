# VPWEM：DP 记忆机制、创新审计与研究重构

> 日期：2026-08-21  
> 文档性质：研究问题重构、代码与实验审计、后续执行方案  
> 核心原则：先冻结问题和证伪标准，再选择方法；不再根据单次涨跌更换故事。

## 一、总判断

研究问题不需要推翻，但新增创新点需要重新设计。

当前可以保留的稳定问题是：

> 在固定 memory token、计算量和单步延迟预算下，如何为部分可观测低层控制维护一个对当前决策充分、对轨迹身份不敏感、且能够被新证据修正的单回合历史表示；在预先指定的 memory-intensive tasks 上提高成功率，同时不损害 Markov negative-control tasks。

当前不能继续保留的结论是：

- delta-PER 已经有效；
- learned retention 已经有效；
- RandomMemory 是标准无偏 reservoir；
- Transport/mh 上的 +13.33pp 已经证明 temporal coverage 是因果机制；
- action chunk 变小可以稳定提高成功率；
- Evidence–Belief、CPB、revision 已经得到实验支持；
- 分段记忆普遍提高 Diffusion Policy 成功率。

现阶段最合理的处理是：

1. 保留原 VPWEM 作为既有基础框架；
2. delta-PER 与当前 learned retention 转为负结果；
3. Coverage First 降级为待验证假设 H1；
4. CPB-VPWEM 降级为候选结构，不再提前命名为已经成立的新方法；
5. 先修复实验协议和实现，再完成 retention × representation 的析因实验；
6. 简单方法不能通过时停止，不再换名字讲新故事。

## 二、DP 的本质是什么

这里的 DP 指 Diffusion Policy，不是动态规划。

它学习的是条件动作块分布：

$$
p(A_t\mid c_t), \qquad A_t=(a_t,\ldots,a_{t+H-1})
$$

其中 $c_t$ 是当前策略条件，通常包含近期视觉观测、机器人状态以及可选的历史记忆。

训练时对专家动作块加噪：

$$
A_t^k=\sqrt{\bar\alpha_k}A_t^0+\sqrt{1-\bar\alpha_k}\epsilon
$$

网络学习预测噪声：

$$
\min_\theta \mathbb E\left\|\epsilon-\epsilon_\theta(A_t^k,k,c_t)\right\|^2
$$

推理时从高斯噪声动作序列出发，经过多步反向去噪得到动作块，执行其中一部分，然后根据新观测再次规划。

因此 DP 主要解决：

- 连续动作序列生成；
- 多模态专家行为；
- 动作块的时间协调；
- 行为克隆中的稳定生成。

DP 本身并不天然解决：

- 部分可观测性；
- episode 早期线索记忆；
- 隐藏任务状态估计；
- 长期规划；
- 陈旧记忆更新。

VPWEM 的作用不是改变扩散过程，而是改变条件 $c_t$：把越出近期窗口的历史压缩成有限 memory token，再与近期观测、扩散时间步一起输入动作去噪网络。

仓库中的主要调用链：

- `cleandiffuser/diffusion/longmem_ddpm.py:210-242`：memory 进入 diffusion condition；
- `cleandiffuser/nn_diffusion/longmem_chitransformerptp.py:130-164`：扩散时间、memory token、近期观测拼接；
- `cleandiffuser/diffusion/ddpm.py:97-113`：加噪和训练损失；
- `cleandiffuser/diffusion/ddpm.py:276-380`：反向采样。

一手来源：[Diffusion Policy](https://arxiv.org/abs/2303.04137)。

## 三、必须区分的三种“分段”

当前材料里至少混用了三个不同概念。

| 概念 | 改变对象 | 主要影响 | 是否属于长期视觉记忆 |
|---|---|---|---|
| Action chunk | 一次预测和执行多少动作 | 开环长度、反馈频率、控制平滑性 | 否 |
| 训练历史分段采样 | 训练时从哪些历史时间点取帧 | 历史证据覆盖率 | 是，训练数据构造 |
| 在线 retention/reservoir | 部署时哪些旧帧在有限缓存中存活 | 推理时可用的历史证据 | 是，在线记忆管理 |

### 3.1 Action chunk 不是长记忆

chunk 大意味着更长时间开环执行，动作可能更连贯，但反馈更迟、误差更容易积累；chunk 小意味着更频繁重规划，但可能产生抖动或模式切换。

当前 RememberColor3 同 checkpoint、同评测协议结果：

| inference action chunk | 成功率 |
|---:|---:|
| 1 | 6/30，20.00% |
| 2 | 6/30，20.00% |
| 3 | 4/30，13.33% |
| 4 | 6/30，20.00% |

成功率没有单调关系，因此 action chunk 只能作为控制超参数，不能作为“分段记忆提高成功率”的证据。

### 3.2 训练分段采样

`LongMemSequenceSampler` 位于 `cleandiffuser/dataset/dataset_utils.py:205-286`，主要逻辑是：

1. 确定当前样本的 episode 起点，避免跨 episode；
2. 将旧历史按 `subsample_ratio` 分段；
3. 每段随机抽取一个时间点；
4. 可选保留 episode anchor；
5. 超过最大长度后保留第一个已选点和最近若干点。

需要注意：`dataset_memory_type` 虽然被传入和保存，但当前没有真正用于不同采样算法分支。因此配置名称不能直接当作不同方法已经实现的证据。

### 3.3 在线 retention

在线阶段要解决的是：固定容量中哪些历史帧留下来。recent、anchor+recent、reservoir、QFormer bank 的保留机制不同，必须与训练采样机制分别分析。

当前还存在 train/inference mismatch：训练阶段按段随机抽帧，在线 QFormer 通常按固定相位 `step % ratio == 0` 写入。短暂 cue 可能在训练中有概率被看到，却在在线固定相位中被系统性错过。

## 四、分段记忆为什么“可能”提高成功率

设：

- $W_t$：最近视觉窗口；
- $H_t^{old}$：更早历史；
- $Z_t$：当前图像不一定直接可见的隐藏任务状态；
- $A_t$：当前正确动作。

旧历史具有额外决策价值的必要条件是：

$$
I(A_t;H_t^{old}\mid W_t)>0
$$

也就是：看完最近窗口后，旧历史仍包含当前动作需要的信息。

如果：

$$
P(A_t\mid W_t,H_t^{old})=P(A_t\mid W_t)
$$

那么近期窗口已经是充分统计量，增加旧历史不可能提高 Bayes 最优动作，反而可能因为噪声、伪相关、陈旧状态、容量竞争和优化负担降低成绩。

如果历史被压缩为 $E_t=C(H_t^{old})$，还必须满足：

$$
I(A_t;E_t\mid W_t)>0
$$

完整成功链是：

> 历史中存在必要线索 → retention 捕获线索 → 压缩后仍可解码 → 策略真正使用 → 低层动作执行成功。

可近似分解为：

$$
P(\text{success})\approx p_{\text{motor}}[p_{\text{capture}}p_{\text{decode}}+(1-p_{\text{capture}})p_{\text{guess}}]
$$

其中：

- retention 和分段采样主要改变 $p_{capture}$；
- QFormer 等压缩器主要改变 $p_{decode}$；
- action chunk 和低层控制主要改变 $p_{motor}$。

在固定 $K$ 个 token 下，分段或均匀采样可能比 recent-$K$ 覆盖更长时间、减少相邻冗余。如果一个长度为 $r$ 的区间中 cue 持续 $d$ 帧，每段均匀抽一帧，则近似捕获概率为：

$$
p_{capture}\approx d/r
$$

但这不是保证：短 cue 仍会被漏掉，稀疏帧也可能破坏速度和接触信息；压缩器还可能丢掉已经捕获的证据。

## 五、创新点的真实演化路径

### 5.1 原始 VPWEM

原始问题链是稳定的：

> 部分可观测低层控制需要越窗历史 → 完整历史成本持续增长 → working memory 保存近期细节 → QFormer 将更早的单回合历史压缩为固定 token → 条件化 Diffusion Policy。

这不是凭空换故事，是合理的研究问题和方法链。[VPWEM 论文](https://arxiv.org/abs/2603.04910)、[官方代码](https://github.com/HarryLui98/code_vpwem)。

但在当前服务器严格流程中，基线 parity 是混合的：

- ShellGameTouch：约 91.11%，接近论文；
- RememberColor3：约 2.22%，论文约 82%；
- LongSquare 修复 evaluator 后 strict seed100 为 23.33%，仍远低于论文约 70%；
- Robomimic 四项本地高分主要来自 4-layer 变体，不能称为论文 8-layer 严格复现。

所以原始机制合理，不等于当前管线已经全面证明其效果。

### 5.2 delta-PER

delta-PER 来自“变化帧可能是事件”的直觉，最终实现基本是相邻视觉 embedding 的变化量。

逻辑断点是：

$$
\text{视觉变化大}\neq\text{任务事件}\neq\text{未来动作有用}\neq\text{隐藏状态充分}
$$

Transport/mh 三训练 seed、900 rollouts：

| 方法 | 成功率 | 差值 |
|---|---:|---:|
| FIFO | 357/900，39.67% | — |
| delta-PER | 383/900，42.56% | +2.89pp |

但 paired bootstrap 95% CI 为 `[-1.33,+7.11]pp`，McNemar `p=0.203`。跨 MIKASA/MoMaRT 的 12 个任务总体约 `-0.25pp`，ShellGameTouch 还下降约 12pp。

此外正式实验存在 candidate interval、训练/推理采样比例和 scheduler 配置混杂。因此 delta-PER 应停止作为性能创新，保留为负结果。

### 5.3 Learned retention

seed100 screening：

| 方法 | 成功率 |
|---|---:|
| FIFO | 38% |
| delta | 35% |
| learned | 39% |
| random/raw | 51% |

learned selector 离线保留 Oracle importance 约 80.43%，高于 delta 和 random，但验证相关性只有约 0.035，在线仅比 FIFO 高 1pp。

这说明离线 importance 排序没有形成：

> retention → hidden-state recovery → correct decision → success

因此当前 learned objective 也应停止。

### 5.4 Coverage/CPB

Random raw 的正结果促成了 Coverage First 和 CPB-VPWEM，但目前只能称为证据驱动的候选假设，不能称为已经成立的方法。

## 六、Random/Reservoir 实验的严格审计

### 6.1 数值正信号

Transport/mh 多 seed：

| train seed | FIFO | Random-2 raw | 差值 |
|---:|---:|---:|---:|
| 100 | 38% | 51% | +13pp |
| 200 | 36% | 58% | +22pp |
| 300 | 39% | 44% | +5pp |
| pooled | 37.67% | 51.00% | +13.33pp |

episode pooled McNemar `p=0.0008`，bootstrap CI 约 `[+5.7,+20.7]pp`。

但训练 seed 只有 3 个，seed 差值 `[13,22,5]pp` 的 seed-level t CI 约 `[-7.8,+34.5]pp`。三组训练 seed 还复用了同一套 100 个 episode，因此不能把 pooled 300 对当作 300 个独立训练重复。

### 6.2 当前实现不是标准无偏 reservoir

`cleandiffuser/nn_memory/random_memory.py:69` 当前使用：

```python
j = torch.randint(0, self.step, (B,))
```

PyTorch 的上界不包含 `self.step`。标准 Algorithm R 在处理当前新元素时，应允许抽到新元素自身，即 high 应为 `self.step + 1`。

当前实现会导致第一次溢出时必然替换一个旧元素，早期元素的保留概率低于后续元素。因此不能使用“unbiased reservoir”或“均匀历史覆盖”的强表述。

### 6.3 训练索引共享且训练/推理分布不同

训练 `forward` 使用一次 `torch.randperm(T)[:K]`，整批轨迹共用同一组时间索引；训练只从最长约 16 帧历史中抽 2 帧，推理却在整个 episode 流上做在线有偏 reservoir。

### 6.4 Raw 与 QFormer 严重混杂

- Random/Recent 输出两个 raw embedding，不使用 QFormer；
- FIFO 使用 bank8，再经过两层 QFormer 压缩成两个 token；
- checkpoint 大小约 79MiB 对 113MiB。

所以 Random 与 FIFO 同时改变了 retention、compression、参数量和训练/推理历史分布。

seed100 机制拆分：

| 方法 | 成功率 |
|---|---:|
| FIFO QFormer bank8 | 38% |
| Recent-2 raw | 46% |
| QFormer random-evict bank8 | 38% |
| Random/Reservoir-2 raw | 51% |

逐 episode 重算：

- Random raw vs Recent raw：+5pp，CI 约 `[-8,+18]pp`，`p≈0.551`；
- Recent raw vs FIFO QFormer：+8pp，`p≈0.291`；
- QFormer random-evict vs FIFO：0pp，`p=1`。

真正隔离 coverage 的 Random-vs-Recent 并不显著；最大差异同时去掉了 QFormer。因此当前证据更像“raw fidelity 可能有帮助”，不能证明 coverage 是 +13.33pp 的因果来源。

### 6.5 RNG 口径

`torch.randint` 未指定 device，默认使用 CPU RNG；GPU 评测中的 diffusion `randn_like` 使用 CUDA RNG。因此不能笼统声称 RandomMemory 必然改变 CUDA diffusion noise stream。

但 retention CPU RNG 没有独立 generator，也没有保存逐步 retention 轨迹；不同方法运行时也没有复用完整 action-noise 序列。严格配对应当分别管理环境、retention、diffusion generator，并保存每个 episode 的环境初态、retention index 与 action-noise seed/noise。

### 6.6 最终证据判定

> Random-2 raw 是 Transport/mh 上值得修复后复测的候选，不是已证实的 coverage 创新。

## 七、为什么看了很多论文却没有直接复现

此前混淆了两种复现。

### 7.1 完整系统复现

MemoryVLA、HAMLET、MemER、RoboMME 等可能使用不同 VLA/VLM backbone、语言监督、动作层级、数据格式和算力。它们可以按官方生态运行，但完整系统结果不能直接冒充当前 DP-PTP 下的公平基线。

### 7.2 机制级复现

只要核心机制能隔离，就必须移植到统一 DP-PTP、统一 token 数、统一历史范围和统一训练预算下比较，不能用“架构不同”回避强基线。

| 路线 | 当前复现方式 | 优先级 |
|---|---|---:|
| Recent/periodic/uniform/FrameSamp | 直接选择 raw history token | 必做 |
| Corrected reservoir/stratified/anchor+recent | 直接实现 | 必做 |
| ALT nearest observation→action lookup | 当前已有 `dp_emb`，可直接建索引 | 必做诊断 |
| HAMLET-style moment aggregation | 在 256-d embedding 上适配 block-causal aggregation | 必做强基线 |
| xLSTM/recurrent state | 固定大小 recurrent state 条件化现有 decoder | 必做 |
| MemoryVLA-style adjacent merge | 迁移最小 merge/retrieval 组件 | 必做组件对照 |
| MemER keyframe mechanism | 迁移无语言 keyframe/change-point 版本 | 次优先 |

一手来源：

- [MemoryVLA](https://github.com/shihao1895/MemoryVLA)
- [HAMLET](https://github.com/myungkyuKoo/HAMLET-Isaac-GR00T)
- [MemER](https://memer-policy.github.io/)
- [ALT](https://stanfordmsl.github.io/alt/)
- [RoboMME](https://arxiv.org/abs/2603.04639)

正确结论是：

> 完整系统通常不能原样替换当前 backbone，但其核心机制可以而且必须做同预算复现。

## 八、重新冻结研究目标与工作顺序

建议永久冻结问题，不冻结具体模块：

> 在当前观测不足以决定动作时，如何在固定 token、显存和单步计算预算下，从单回合历史维持对未来动作充分、对轨迹身份不敏感、并可被新证据修正的任务状态？

以后必须遵循：

> 稳定问题 → 测量瓶颈 → 因果假设 → 预注册预测 → 公平实验 → 因果干预 → 最后命名与叙事。

不采用“先找到涨点方法，再串成故事”。成功率仍然是最终指标，但必须知道变化来自 capture、decode、policy use 还是 motor control。

## 九、研究问题、实验预测与停止条件

| 编号 | 研究问题 | 最小实验 | 通过条件 | 不通过时 |
|---|---|---|---|---|
| RQ0 | 基线和评测是否正确 | 原论文配置、evaluator、数据、checkpoint parity | RememberColor3/LongSquare 恢复可信水平 | 停止创新，只做 pipeline regression |
| RQ1 | 任务是否真的需要旧历史 | recent/no history、oracle cue、full history、matched/zero/wrong memory | oracle/full history 明显优于 recent | 停止在该任务研究 memory |
| RQ2 | coverage 是否有效 | recent、corrected reservoir、stratified、anchor+recent | 至少两任务成立，且优势随 cue-delay 增大 | 删除 coverage 故事 |
| RQ3 | compression 是否丢证据 | 固定相同时间戳比较 raw 与 QFormer | probe、目标选择、success 同向改变 | 不再归因 retention |
| RQ4 | evidence 与 belief 是否互补 | all-raw、all-belief、hybrid，固定总 token | hybrid 同时超过二者 | 不命名 CPB |
| RQ5 | learned utility 是否必要 | coverage floor + query-conditioned selector | 超过 uniform/reservoir，且 span/write rate 匹配 | 停止 learned selector |
| RQ6 | 是否需要 revision | cue reversal、relocation、rollback | stale-memory 恢复步数与成功率改善 | 没有 stale failure 就不加 revision |
| RQ7 | 是否只是轨迹/动作查表 | hidden-state probe、trajectory-ID probe、ALT | 状态可读、轨迹 ID 弱、OOD 提升 | 降级“状态记忆”主张 |
| RQ8 | 瓶颈是否在低层控制 | cue recall、目标选择、抓取、放置、最终成功分阶段统计 | memory 改善沿因果链传递 | 若只改善目标判断，转向控制器 |

## 十、具体执行方案

### P0：Correctness gate

在任何新方法训练前完成：

1. 冻结 clean commit；记录当前 dirty diff；
2. 保存完整 Hydra config、数据、normalizer、checkpoint 和环境哈希；
3. 修复 reservoir off-by-one；
4. 训练改为每个 batch 样本独立采样；
5. 对齐训练与在线 retention 的历史范围和采样分布；
6. 环境、retention、diffusion RNG 三路隔离并记录；
7. 单测每个位置的 inclusion frequency、token age/span、episode reset 和 sampler episode boundary；
8. 修复 RememberColor3、LongSquare baseline parity；
9. 已经反复查看的 eval set 永久降级为 development set。

如果 LongSquare 仍低于 50%、RememberColor3 仍远低于论文，停止在这两个任务上堆叠创新，只进行 pipeline regression。

### P1：Bottleneck ladder

每个任务运行：

1. M0：recent/no-history DP；
2. M1：oracle hidden state 或 oracle cue；
3. M2：full-history upper bound；
4. M3：matched、zero、wrong-trajectory memory。

同时报告：

- cue 是否被 memory 捕获；
- 隐藏状态是否解码正确；
- 是否选择正确目标；
- 是否完成抓取；
- 是否完成放置；
- 最终任务成功率。

如果 oracle cue 能恢复正确目标但最终成功率不涨，瓶颈在低层控制，不应继续设计复杂记忆。

### P2：Retention 因素隔离

Transport/mh development screening：3 train seeds × 100 paired episodes。

方法：

1. Recent-2 raw；
2. corrected unbiased Reservoir-2 raw；
3. Stratified/uniform-bin-2 raw；
4. Anchor+Recent-2 raw。

必须保持相同：

- backbone；
- 初始化策略；
- token 数；
- 训练步数；
- LR schedule；
- candidate interval；
- 训练历史范围；
- 环境初态和 action noise。

这一阶段只回答“哪种保留规则提高分数”。

### P3：Representation 因素隔离

固定完全相同的被选时间戳，比较：

- raw-2；
- QFormer→2；
- hybrid raw1+belief1。

最小 $2\times2$ 矩阵：

| | Raw | QFormer |
|---|---|---|
| Recent | recent/raw | recent/QFormer |
| Coverage | coverage/raw | coverage/QFormer |

这一阶段回答收益来自 temporal coverage 还是 evidence fidelity/compression。

### P4：外部强基线

P2/P3 通过后再加入：

- FrameSamp/uniform；
- HAMLET-style；
- xLSTM；
- MemoryVLA-style merge；
- ALT lookup。

复杂方法必须超过最强简单 raw baseline，不能只超过原 FIFO-QFormer。

### P5：候选新方法

只有对应 gate 通过后才增加相应模块：

- coverage/raw 稳定胜出：保留 coverage floor；
- raw 明显优于 QFormer：研究 evidence fidelity，不先增加更复杂压缩；
- all-raw 与 all-belief 各有失败：测试固定总预算的 evidence+belief hybrid；
- uniform/reservoir 已经足够：不设计 learned selector；
- 确认存在任务相关选择需求：使用当前 observation/task query 条件化的 future-action utility，而非全局视觉 delta；
- 确认 stale-memory failure：才增加 keep/update/reset revision；
- 确认 trajectory lookup：加入 decision-sufficient、trajectory-invariant 目标。

潜在长期方法目标：

1. 对“近期观测相似、隐藏状态/正确动作不同”的历史，memory 必须区分；
2. 对“轨迹外观不同、隐藏状态/正确动作相同”的历史，memory 应保持不变；
3. 联合 action diffusion loss、state-sufficiency contrastive loss 与 trajectory-identity suppression；
4. 始终保留透明的 coverage floor，避免 learned selector 完全漏掉早期证据。

该方向在正式文献查新和实验 gate 通过前不命名为新方法。

### P6：正式确认

冻结唯一候选后，在从未查看过的评测集合上运行：

- 方法：候选、最强简单 retention、FIFO-QFormer、no-memory/direct-context；
- 任务：至少 3 个 memory-intensive tasks + 1 个 Markov negative control；
- 至少 5 个训练 seed；
- 每方法/任务/seed 300 个 paired episodes；
- 训练 seed 作为主要统计推断单位；
- task/seed/episode 分层 bootstrap；
- top candidate 增加 matched/zero/wrong/reverse memory intervention。

四方法 × 三主任务 × 五 seed × 300 episodes，确认阶段约 18,000 条 rollouts。只有 development gate 通过后才投入。

## 十一、Go/Stop 标准

### Development 晋级

候选必须同时满足：

- 相对 Recent 和 corrected Reservoir/stratified 至少 +5pp；
- 至少 2/3 train seeds 同方向；
- 任一 seed 不退化超过 5pp；
- token span、cue recall、hidden-state probe 按假设改变；
- 没有额外 token、历史范围、参数量或训练预算混杂。

### 正式 claim

必须同时满足：

- 分层 95% CI 下界大于 0；
- 平均至少 +5pp；
- 至少两个 memory-intensive tasks 成立；
- 关键任务至少 4/5 seed 为正；
- Markov/安全回归任务不下降超过 5pp；
- latency、显存、token 和参数预算在预注册范围内；
- matched > zero 且 matched > wrong memory；
- 结果在未见 confirmation set 上成立。

### 立即停止条件

- delta-PER 当前版本停止；
- 当前 learned retention objective 停止；
- corrected reservoir 不能胜过 Recent/stratified 时，不讲 coverage；
- hybrid 不能同时胜过 all-raw 与 all-belief 时，不讲 CPB；
- learned selector 不能胜过 uniform/reservoir 时停止；
- 没有 stale-memory failure 时不增加 revision；
- 复杂方法不能超过简单 raw retention 时，保留简单方法和负结果，不重新命名；
- 同一 eval set 经多轮方法筛选后，不再用于正式确认。

## 十二、最终创新决策

### 建议保留

- 原 VPWEM 的 bounded within-episode memory 问题；
- working context 与越窗历史分离；
- 固定 token 条件化低层 diffusion action generation；
- memory intervention、cue-delay、资源曲线等因果评测。

### 建议删除或降级

- delta-PER 作为性能主创新；
- “变化天然等于关键事件”的强主张；
- learned retention 已经有效的表述；
- action chunk 作为记忆创新；
- RandomMemory 作为算法创新；
- Coverage First 已经成立；
- CPB、prediction、revision 已经有效。

### 当前最高概率的涨点路线

在 baseline correctness 修复后，最值得优先测试的是：

> 训练/推理一致的 stratified 或 uniform raw history token，必要时加入明确的 anchor，在固定 $K=2/4$ 和统一预算下与 Recent、corrected Reservoir、QFormer 比较。

它目前首先是强基线，不是论文创新。

### 真正可能形成下一篇创新的方向

仅仅组合 raw evidence + compact belief 与 MemoryVLA 等已有 perceptual/cognitive memory 叙事重叠较大。更值得形成方法贡献的是：

> Coverage-constrained, decision-sufficient, trajectory-invariant episodic memory。

核心不是“保存变化最大的帧”，而是：

- 保证跨时间证据覆盖；
- 区分近期观测相同但隐藏任务状态不同的历史；
- 抑制与训练 trajectory identity 相关的伪特征；
- 只在实验证明必要时增加 task-conditioned utility 和 revision。

这个方向必须经过 RQ0–RQ7 的逐级证据后再命名。

---

## 十三、最终结论

当前没有证据证明“分段记忆普遍提高成功率”，也没有一个新增创新达到已确认有效的标准。

原 VPWEM 的问题与方法链是成立的，但当前服务器对 RememberColor3、LongSquare 的严格复现仍失败。delta-PER 与 learned retention 没有稳定在线收益；Random-2 raw 在 Transport/mh 上有值得重测的正信号，但实现、压缩方式、参数量和训练/推理分布均存在混杂，不能归因为 coverage。

后续研究主线应固定为：

> 先证明旧历史对当前动作确有条件增量信息，再依次验证历史捕获、证据保真、状态解码、策略使用和低层执行；简单方法过不了就停止，复杂方法不能超过简单基线就不换名字讲新故事。

只要严格遵守这些 gate，即使最终结论是“简单 uniform/raw memory 最好，复杂 retention 无收益”，也比不断更换叙事更可靠，并且可以形成有价值的机制和负结果贡献。
