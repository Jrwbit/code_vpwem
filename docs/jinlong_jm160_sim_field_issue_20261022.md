## 已完成的独立终点审计

按相同归档输入、有效DH、选定JM160端子模型、−90°工具安装、当前右臂和相机模型，在隔离MuJoCo环境运行arm_ik、ik_low_elbow、ik_stage。独立63次采样中24次收敛、0次合法，不声称逐项重放生产原159次随机序列。拒绝组合：

| 拒绝项 | 次数 |
|---|---:|
| 仅碰撞 | 12 |
| 碰撞+肘高 | 1 |
| 碰撞+腕部 | 1 |
| 仅腕部 | 2 |
| 限位余量+腕部 | 8 |

14次碰撞的最小间隙配对均为`keepout_camera / AR5-5_07L_link4`，代表模型禁入区冲突，不能据此说现实设备已经相撞。无碰撞的一个收敛解模型间隙约5.359 mm，但J6≈40.609°、J7≈87.854°，腕部指标≈1.411 > 0.95，且限位余量约1.146° < 2.865°。

本轮门限保持：终点模型间隙≥0、关节限位余量≥0.05 rad、肘相对肩高≤0.1 m，`(J6/60°)^2+(J7/90°)^2≤0.95`；规划J7为±89°。**需要核对成功仿真是否使用同样的相机禁入区、工具安装/模型、有效DH、腕部和限位余量门限，以及同样腰姿与目标坐标，不能把本轮拒绝项当作已确认的唯一根因。**
