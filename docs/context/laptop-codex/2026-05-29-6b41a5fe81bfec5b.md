三、关键模块

1. preprocess_image(img)

功能：
- 转灰度
- CLAHE 增强
- 高斯滤波
- Canny 边缘
- 形态学闭运算

返回：
- gray
- enhanced
- edges

2. detect_terminal_box(img)

功能：
- 找接线盒大 ROI
- 如果当前图像里接线盒边框不明显，先允许手动给默认 ROI
- 后续再优化自动检测

实现方式：
- findContours 找大轮廓
- 用 minAreaRect 得到旋转矩形
- 选择面积合适、长宽比合理的轮廓
- 返回 box_rect，包括：
  - center
  - size
  - angle
  - four corners

如果自动找不到，则返回整张图中央区域作为 fallback ROI。

3. warp_box_to_canonical(img, box_rect)

功能：
- 根据接线盒旋转矩形，把接线盒区域透视变换/仿射旋正
- 输出标准正视 ROI 图像
- 保存 transform 矩阵 M 和 Minv，用于把局部坐标映射回原图

返回：
- warped_roi
- M
- Minv

4. get_norm_roi(image, norm_rect)

功能：
根据归一化比例裁剪 ROI。

norm_rect 格式：
[x_norm, y_norm, w_norm, h_norm]

例如：
terminal_grid.search_roi_norm = [0.15, 0.20, 0.70, 0.45]

表示在旋正后的接线盒 ROI 中，裁剪中上部区域用于找六个接线柱。

5. detect_circle_candidates(roi)

功能：
在指定 ROI 内找圆/椭圆候选，而不是全图找。

候选检测方法：
- 优先使用轮廓法
- HoughCircles 作为备选

轮廓法步骤：
1. 灰度化
2. blur
3. threshold 或 Canny
4. findContours
5. 对每个 contour：
   - 面积过滤
   - 圆度过滤 circularity = 4*pi*area/perimeter^2
   - minEnclosingCircle 得到 center/radius
   - 如果 contour 点数足够，用 fitEllipse 得到 angle
6. 返回候选列表

每个 candidate：
{
  "center": [x, y],
  "radius": r,
  "angle": angle,
  "area": area,
  "circularity": circularity,
  "score": score
}

注意：
这里的 center 是 ROI 内坐标，后续要加上 ROI offset。

6. match_2x3_terminal_grid(candidates)

功能：
从候选圆中选出最符合 2 行 × 3 列结构的六个接线柱。

不要单独判断每个圆，而是整体匹配一组 6 个点。

实现逻辑：

A. 如果候选数量刚好或不多：
- 遍历 combinations(candidates, 6)
- 对每组做评分
- 返回分数最高的一组

B. 如果候选数量很多：
- 先按半径、圆度、位置过滤
- 保留前 20 个以内
- 再 combinations

评分函数 evaluate_grid_score(group)：

输入 6 个候选点，输出 score，越小越好。

评分项：
1. 是否能分成上下两行
2. 每行是否有三个点
3. 每行内部 x 间距是否接近
4. 两行 y 间距是否接近
5. 六个半径是否一致
6. 整体中心是否接近理论区域中心
7. 点阵是否近似矩形

伪代码：

def match_2x3_terminal_grid(candidates):
    best_group = None
    best_score = 1e9

    for group in combinations(candidates, 6):
        pts = np.array([c.center for c in group])

        sorted_by_y = sort by y
        row1 = top 3
        row2 = bottom 3

        row1 = sort row1 by x
        row2 = sort row2 by x

        score = evaluate_grid_score(row1, row2)

        if score < best_score:
            best_score = score
            best_group = [row1, row2]

    if best_score > threshold:
        return invalid

    return ordered six points:
    [
      top_left, top_mid, top_right,
      bottom_left, bottom_mid, bottom_right

```text

-> 找小圆/亮暗圆候选
-> 按四角矩形几何筛选四个点
-> 用四点建立局部坐标系
```

缺点是四角特征必须稳定可见。

**第四方案：模板匹配 / 边缘模板**

如果型号固定，可以拍一张标准接线盒模板：

```text
模板图
-> 提取边缘/ORB特征
-> 当前图里匹配
-> findHomography
-> warp 到标准视图
```

灰色场景下，纯强度模板有时比找轮廓稳。适合型号固定、姿态变化不大的情况。

**第五方案：深度辅助**

如果接线盒相对电机壳有高度差，Orbbec 深度可以辅助：

```text
粗 ROI
-> 深度滤波
-> 找近/远平面差异
-> 分割接线盒凸起区域
-> 拟合矩形
```

但灰色塑料/金属表面和斜视角会让深度有噪声。可以作为辅助，不建议单独依赖。

**第六方案：加标记或工装定位**

如果允许改现场，最稳：

```text
接线盒旁贴 ArUco/AprilTag
或工装上做定位孔/定位边
```

这会极大降低算法难度。

我的判断：如果你真实目标是灰色电机灰色接线盒，而且要传统 OpenCV 稳定运行，最佳路线不是“自动找外框”，而是：

```text
固定工位：手动四角标定 + homography
非固定工位：四角螺丝/安装孔定位
最后才是：HoughLinesP 外框直线组合
```

如果你要继续自动化，我建议下一步改成“手动标定一次接线盒四角 + 实时复用”的版本，先把后面的接线柱检测做稳。

可以，但要分清 CAD 能解决什么、不能解决什么。

CAD 尺寸有用，尤其是后续位姿和 XYZ；但它不能直接替代图像里的外框检测。因为 CAD 是 3D 几何，当前 OpenCV 图像是 2D 灰度/边缘，算法还需要知道 CAD 模型在图像里投影到哪里。

CAD 可以这样用：

**方案 1：CAD 给几何先验，图像找少量特征点**

如果 CAD 里有这些已知点：

```text
接线盒四角
四角螺丝孔
六个接线柱中心
接地螺丝中心
```

你可以从 CAD 里导出它们的 3D 坐标，然后图像中只要检测或手点 4 个以上对应点，就能：

```text
2D 图像点 + CAD 3D 点 + 相机内参
-> solvePnP
-> 得到电机/接线盒位姿
-> 投影出六个接线柱理论位置
-> 只在理论小窗口内精检
```

这很适合你的需求。

**方案 2：CAD 渲染边缘模板**

如果型号固定，可以从 CAD 渲染一个接线盒正视图/边缘图：

```text
CAD 正视图
-> 渲染灰度或边缘模板
-> 当前相机图像做边缘匹配 / ORB / ECC
-> 得到 homography
-> warp 到标准视图
```

这个比纯找外框稳定，但需要 CAD 视角和真实相机视角接近，光照和遮挡不能太离谱。

**方案 3：CAD + 手动一次标定**

这个最实用：

```text
第一次拍真实电机
-> 手点 CAD 中定义的几个结构点对应的图像点
-> 保存 homography 或 solvePnP 结果
-> 后续实时检测只在投影出来的理论区域找目标
```

如果相机固定、工件位置固定，这会非常稳。

**不建议直接做的事**

不建议直接拿完整 CAD 网格去图像里匹配。灰色电机、反光、遮挡、线缆、接线盒盖打开状态都会让完整 CAD 边缘匹配很脆。

最推荐你现在走这条：

```text
CAD 导出关键点坐标
-> 拍一张图手动点击对应关键点
-> solvePnP / homography 建立局部坐标系
-> 六个接线柱和接地螺丝用 CAD 理论位置生成小 ROI
-> OpenCV 只在小 ROI 内精检
```

这比“自动找灰色接线盒外框”靠谱得多。
