流程：

1. 先用深度 raw 范围 `17000-19300` 提取候选区域。
2. 用我刚加的接线盒 mask 只保留接线盒区域，排掉下面长杆和背景。

**我不建议直接全局 ICP 的原因**

你的截图里接线盒点云面积其实不大，下面长杆和电机本体的深度结构更大、更明显。全局匹配时，优化目标会偏向这些大结构，接线盒反而不是主导信息。只要位置变了、倾斜了、背景有变化，就容易匹配到错误局部最优。

**更好的匹配目标**

如果最终只是要“接线盒中心姿态”，不一定需要完整 CAD 点云匹配。可以优先用几何：

- 中心：接线盒 mask 的旋转矩形中心 + 深度中位数反投影。
- 朝向：旋转矩形角度或接线盒边框点云 PCA。
- 法向：接线盒上表面/边框局部点云 RANSAC 拟合平面。
- 姿态矩阵：`x_axis` 取长边方向，`z_axis` 取平面法向，`y_axis = z x x`。

这会比 ICP 更快，也更可解释。

-> ICP refine 到接线盒模板点云
