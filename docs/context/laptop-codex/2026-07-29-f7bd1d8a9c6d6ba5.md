#### 4. 如何得到真正的XYZ误差

“探针能插入孔”只能得到通过/失败，不能得到准确误差。要测数值，建议对每个孔做四边寻心：

```text
接触孔左边缘：x_left
接触孔右边缘：x_right
接触孔上边缘：y_top
接触孔下边缘：y_bottom
接触上表面：z_plane
```

孔中心真值：

```text
x_gt = (x_left + x_right) / 2
y_gt = (y_top + y_bottom) / 2
z_gt = z_plane + 孔中心要求的Z偏移
```

程序视觉输出为：

```text
P_vision = [x_vision, y_vision, z_vision]
```

误差计算：

```text
ex = x_vision - x_gt
ey = y_vision - y_gt
ez = z_vision - z_gt

XY误差 = sqrt(ex² + ey²)
三维误差 = sqrt(ex² + ey² + ez²)
```

球头半径会影响单侧接触坐标，但左右取中点时半径误差基本抵消。最好使用触发探针或电接触信号，手动目测接触难以达到亚毫米精度。

- 四个孔各测一次，得到单次四点误差；
- 同一工件重复视觉检测和落点 10 次，测重复性；
- 工件拆下重装 10 次，测夹具重装误差；
- 换 3～5 个不同工件，测产品差异；

```text

```
