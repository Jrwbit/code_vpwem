比如视角从正面变成大斜角、距离大幅变化、孔变小、反光/遮挡变多、接线盒旋转角度范围更大。
这种建议**补拍一批数据再训练或微调 YOLO**，否则可能出现你之前那种：

```text
corner_hole 只识别到 3 个
ground_screw 识别不到
```

实用判断方式：先把相机移到新位置，直接跑：

```bash
cd /[REDACTED long identifier]pnp验证
./run.sh
```

如果连续 20 张都能稳定出 `4 个孔 + 1 个接地螺丝`，YOLO 暂时不用重拍。
如果经常漏检、误检、置信度低，再补拍数据集。

最低要求：

```text
相机固定位置变了：一定重新做手眼标定
相机分辨率/镜头/对焦变了：重新做内参
YOLO 检测不稳：补拍数据集重新训练
```
