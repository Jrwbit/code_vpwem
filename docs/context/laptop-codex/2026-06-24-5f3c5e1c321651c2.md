3. 每个点运动前会检查当前关节到目标关节的跳变，超过限制就停。
4. 到位后等机械臂停稳。
5. CharUco 检测成功且重投影误差合格，才保存：
   ```text

   0001_overlay.png
   0001.json
   ```
6. 如果检测失败、相机超时、UR 网络断开，会停止，不会跳过继续乱采。
