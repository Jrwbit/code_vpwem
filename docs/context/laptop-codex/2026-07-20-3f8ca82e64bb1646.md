## assistant — 2026-07-20T06:21:13.301Z

可以分三层测试：物理连接、网络通信、传输性能。

1. 看物理链路

- 交换机端口灯和电脑网口灯应亮起或闪烁。
- Linux 查看网口：

```bash
ip -br link
```

找到类似 `enp3s0`、`eth0` 的有线网卡。如果显示 `UP` 且 `LOWER_UP`，说明网线、网口和交换机端口已成功建立链路。

进一步检查：

```bash
sudo ethtool enp3s0
```

重点看：

```text
Link detected: yes
Speed: 1000Mb/s
Duplex: Full
```

把 `enp3s0` 替换成实际网卡名。若显示 `Link detected: no`，依次更换网线、交换机端口、电脑网口测试。

2. 测试实际通信

先查看是否获得 IP：

```bash
ip -br addr
ip route
```

如果交换机连接的网络中有 DHCP，可以重新获取地址：

```bash
sudo dhclient -v enp3s0
```

然后测试网关：

```bash
ping -c 10 网关IP
```

例如：

```bash
ping -c 10 192.168.1.1
```

也可以测试同一交换机上的另一台设备：

```bash
ping -c 10 对方IP
```

注意：普通交换机自身可能没有 IP，也不一定提供 DHCP。仅把电脑接到一个未连接其他设备的交换机上，只能验证链路建立，无法完整验证数据通信。

3. 测试丢包和速度

需要另一台接在同一交换机上的电脑。两台电脑配置到同一网段，例如：

- 电脑 A：`192.168.50.1/24`
- 电脑 B：`192.168.50.2/24`

电脑 B 启动服务：

```bash
iperf3 -s
```

电脑 A 测速：

```bash
iperf3 -c 192.168.50.2
iperf3 -c 192.168.50.2 -R
```

千兆网口实际通常能达到约 `900–950 Mbit/s`。同时可查看网卡错误计数：

```bash
ip -s link show enp3s0
```

如果 `errors`、`dropped`、`carrier` 持续增加，可能是网线、接口接触或速率协商存在问题。

你这个用途——上游网络接入交换机，再分给多个人上网——请选择最下面的「标准交换」模式。

三种模式大致用途：

- 标准交换：所有端口正常互通，适合办公室多人共享网络。
- VLAN 隔离：各用户端口之间相互隔离，适合不希望用户设备互访的场景；需要按该型号指定端口连接上联。
- 网络克隆：用于特定的网络复制/克隆场景，普通上网不需要。

建议接法：

```text
上游路由器 LAN口
        │
交换机任意端口
   ├── 用户电脑
   ├── 用户电脑
   └── 用户电脑
```

注意：

- 切换到「标准交换」后，最好将交换机断电再通电。
- 上游必须有路由器或单位网络的 DHCP 服务，交换机本身不会给用户分配 IP。
- 两台交换机级联时，只用一根网线连接它们，不能接两根形成环路，否则可能导致全网卡顿或断网。
- 你之前关闭 Wi‑Fi 后可以正常上网，说明当前上联网络是可用的。切换模式并重启后，再测试：

```bash
ping -c 20 10.1.76.1
ping -c 20 223.5.5.5
```

两项都稳定、无丢包即可投入使用。
