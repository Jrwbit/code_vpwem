1. **先保住已有动作能力，再验证记忆是否增益。**
   当前 raw TTT 从头训练，但100k时策略参数实际更新约59,964次，对照约99,965次，学习率也更低；这首先是训练条件不同，尚不能归因于“记忆无效”。最小方案是同一强 No-History 权重，保留原视觉和注意力路径，另设记忆读取残差：
   `h_i' = h_i + tanh(α) · P(Read(h_i, M))`。
   `α=0`、投影正常初始化；不能把门和投影同时置零。先验证关闭分支时，同输入、同噪声的动作采样一致，再与同一权重继续训练的 No-History 比较。将零 token 追加到原注意力中不满足这一点：它仍改变 softmax 分母。依据：四方法审计；T²Mem、IMPRINT提供相关机制启发，**不是此具体方案已有效的证据**。

2. **PTP 的时间约束必须覆盖新记忆分支。**

**PTP：Learning Long-Context Diffusion Policies via Past-Token Prediction**
arXiv:2505.09561，CoRL 2025；作为已有方法背景。它让 Transformer DP 在预测未来动作时，同时重建观测窗口对应的过去动作，促使动作头利用时序关系。先训练短上下文视觉编码器，再冻结并缓存图像特征，训练长上下文动作头；没有新增固定容量记忆库。同文三种子实验条件中，Long Square 的 PTP 为93%±2%，无历史12%±5%，有历史但无PTP为3%±2%；三个随机种子。收益不能全归于一个辅助损失，后续研究指出冻结编码器也有贡献。官方代码包含训练、配置、数据处理与评估说明，已实质公开。[论文](https://arxiv.org/html/2505.09561v2) · [代码](https://github.com/long-context-dp/ldp)

**LongContextDP：Training and Evaluating Diffusion Policies with Long Context Lengths**
arXiv:2606.16447，v2为2026-07-09。它不另造记忆库，而是研究“直接让 DP 看更多历史，怎样才能训好”：采用 U-Net＋cross-attention 读取历史 token，并在训练中混合短、长上下文，或逐渐扩大历史长度。五任务、三档数据规模的研究发现，长历史失败取决于骨干、数据量和操作难度，不能笼统归因于历史噪声；低数据条件下，可变历史训练相对最强固定历史对照提升约1.25—2倍，幅度依任务而异。也复查了PTP，指出冻结短历史编码器参与了收益。适合作为复杂memory模块必须面对的强简单对照；作者项目代码仍标coming soon。[论文](https://arxiv.org/html/2606.16447v2) · [项目](https://dp-with-long-context.github.io/)

**DSSP：Diffusion State Space Policy with Full-History Encoding**
arXiv:2605.14598，v2为2026-05-21。Mamba逐步把完整观测历史压成一个状态token，辅助任务根据“记忆＋已执行动作”预测下一状态特征；历史token与最近观察共同作为前缀输入扩散去噪器，扩散步通过AdaLN单独注入。它同时将去噪器换成Mamba，主要实验使用点云，因此不是在原RGB DP上只添一个memory。最清楚的同架构消融是六个历史敏感任务：移除历史编码器64.33%，完整模型71.33%；移除动力学辅助损失69.50%。可借鉴状态预测监督和持续递推，但需独立控制骨干与输入模态；未核实官方可运行代码入口。[论文](https://arxiv.org/html/2605.14598v2)
