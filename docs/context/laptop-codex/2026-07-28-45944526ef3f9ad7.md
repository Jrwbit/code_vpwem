## 第一阶段：Windows 下处理 `/data`

这是最重要的一步。目的是清除 NTFS 的休眠和 dirty 状态，让 Linux 能以读写方式挂载 `/data`。

### 1. 确认 Data 分区的盘符

用管理员身份打开 PowerShell：

```powershell
Get-Volume | Format-Table DriveLetter, FileSystemLabel, FileSystem, Size, SizeRemaining
```

找到满足这些特征的卷：

```text
FileSystemLabel: Data
FileSystem:      NTFS
Size:            约 638 GiB
```

假设它是 `D:`。如果实际是其他盘符，后面全部替换。

也可以打开：

```text
Win + X → 磁盘管理
```

确认约 638 GiB、名称为 `Data` 的分区。不要把 Windows 系统盘误认为 Data。

### 2. 检查 BitLocker

管理员 PowerShell：

```powershell
manage-bde -status
```

确认 Data 分区没有处于 BitLocker 加密或锁定状态。如果 Data 被加密，先解密：

```powershell

```

### 3. 关闭休眠

管理员 PowerShell：

```powershell
powercfg /h off
```

这会同时消除 NTFS 处于休眠状态的常见原因。

虽然 `powercfg /h off` 通常已经禁用快速启动，仍建议检查一次。

```powershell
chkdsk D: /f
```

如果提示该卷正在使用，选择允许卸载卷：


如果提示必须重启检查，也选择：

完成后，可以再运行一次：


理想结果应显示没有文件系统问题。
