---

```bash

```

只在第一帧 safety gate 用。意思是：刚开始执行时，模型给出的目标姿态和当前真机姿态最大差值不能超过 `20 deg`。

---

```bash
--single-step-max-delta-deg 20
```

每一轮真正下发前的安全检查。意思是：本轮目标关节角和当前真机关节角的最大差值不能超过 `20 deg`。

它和 `max-delta-deg` 有点重叠，但位置不同：

- `max-delta-deg`：先把模型输出裁剪到当前值附近
- `single-step-max-delta-deg`：裁剪后再做安全检查，超过就不下发

通常 `single-step-max-delta-deg` 应该大于等于 `max-delta-deg`，否则可能经常被 safety gate 拦住。

---

```bash

```

你的数据里右手固定是 `800`，所以这里设 `800`，让推理输入和训练数据一致。
