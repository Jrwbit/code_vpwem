```bash
code --disable-gpu --disable-extensions --new-window
```

如果还是崩，再用一个全新的 VS Code 用户数据目录启动：

```bash
code --disable-gpu --disable-extensions --user-data-dir /tmp/vscode-clean --extensions-dir /tmp/vscode-ext-clean --new-window
```

判断：

- 这个不崩：你原来的 VS Code 配置、缓存或扩展有问题
- 这个还崩：VS Code 本体/Electron/系统环境问题更大

**2. 清理本地 VS Code 缓存**

先关闭所有 VS Code：

```bash
pkill -f code
```

再清理缓存：

```bash
rm -rf ~/.config/Code/Cache
rm -rf ~/.config/Code/CachedData
rm -rf ~/.config/Code/GPUCache
rm -rf ~/.config/Code/Code\ Cache
rm -rf ~/.config/Code/Crashpad
```

然后启动：

```bash
code --disable-extensions --new-window
```

**3. 如果一连 Remote-SSH 就崩，清理远端 VS Code Server**

登录远端：

```bash
ssh 192.168.8.230
```

执行：

```bash
rm -rf ~/.vscode-server
rm -rf ~/.vscode-remote
touch ~/.hushlogin
exit
```

然后本地确认：

```bash
echo 'echo hello' | ssh -T 192.168.8.230
```

应该只输出：

```text
hello
```

再用 VS Code Remote-SSH 重新连。

**4. 临时关闭 Remote-SSH 新启动方式**

VS Code `settings.json` 加：

```json
{
  "remote.SSH.showLoginTerminal": true,
  "remote.SSH.useLocalServer": false,
  "remote.SSH.useExecServer": false
}
```

**5. 看崩溃日志**

运行：

```bash
ls -lt ~/.config/Code/logs | head
```

然后看最新日志目录：

```bash
find ~/.config/Code/logs -type f | tail -30
```

重点找里面有没有：

```text
renderer
crash
remote
extensionHost
ssh
```

你现在最关键的是先跑这条：

```bash
code --disable-gpu --disable-extensions --user-data-dir /tmp/vscode-clean --extensions-dir /tmp/vscode-ext-clean --new-window
```

如果这条还崩，问题就不在 Remote-SSH，也不太像普通扩展问题，而是 VS Code/Electron 和系统环境本身。
