**总体演进**

本项目的视觉定位路线经历了从传统 2D 规则方法，到 RGB-D/点云 3D 方法，再到 YOLO 深度学习检测结合 PnP 的工程化路线。核心目标始终是：稳定识别接线盒或工件关键点，计算其在相机坐标系下的位姿，再通过手眼标定转换到 UR5 基坐标系。

**路线一：传统模板/轮廓匹配**

技术思路：  
先用 OpenCV 对图像做灰度、增强、边缘、轮廓检测，找到接线盒大致区域；再根据接线盒外形、矩形轮廓或预设模板，推断目标所在位置。

典型流程：

```text
相机图像
-> 图像增强、边缘检测
-> 找接线盒轮廓或模板区域
-> 透视变换到标准视角
-> 在固定区域内查找端子、螺丝、孔位
```

优点：

- 不需要训练数据，开发验证快。
- 算法逻辑清楚，方便调参和解释。
- 对固定工位、固定光照、固定摆放比较有效。

主要问题：

- 对光照、反光、遮挡、背景变化敏感。
- 接线盒姿态变化大时，模板或轮廓容易失效。
- 参数多，例如阈值、边缘、面积、圆度、ROI 范围都要人工调。
- 泛化能力弱，换型号、换角度、换环境后容易重新调参。

适用场景：  
固定工装、固定相机、产品变化小的场景，可作为低成本快速验证方案。

**路线二：传统 ROI 圆形检测**

技术思路：  
先定位接线盒大致 ROI，再在 ROI 内用 HoughCircles、轮廓圆度、椭圆拟合等传统方法检测圆孔、螺丝或端子。检测到四个角孔后，用已知物理尺寸做 PnP 位姿计算。

典型流程：

```text
相机图像
-> 接线盒 ROI
-> ROI 内圆形/椭圆候选检测
-> 筛选四个角孔
-> 按左上、右上、右下、左下排序
-> solvePnP
-> camera_T_box
```

优点：

- 比全图检测稳定，因为搜索范围缩小了。
- 四孔 PnP 计算简单，能直接输出接线盒 6D 位姿。
- 可以用人工点选作为对照，便于验证自动检测误差。

主要问题：

- 圆孔、螺丝、反光点、背景纹理容易混淆。
- 孔边缘不清晰时，Hough 圆检测不稳定。
- 四个点只要有一个选错，PnP 重投影误差可能仍然很小，但真实位姿是错的。
- 只能解决“看起来像圆”的目标，对复杂外观不够鲁棒。

适用场景：  
接线盒角孔清晰、背景简单、光照可控时，可以作为传统视觉基线方案。

**路线三：RGB-D 点位反投影 / 点点对应**

技术思路：  
不依赖 CAD，也不做完整点云配准。通过人工点击或 ROI 自动检测得到图像上的关键点，再读取深度图，将 2D 像素反投影成相机坐标系下的 3D 点。

典型流程：

```text
RGB-D 采集
-> 手点或 ROI 检测关键点
-> 读取对应深度
-> 像素点反投影成 3D 点
-> 输出相机坐标下的点位
```

如果点击三个非共线点，还可以定义一个简单物体坐标系：

```text
点1 -> 点2 定义 X 轴
三点平面法向定义 Z 轴
Z x X 定义 Y 轴
```

优点：

- 逻辑直观，适合验证相机深度和关键点坐标。
- 不需要 CAD 模型。
- 可以快速得到端子、孔位等目标的 3D 坐标。

主要问题：

- 深度质量是瓶颈，金属端子、黑色孔洞、反光区域容易深度缺失或跳变。
- 手点方式不能长期自动化。
- ROI 自动检测仍然依赖传统阈值和局部规则。
- 单点深度噪声会直接影响最终 3D 坐标。

适用场景：  
早期验证、点位采集、手眼标定辅助、深度相机可用性评估。

**路线四：CAD / 点云匹配**

技术思路：  
利用工件 CAD 或 STL 模型生成模型点云，再用 RGB-D 相机采集现场点云。去除背景后，将模型点云和现场工件点云做配准，得到工件整体 6D 位姿。

典型流程：

```text
CAD / STL 模型
-> 采样生成 model.pcd
-> RGB-D 采集 scene.pcd
-> 去背景、提取工件点云
-> FPFH + RANSAC 粗配准
-> ICP 精配准
-> 输出 model_T_camera 或 camera_T_model
```

优点：

- 理论上可以得到完整 6D 位姿，不依赖少数二维特征点。
- 适合有 CAD 模型的工件。
- 对整体几何定位更通用，可扩展到不同零件。

主要问题：

- 对点云质量要求高，深度缺失、噪声、遮挡会影响配准。
- 工件如果几何对称，配准可能出现 90°、180° 等方向歧义。
- 背景分割、点云尺度、单位、初始位姿都会影响结果。
- 对小孔、薄边、金属反光等结构，RGB-D 点云往往不够完整。

适用场景：  
有可靠 3D 相机、工件几何明显、点云质量较好的零件定位任务。

**路线五：YOLO 五点检测 + PnP**

技术思路：  
用 YOLO 替代传统阈值和圆检测，直接检测接线盒 ROI、四个角孔和接地螺丝。四孔用于 PnP，接地螺丝用于判断接线盒物理方向，最后结合手眼标定输出 UR5 基坐标系下的位姿。

典型流程：

```text
奥比中光彩色图
-> YOLO 检测接线盒 ROI
-> YOLO 检测四个角孔 + 一个接地螺丝
-> 通过接地螺丝判断物理上边
-> 四孔按 LT / RT / RB / LB 排序
-> solvePnP
-> camera_T_box
-> base_T_box = base_T_camera @ camera_T_box
-> 输出 UR5 [x, y, z, rx, ry, rz]
```

优点：

- 对光照、背景、角度变化的鲁棒性明显优于传统阈值方法。
- 不再依赖 Hough 圆等脆弱特征。
- 接地螺丝参与方向判断，解决四孔矩形本身的方向歧义。
- 输出链路完整，能直接给下游机械臂程序读取。
- 有状态检查：检测不完整、方向不稳定、PnP 深度异常、重投影误差过大时不输出可用位姿。

主要问题：

- 需要采集和标注数据。
- 泛化能力取决于训练数据覆盖范围，包括角度、光照、遮挡、不同批次产品。
- PnP 精度依赖孔中心检测精度、相机内参、实际孔距和手眼标定。
- 重投影误差只能说明图像点和模型点自洽，不能单独证明真实毫米精度。

适用场景：  
当前最适合作为工程主线。尤其适合接线盒四孔清晰、方向需要自动判断、需要接入 UR5 的自动化场景。

**当前推荐技术路线**

当前建议以：

```text
YOLO 五点检测 + PnP + 手眼标定
```

作为主线方案。

原因是它在工程上平衡了稳定性、实时性和可落地性：

- 用 YOLO 解决传统视觉对光照和阈值敏感的问题。
- 用四孔 PnP 保持位姿计算简单可靠。
- 用接地螺丝解决接线盒物理方向判断。
- 用手眼标定完成相机坐标到 UR5 基坐标的转换。
- 用状态字段限制错误结果进入下游机械臂控制。

传统 ROI 圆检测、手点反投影和点云配准仍有保留价值：  
传统方法适合做对照验证；RGB-D 点位适合做三维坐标检查；CAD 点云配准适合后续扩展到几何特征更明显、有稳定点云质量的零件。
