### 1. 遮挡情况下的对齐策略

推荐采用：

> 一个唯一孔 + 端盖方向特征 + 机座独立基准

具体为：

- 先识别端盖三个通孔，即使下层孔被遮挡也保留三个通孔位置。
- 根据孔径、安装耳形状、角度位置等特征，确定哪个是唯一基准孔，例如 H01。

| 可见条件 | 能否判定三孔对齐 |

### 对齐不能要求圆心完全重合

通孔通常比螺栓直径大，本身允许一定偏差。应根据实际尺寸计算允许偏心：

```text
理论径向余量 = (端盖通孔直径 - 螺栓杆直径) / 2
安全允许偏差 =
    理论径向余量
    - 定位误差
    - 机器人误差
    - 螺纹孔加工误差
    - 安全裕量
```

逐孔判定可以写成：

```text
offset + 3 × measurement_uncertainty <= allowable_radial_offset
AND
axis_angle <= allowable_axis_angle
```

不能直接用固定的“圆心误差小于 1 mm”，必须依据三个孔各自的直径、螺栓和公差设定。
