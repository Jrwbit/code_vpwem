## assistant — 2026-06-24T02:07:09.651Z

可以，用 VS Code 的 **Remote - SSH**。

步骤：

1. 在 VS Code 里安装扩展：
   `Remote - SSH`

2. 打开命令面板：
   `Ctrl+Shift+P`

3. 选择：
   `Remote-SSH: Open SSH Configuration File...`

4. 选你的 SSH 配置文件，通常是：

```bash
~/.ssh/config
```

5. 加入这一段：

```sshconfig
Host rm75
    HostName 10.1.77.25
    Port 22022
    User jrw
```

```sshconfig
Host rm75
    HostName 10.1.77.25
    Port 22022
    User jrw
    IdentityFile ~/.ssh/id_rsa
```

6. 再打开命令面板：

```text
Remote-SSH: Connect to Host...
```

选择：

```text
rm75
```

7. 第一次连接会让你选择远端系统，通常选：

```text
Linux
```

连接成功后，VS Code 左下角会显示类似：

```text
SSH: rm75
```

然后你可以点：

```text
File -> Open Folder
```


或者你的项目目录。

如果 VS Code 连接失败，但命令行能连，最常见是 VS Code 没读到同一个 SSH 配置。你可以先在 VS Code 终端里确认：

```bash
ssh -p 22022 jrw@10.1.77.25
```

如果可以，再用上面的 `~/.ssh/config` 方式连接。
