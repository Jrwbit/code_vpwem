可以把四条 `movel` 放进同一个 URScript 程序一次发过去。UR 会按顺序执行，不是四个同时动。

在 Python 交互环境里直接这样发：

```python
import socket

robot_ip = "192.168.10.12"

script = """
def pnp_four_points():
  movel(p[-0.323034174, -0.565664185, 0.387930005, 1.047000000, 2.999000000, -0.005000000], a=0.050000, v=0.020000, r=0.0)
  sleep(1.0)
  movel(p[-0.257236038, -0.628516061, 0.386813312, 1.047000000, 2.999000000, -0.005000000], a=0.050000, v=0.020000, r=0.0)
  sleep(1.0)
  movel(p[-0.320096811, -0.694293522, 0.385125440, 1.047000000, 2.999000000, -0.005000000], a=0.050000, v=0.020000, r=0.0)
  sleep(1.0)
  movel(p[-0.385894947, -0.631441645, 0.386242134, 1.047000000, 2.999000000, -0.005000000], a=0.050000, v=0.020000, r=0.0)
end
pnp_four_points()
"""

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect((robot_ip, 30002))
s.sendall(script.encode("utf-8"))
s.close()
```

更安全一点，第一次建议每个点之间停久一点，比如 `sleep(3.0)`，你能看清是否到位。

另外强调：这会连续走四个点。确认第一点单独跑没问题、路径无碰撞后再执行四点连续。
