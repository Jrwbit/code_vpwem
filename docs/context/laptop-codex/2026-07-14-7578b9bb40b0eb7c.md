建议这样验收：

1. 明确位姿原点  
   当前原点是接线盒四个安装孔中心组成矩形的中心，方向由四孔和接地螺丝确定。现场测量也必须使用同一个原点和坐标轴。

2. 获得独立真值  
   可选方式：

   - 机器人末端安装探针，依次触碰四个安装孔中心。
   - 使用三坐标仪或高精度测量臂。
   - 将电机固定在带精确刻度/定位孔的标定台上。
   - 仅验证相机坐标时，可使用与接线盒刚性连接的标定板作为参考。

3. 计算位置误差  
   对每次测量比较算法位置与真值：

   ```text
   ΔX = X识别 - X真值
   ΔY = Y识别 - Y真值
   ΔZ = Z识别 - Z真值

   位置误差 = sqrt(ΔX² + ΔY² + ΔZ²)
   ```

4. 计算姿态误差  
   使用两个旋转矩阵计算夹角：

   ```text
   R_error = R真值⁻¹ × R识别
   角度误差 = acos((trace(R_error) - 1) / 2)
   ```

5. 多位置重复验证  
   至少覆盖：

   - 不同 X/Y/Z 位置
   - 正负旋转角
   - 不同俯仰角
   - 不同光照和工作距离
   - 每个位置连续采集 20～30 帧

需要分别统计：

- 绝对位置误差：识别结果与真值的差。
- 重复性：电机不动时多帧结果的波动。
- 成功率：完整识别并通过质量门的帧数占比。
- 最大误差和 95% 分位误差，不能只看平均值。
