```text
二维椭圆几何中心 ≠ 三维圆心在图像上的投影
```

你现在部分路径正是先 `fitEllipse` 得到二维中心，再把这个中心射线与端盖平面求交，[detector.py](/[REDACTED long identifier].py:1165)。这会产生系统偏差，尤其是：

- 相机斜看端盖；
- 孔位于图像边缘；
- 检测到的是倒角外圆、阴影或部分圆弧；
- 镜头畸变或 RGB—深度对齐不够准。

这很可能是绿色检测中心与粉色 CAD 点存在十几像素偏差的原因之一。

第二篇论文更适合的做法是：

1. 在 RGB 中提取每个孔的完整边缘点或可靠圆弧，而不只是一个二维中心。
2. 使用端盖孔周围的有效深度点拟合公共安装平面。
3. 将每个孔边缘像素变成相机射线。
4. 每条射线与公共端盖平面求交，获得一圈三维边缘点。
5. 在该平面内用 LM/最小二乘拟合空间圆。
6. 空间圆圆心作为真实孔位；公共平面法向作为三个孔的共同轴向。
7. 最后才用 BCD=172 mm、120° CAD 模型对三个独立圆心做刚体拟合和残差检查。

也就是：

```text
RGB圆弧 → 像素射线
                 ↘
深度端盖面 → 公共平面 → 三维圆边缘 → 空间圆心、半径、法向
                                      ↓
                              三孔CAD刚体拟合
```

对于孔朝向，第二篇的思路也比单独从椭圆长短轴计算更加稳定：

- 如果三个孔是垂直加工在端盖平面上的，孔轴就使用端盖公共平面法向。
- 不要让每个不完整椭圆分别计算一个孔轴，否则三个孔方向会因阴影和缺边发生抖动。
- 电机轴方向可以作为端盖法向的先验和一致性检查，但不宜单独作为最终孔轴，因为轴的反光、遮挡以及轴与端盖面的制造误差都会传入结果。
- 如果孔本身可能不垂直于端盖，则公共平面只能提供名义轴向，必须观察内壁、多层同心轮廓或采用多视角才能测量每个孔的独立轴线。

第一篇论文的价值主要在外围：

- 用检测/分割确定 ROI，精确位置仍交给传统几何边缘算法；
- 用 Hough 圆和 CAD 点集做对应关系、迭代配准和离群点剔除；
- 强调手眼标定、相机—电批 TCP 标定；
- 用孔与螺钉间隙定义允许的定位误差；
- 使用稳定环形光源，避免曝光变化影响孔边缘。

但它的姿态主要通过侧视相机观察物体直线边缘，并不是利用孔椭圆恢复孔轴；而且其二维 CAD 仿射配准允许缩放和剪切，可能把检测误差“拟合掉”。这部分不适合直接代替你现在的物理刚体模型。

结论是：下一步最值得做的不是继续调整三角形或把粉色 X 强制放到圆中心，而是新增“孔边缘射线—端盖平面求交—三维空间圆拟合”路径。这样可以同时得到：

- 每个孔的独立三维实测圆心；
- 三孔共同插入方向；
- 实测孔径；
- 空间圆拟合残差；
- 观测孔心与 CAD 孔心的真实残差。

第二篇报告的融合方法达到约 `0.201/0.143/0.217 mm` 的 XYZ 误差和 `0.19°` 的法向误差。你的 JL100 深度相机可以暂时代替论文中的激光位移传感器拟合公共平面，但需要先验证金属端盖有效深度的重复性、RGB—深度外参和镜头畸变。
