内参通常包含两部分：

```text
相机矩阵 K：
fx, fy  焦距（像素单位）
cx, cy  图像主点

畸变系数：
k1, k2, k3  径向畸变
p1, p2      切向畸变
```

你这台海康读取到的 RGB 参数中，例如：

```text
fx = 3109.9824
fy = 3110.5889
cx = 1593.6560
cy = 924.7585

k1 = -0.06426261
k2 =  0.09391813
p1 = -0.00079258
p2 = -0.00044727
```

处理关系是：

```text
原始畸变图像
  → 使用 K 和畸变系数进行校正
  → 去畸变图像
```

OpenCV 中可以这样处理：

```python
undistorted = cv2.undistort(
    image,
    camera_matrix,
    distortion_coefficients,
)
```

不过，位姿计算时不一定需要先生成一张去畸变图。例如 `solvePnP` 可以直接输入原始像素点，同时传入内参和畸变系数：

```python
ok, rvec, tvec = cv2.solvePnP(
    object_points,
    image_points,
    camera_matrix,
    distortion_coefficients,
)
```

OpenCV 会在几何计算内部补偿畸变。此时不能再把已经去畸变的像素点与原始畸变系数一起输入，否则会发生二次补偿。

因此在当前项目中建议：

- YOLO 检测和画面显示：可以继续使用原始 RGB 图。
- 像素点、PnP 和精确测量：传入真实内参及畸变系数。
- 如果先对整张图做了去畸变：后续必须使用对应的新相机矩阵，并把畸变系数设为零。
- 深度与 RGB 对齐：使用海康 SDK 提供的深度到 RGB 外参和标定接口，不要只靠 `cv2.undistort`。

一句话概括：内参标定是获得“如何补偿畸变”的参数；真正消除畸变发生在使用这些参数进行图像校正或几何计算的时候。
