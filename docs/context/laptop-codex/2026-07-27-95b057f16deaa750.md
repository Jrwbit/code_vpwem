核心办法是：取消“先按固定绝对深度截接线盒”的逻辑，改成“先在较大的三维工作空间里找候选平面，再以候选平面为零高度生成相对平面 ROI”。

现在的问题本质是循环依赖：

```text
需要接线盒 ROI 才能拟合平面
但接线盒倾斜后，固定深度又得不到完整 ROI
```

要打破这个循环，第一步不能再使用接线盒水平时的窄深度层。

### 1. 绝对深度只作为宽范围安全门

例如现在若按水平接线盒深度 `Z0 ± 2 mm` 取点，倾斜后肯定不完整。应改成覆盖整个工位变化的宽范围：

```text
相机可测工作区：Zmin < Z < Zmax
```

这个范围根据以下因素确定：

- 接线盒中心位置最大变化；
- 接线盒尺寸；
- 最大允许倾角；
- 电机型号高度差；
- 额外安全余量。

倾斜产生的深度跨度约为：

\[
\Delta Z = L\sin(\theta)
\]

例如接线盒沿倾斜方向长度为 `160 mm`：

- 倾斜 `10°`：深度跨度约 `27.8 mm`
- 倾斜 `20°`：约 `54.7 mm`
- 倾斜 `30°`：约 `80 mm`

如果中心深度还会变化，那么绝对深度范围需要进一步扩大。这个宽范围的目的只是排除远处背景和相机无效区，不能直接作为接线盒表面分割条件。

### 2. 从宽范围点云中直接寻找候选平面

在宽深度范围内生成点云，然后做多平面 RANSAC或法向区域生长：

```text
宽深度工作区点云
→ 降采样和离群点去除
→ 估计局部法向
→ 多次 RANSAC 提取平面
→ 根据面积、形状、尺寸和位置筛选接线盒候选平面
```

不要限制平面必须近似水平。可以只设置一个很宽的可见性限制，例如避免选择几乎与视线平行、深度数据极差的平面。

候选平面不能只按“内点最多”选择，否则容易选到地面、电机外壳或背景。建议综合评分：

- 平面面积是否接近接线盒顶面；
- 投影后的长宽是否处于型号允许范围；
- 矩形度、凸度是否合格；
- 平面中心是否位于机械臂允许工作空间；
- RGB 中是否存在对应的矩形外框；
- 平面内部是否存在四孔、端子排等几何结构；
- 法向是否处于机器人允许检测的角度范围。

如果现场背景平面很大，最好先通过空场点云或已知工装平面把背景去掉。

### 3. 建立接线盒候选平面的局部坐标系

假设 RANSAC 得到：

- 平面上一点 \(P_0\)
- 单位法向量 \(n\)

对候选点 \(P_i\) 计算相对平面高度：

\[
h_i=n^\mathsf{T}(P_i-P_0)
\]

这里的 \(h_i\) 才是应该用于分层的“深度”。它与接线盒在相机坐标系中的绝对 Z 无关，也不受接线盒倾斜影响。

例如：

```text
|h| < 2 mm       → 接线盒基准平面
2 mm < h < 15 mm → 平面上的凸起、端子或螺钉
h < -2 mm        → 孔洞、边缘或背景
```

具体正负号取决于法向定义。

只要平面找对了，接线盒水平、倾斜或者整体位置变化，表面点相对于自身平面的高度仍然接近零。

### 4. 把三维平面转成相对平面 ROI

在候选平面上建立二维坐标：

```text
Z' = 平面法向 n
X' = 平面内主方向/PCA方向
Y' = Z' × X'
```

将所有候选点投影到局部平面：

\[
x_i'=(P_i-P_0)^\mathsf{T}X'
\]

\[
y_i'=(P_i-P_0)^\mathsf{T}Y'
\]

然后在 \(X'Y'\) 平面中做：

- 连通域；
- 最小外接矩形；
- 长宽和矩形度筛选；
- 外轮廓拟合；
- 相对高度分层。

得到的是跟随接线盒倾斜的三维 ROI，而不是固定在图像或相机 Z 方向上的 ROI。最后再把这个三维矩形投影回 RGB 图，获得倾斜四边形 mask；不要只用轴对齐的 `x0,y0,x1,y1` 矩形框。

### 5. 更适合当前项目的落地流程

建议将现有无 YOLO 路线改为：

```text
宽绝对深度工作区
→ 去除固定背景/工装
→ 点云法向估计
→ 多平面 RANSAC或区域生长
→ 按物理尺寸、矩形度、位置筛选候选平面
→ 建立候选平面局部坐标
→ 计算每个点相对平面的高度
→ 在局部平面中提取完整接线盒外框
→ 投影回 RGB 做边缘精修
→ 重新使用精修 ROI 拟合平面
→ 迭代一次
→ 输出中心、法向和面内方向
```

第一次平面只是粗平面；获得完整 ROI 后再拟合一次精平面，稳定性会更好。

### 6. 两种可选的启动方式

纯深度启动适合深度质量好、接线盒平面明显的场景：

```text
宽点云 → 多平面 → 尺寸筛选 → 相对平面 ROI
```

RGB 几何启动适合背景平面多、接线盒外框清楚的场景：

```text
RGB 线段/四边形候选
→ 候选四边形内部取宽范围深度点
→ RANSAC 拟合任意倾角平面
→ 相对平面分层
```

第二种仍然不依赖 YOLO，只使用传统的边缘、直线和四边形检测，通常更容易避免把电机主体或工装平面选成接线盒。

最终要取消的是当前这种逻辑：

```text
abs(depth - 水平标定深度) < 固定阈值
```

改成：

```text
绝对深度：只做宽工作空间限制
相对深度：point-to-plane distance 做精确表面分割
```

这样接线盒位置变化由候选平面中心解决，姿态变化由候选平面法向和局部坐标系解决。唯一仍然不能仅靠矩形平面解决的是绕法向的 `180°` 物理方向歧义，需要接地螺丝、二维码、工装方向或其他非对称特征消歧。
