# CAD / 点云配准流程

这套流程用于有 CAD/STL 模型的盖板位姿检测：先把 CAD 模型采样成点云，再和 RGB-D 实测点云配准，最后输出盖板整体 6D 位姿和 CAD 8 个孔中心在相机坐标系下的位置。

本目录是独立流程，不 import 项目根目录下的旧脚本。默认模型资源、配置、运行入口和输出目录都在 `cad_pose_pipeline/` 内。

```text
CAD/STL 模型
```
