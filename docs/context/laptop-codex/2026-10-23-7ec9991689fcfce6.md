1. **GMP — Gated Memory Policy: In-Context Memorization and Adaptation**，arXiv:2604.18933v2，2026-08-03。以 Transformer Diffusion Policy 为基础，把历史图像摘要和历史动作存入缓存，由独立 cross-attention 读取，再通过二值门控残差接入动作网络。门控不是直接端到端学：先训练有／无记忆策略，在验证集比较动作误差生成“何时需要记忆”的标签，最后固定门控重训策略；历史动作还按扩散步加噪。同文真实投掷任务为 95%，长历史 DP 为 20%，No-History 为 5%；但 Tool Hang 为 79%，仍低于 No-History 的 82%，支持“需要时读取、其他时候保住基础能力”，并非记忆总能涨点。代码已公开。

2. **MDP — Memory-gated Diffusion Policy: Advancing Robotic Behaviour Learning with Memory-oriented Architectures**，Knowledge-Based Systems 325，2025，DOI:10.1016/j.knosys.2025.113738。这篇确实研究扩散动作策略的记忆增强：memory-driven VAE 关联当前观测与历史状态，memory-gated Mamba 传播相关状态，memory-gated attention 筛选与当前决策有关的历史，再结合 DDIM 加速采样。公开引言列出 Block-Push、Push-T、Franka Kitchen 和真实抓放／抽屉实验，但全文受限，无法核验具体成功率、消融以及训练配方，也未核实官方源码。因此适合纳入扩散记忆相关工作，不宜作为当前首选复现对象，更不能补写未经核验的分数或声称直接插入官方 DP 某层。
