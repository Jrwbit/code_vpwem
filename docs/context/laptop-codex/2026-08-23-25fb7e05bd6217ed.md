## 二、现在卡住自动打螺丝的关键问题

程序目前明确保持 `robot_ready=false`，主要不是识别算法问题，而是以下生产条件还没冻结：

1. 锁付工艺

2. 工具方案  
   需要确定用套筒还是批头、螺栓如何供料、弹簧垫圈如何装、有没有浮动或柔顺机构。

3. 三孔编号和锁付顺序  
   三孔是 120° 对称的，目前 H01 的绝对方向没有经过现场工装确认。还要确定顺序锁还是分级交叉锁。

4. 下层螺纹孔是否同心  
   视觉当前看到的是端盖 Ø10 通孔，尚未证明通孔与下面机座螺纹孔完全对准。端盖略微错位时，批头可能仍会卡住。

5. 端盖是否落座  
   当前只能测端盖自身平面，缺机座法兰或工装参考面，不能可靠判断端盖翘起和高度异常。

## 三、有几种方案

### 方案 A：固定 RGB-D 相机一次定位全部三孔

### 方案 B：固定相机定位 + 深度/几何校验

它不是完全独立的锁付方案，更适合作为方案 A 的质量门。

- 用 BCD、三边一致性、安装面和平面残差校验孔位；

这部分当前也已经接入。单独依赖深度找孔不可靠，因为黑色孔内部容易没有有效深度。

### 方案 C：固定相机粗定位 + 末端相机逐孔精定位

当方案 A 的端到端误差不能满足入孔时使用。

- 固定相机负责识别电机和粗定位；
- 机器人到每个孔上方；
- 末端小视野相机再次修正 XY 和角度；
- 再由批头入孔。

精度潜力最高，但增加末端相机、光源、二次手眼标定、遮挡处理和节拍，建议确认固定相机确实不够后再上。

## 视觉上有三种方案

### 方案一：直接看见通孔和下层螺纹孔

在同一个通孔 ROI 内分别识别：

- 外层端盖通孔孔口；
- 内部或孔底的螺纹孔孔口；
- 两个圆或椭圆的中心。

然后计算安装平面内的中心偏差：

```text
offset_xy = threaded_hole_center - cover_hole_center
```

优点：

- 对齐结果最直接；
- 不依赖机座与端盖的理论装配关系；
- 可以逐孔判断。

难点：

- 通孔内部暗；
- 下层孔可能被端盖孔壁遮挡；
- 螺纹、高光和无效深度容易产生伪边缘；
- 视角倾斜时可能只能看到部分圆弧。

这是最值得优先验证的方案。先采集近距离、加强同轴照明的孔内图片，确认下层螺纹孔是否实际可见。

### 方案二：通过端盖和机座基准间接判断

分别估计：

- 端盖位姿；
- 电机机座、法兰或稳定加工基准的位姿；
- 根据图纸获得机座螺纹孔相对基准的理论位置。

将理论螺纹孔投影到当前相机画面，与实测端盖通孔比较。

优点：

- 即使下层螺纹孔看不见也可以判断；
- 可以同时判断端盖平移、旋转和翘起；
- 适合固定工装和受控型号。

限制：

- 依赖准确图纸、加工公差和基准标定；
- 机座参考特征必须稳定可见；
- 得到的是间接对齐结果，不能发现单个螺纹孔加工偏差。

### 方案三：多视角或近距离二次观测

固定相机先定位端盖和三个通孔，再通过移动相机、末端相机或小视野相机从接近孔轴的方向观察孔内。

优点：

- 能减小孔壁遮挡；
- 下层螺纹孔的圆弧更完整；
- 单孔中心和轴线精度潜力最高。

限制：

- 需要额外运动和标定；
- 节拍更长；
- 系统复杂度更高。
