你现在先按这个顺序处理：

1. 退出当前所有 Python / 上位机程序
2. 去示教器里检查并关闭会占用输入寄存器的 fieldbus
3. 如果有别的程序在连机器人，先断掉
4. 必要时重启机器人控制器，再重新开 Python

然后再试：

```python
import rtde_control
robot_ip = "192.168.10.12"
rtde_c = rtde_control.RTDEControlInterface(robot_ip)
```

如果这一步还超时，那就不是点位问题，而是机器人控制器端还在占用 RTDE。

你现在这件事的结论很明确：

- 不是 `moveL` 坐标问题
- 不是四个点的问题
- 是 **RTDE 通道没空出来**
