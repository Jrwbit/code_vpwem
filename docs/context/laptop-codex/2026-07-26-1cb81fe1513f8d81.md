### 不同型号、不同高度怎么定位中心

正确做法是不写死绝对深度，而是采用“分型号几何 + PnP + 自适应深度”：

```text
型号/二维码
→ 选择对应 YOLO 权重和四孔物理尺寸
→ 检出接线盒及四个角孔
→ 四孔 PnP 计算中心、距离和姿态
→ ROI 内自动选择深度主峰/拟合平面
→ 用深度验证或修正 PnP
→ 转换到机器人基坐标
```

电机高度改变时：

- PnP 会从四孔在图像中的尺度自动计算距离，不需要固定电机高度；
- 当前 `peak-band` 会在每帧 ROI 内自动寻找深度主峰，也没有写死绝对 Z；
- 不同型号需要保存各自的孔距、接线盒中心偏移和方向定义；
- 如果深度暂时不稳定，可以增加“四孔齐全时 PnP-only 降级模式”，但必须通过重投影误差和方向检查，不能仅用 YOLO 框中心作为机器人三维坐标。
