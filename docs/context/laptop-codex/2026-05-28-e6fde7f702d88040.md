**PnP 还是 ROI**

如果四角圆孔在真实物体上的尺寸坐标已知，比如四个角点在接线盒坐标系里是：

```text

( L/2, -W/2, 0)
( L/2,  W/2, 0)

```

那么可以用 RGB 里的四个圆心做 `solvePnP`。这会直接得到接线盒相对相机的 6D 位姿。

**我会做的版本**

我建议不要一开始就做复杂分割模型，先做传统视觉版：

```text
1. 用颜色/深度范围提取接线盒外壳区域
2. 找最大轮廓，得到接线盒大致 ROI
3. 在 ROI 内找四个圆形角孔

7. 后续自动根据 box 位姿推算接线柱
```

**关键风险**

有几个地方要注意：

- 四角圆孔必须能稳定检测，否则后续接线柱位置会整体偏。
- 四个角点要有固定排序，不能帧间乱序。
- 如果接线盒接近正方形，PnP 可能有 90 度方向歧义，需要用某个明显特征破除，比如文字、缺口、黑色底板方向，或者规定上边两个孔。

```python
def detect_box_and_terminals():
    color = read_image("color_aligned.png")
    intrinsics = read_json("camera_intrinsics.json")
    calib = read_json("box_terminal_calibration.json")

    # 1. 分割接线盒外壳
    hsv = cvtColor(color, BGR2HSV)
    mask = inRange(hsv, HSV_LOWER, HSV_UPPER)
    mask = morphology_close(mask)
    mask = morphology_open(mask)

    contours = findContours(mask)
    box_contour = largest_contour(contours)

    # 2. 得到接线盒外框模板
    rect = minAreaRect(box_contour)
    rect_corners = boxPoints(rect)
    rect_corners = sort_as_TL_TR_BR_BL(rect_corners)

    # 3. 在ROI里找圆
    roi = boundingRect(box_contour) + margin
    gray_roi = grayscale(color[roi])

    hough_candidates = HoughCircles(gray_roi)
    contour_candidates = circular_contours(gray_roi)
    candidates = dedupe(hough_candidates + contour_candidates)

    # 4. 每个模板角匹配一个圆
    final_corners = []

    for template_corner in rect_corners:
        best = None

        for cand in candidates:
            cand_global = roi_offset + cand.center

            # 候选不能明显跑到蓝色框外侧
            signed_dist = pointPolygonTest(rect_corners, cand_global)

            if signed_dist < -CORNER_INSIDE_MARGIN_PX:
                continue

            dist_to_corner = norm(cand_global - template_corner)

            if dist_to_corner <= CORNER_STRICT_MAX_DIST_PX:
                best = cand_global with smallest distance

        if best is not None:
            final_corners.append(best)
        else:
            # 当前默认策略：用蓝色框模板角
            final_corners.append(template_corner)

    final_corners = sort_as_TL_TR_BR_BL(final_corners)

    # 5. solvePnP
    object_points = [
        [-W/2, -H/2, 0],
        [ W/2, -H/2, 0],
        [ W/2,  H/2, 0],
        [-W/2,  H/2, 0],
    ]

    image_points = final_corners

    rvec, tvec = solvePnP(
        object_points,
        image_points,
        camera_matrix,
    )

    # 6. 根据标定表恢复接线柱
    terminals_box = calib["terminals_box_frame"]

    terminals_camera = []
    terminals_pixels = []

    R = Rodrigues(rvec)

    for p_box in terminals_box:
        p_cam = R @ p_box + tvec
        pixel = project(p_cam, intrinsics)

        terminals_camera.append(p_cam)
        terminals_pixels.append(pixel)

    save_result(terminals_camera, terminals_pixels)
```

**当前算法弱点**

1. 颜色分割依赖外壳颜色和光照。
2. `minAreaRect` 只能给一个近似外框，不一定是四个真实圆心。
3. 外角圆孔有时太小/模糊，Hough 检不出来。
4. 内部螺丝/接线柱反光会产生很多圆形干扰。
5. 用模板角回退虽然比选错内部点稳定，但它不是实际圆心，会带来 PnP 误差。
6. 如果四角圆心和外壳矩形角之间有固定偏移，当前没有建模这个偏移。

**更好的改法建议**

最值得改的是第 6 点：不要把 `minAreaRect` 的四个角直接当圆心模板。应该建立“外壳矩形角 -> 四个圆心”的固定偏移模板。

也就是：

```text
先手点一次4个真实圆心
同时记录自动检测到的蓝色外框 rect
计算每个圆心相对 rect 坐标的位置
后续检测到新 rect 后，用这个相对位置直接预测4个圆心
再在预测点附近小范围找圆
找不到就用预测点
```

这个会比现在“直接找最近圆”稳很多。
