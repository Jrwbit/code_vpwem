- 必要时使用偏振片压制金属反光；

可以利用直射光增强判断，但“亮不亮、是否透光”本身仍不能证明对齐。更合适的是用光把上下两层孔口的边界显现出来，再计算中心偏差。

分两种情况：

### 下层电机孔能从背面透光

如果光源能放到电机孔后方，而且整个孔是贯通的，那么背光是最理想的：

- 对齐时，亮区接近完整圆形；
- 轻微偏移时，亮区变成偏心月牙或被单侧遮挡；
- 大幅偏移但仍相通，仍可能出现亮区，但形状和有效通径会明显缩小。

算法不能只判断“有光/无光”，而应测量：

```text
亮区轮廓
亮区重心
最小有效通径
亮区相对端盖孔中心的偏移
```

不过实际电机螺纹孔通常不是方便背光的贯通孔，所以这种方案可能受到结构限制。

### 下层是盲螺纹孔

这种情况下背光无法使用，可以从相机一侧设置“同轴直射光”：

```text
相机
  ↓
同轴准直光
  ↓
端盖 Ø10 通孔
  ↓
电机螺纹孔入口
```

光线进入孔内后，上下孔偏心会产生方向明确的遮挡和阴影：

- 对齐：内孔口轮廓相对对称；
- 向右偏：左、右两侧的遮挡和反射不对称；
- 轻微偏移：出现单侧月牙形边缘；
- 大幅偏移：内层圆弧明显偏离，但仍可能有局部亮区。

建议不要只安装一盏普通射灯，而采用：

- 相机光轴附近的窄角度同轴光；
- 四方向分区环形灯，分别点亮上、下、左、右；
- 固定曝光和增益；
- 光源、镜头加交叉偏振片，压制金属端盖反光；
- 必要时再增加一组低角度暗场光，突出孔口边缘。

四方向依次点亮后，可以通过阴影方向反推出偏移方向，比单盏直射灯稳定很多。

第一版可以低成本搭建：

```text

+ 同轴光或小角度环形灯

+ 偏振片
```

3. 左右方向光图像；
4. 当前普通环境光图像。

然后观察能否稳定拟合：

- 端盖孔外圆中心；
- 下层螺纹孔入口的完整或部分圆弧；
- 两中心偏差；
- 最小剩余通径。

最终判据应是类似：

```text
center_offset_mm <= 工艺允许偏差
min_effective_diameter_mm >= 螺钉外径 + 综合安全余量
inner_arc_coverage >= 最小可观测比例
```

