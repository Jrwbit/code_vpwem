## My request for Codex:
为什么红外能照射到接线盒内部，但深度图里没有

## assistant — 2026-06-14T09:17:44.585Z

因为“红外能看到散斑”不等于“深度算法能解出深度”。

你这张图里，问题很典型：红外散斑确实打进了接线盒内部，但深度图仍然缺失，主要原因通常是下面几个：

1. **深度需要匹配，不只是照亮**
   Orbbec 这类结构光/双目深度相机需要在左右红外图之间找到同一个散斑/纹理的位置差，也就是视差。
   你看到左/右红外都有光点，但接线盒内部有很多遮挡、凹槽、端子、线缆和高反光金属，左右红外相机看到的内容不一致，匹配失败就输出 0 深度。

2. **接线盒是凹进去的，存在视角遮挡**
   RGB 相机从上方能看到内部，但深度相机的左右红外视角不是同一个位置。盒壁、端子边缘、线缆会挡住其中一个红外相机的视线。
   只要左眼能看到、右眼看不到，或者投影器照到了但其中一个接收相机看不到，就没法三角测量。

3. **白色/金属端子和螺丝过曝**
   你的红外图里接线端子中心区域非常亮，已经接近过曝。过曝区域细节丢失，散斑形状糊在一起，算法无法可靠匹配，所以深度图会挖空。

4. **黑色线缆、暗色内壁吸收红外**
   黑线、阴影、深色材料在红外下反射弱，散斑虽然在周围能看到，但线缆本体/边缘可能信号不足，也会深度无效。

5. **细小结构小于深度算法的稳定尺度**
   接线柱、螺丝、线头边缘都很细，深度算法需要一个局部窗口做匹配。窗口里混了前景/背景/空洞/反光，结果常常被判为无效。

所以结论可以这样跟领导说：

> 红外图只能证明投射光进入了接线盒，但深度图需要双目/结构光匹配成功才能生成。接线盒内部存在遮挡、反光、过曝、黑色线缆和细小结构，导致红外匹配失败，因此深度图在关键目标区域没有有效深度，RGB-D 反投影方案不可用。

你可以尝试验证几个方向，但不一定能根治：

```text
1. 降低 IR projector / laser power，避免中心白色端子过曝
2. 调整相机角度，让左右红外都能看到接线盒内部
3. 增大距离，减少近距离遮挡和过曝
4. 关掉/调低环境强光
5. 换成 RGB 单目 PnP / YOLO 五点检测方案，不依赖深度
```

从你这张 Viewer 截图看，最关键的问题不是“有没有红外照明”，而是“接线盒内部的红外匹配不稳定/失败”。
