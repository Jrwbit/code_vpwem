你刚才机器报 `No CUDA GPUs are available`，所以如果当前终端没有 GPU，就用 CPU 会非常慢。你在有 CUDA 的环境里重新跑原命令即可：

```bash
cd /home/wjr/diffusion_policy

[REDACTED long identifier] \
/[REDACTED long identifier] -m dp_eval.cli \
  --checkpoint /[REDACTED long identifier].00145.ckpt \
  --dataset-path /[REDACTED long identifier].zarr \
  --output-dir /[REDACTED long identifier] \
  --device cuda:0 \
  --split val \
  --num-workers 0 \
  --num-batches 8 \
  --num-samples 8 \
  --start-index 0 \
  --num-episodes 4 \
  --start-episode 0 \
  --max-steps 200 \
  --fps 8 \
  --arm-ymin -3.2 \
  --arm-ymax 3.2 \
  --grip-ymin 0 \
  --grip-ymax 1 \
  --pass-threshold 0.05
```

如果还是在这台没有 CUDA 的环境，只能改成：

```bash
--device cpu
```
