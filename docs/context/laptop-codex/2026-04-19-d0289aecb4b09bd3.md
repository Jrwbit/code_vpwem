| sampler 不跨 episode | `SequenceSampler` 只能在 `episode_ends` 内采样 | 必须成立 |

**训练层**
| 核对项 | 要检查什么 | 当前标准 |
| --- | --- | --- |
| normalizer 正确 | `joint_state/action` 用 grouped normalizer；image 用 image normalizer | 必须和训练一致 |
| horizon 设置合理 | 当前配置：`horizon=16`，`n_obs_steps=2`，`n_action_steps=8` | 以 ckpt 配置为准 |
| 小数据可过拟合 | 小样本训练应明显下降并能复现动作趋势 | 建议实测 |
| train/val 行为一致 | train/val 都走同一 dataset 语义，只是 episode mask 不同 | 必须一致 |
| checkpoint 保存完整 | 当前部署会重新从 `dataset_path` 构建 dataset 和 normalizer | 这项不能简单打勾，依赖部署时传入正确 dataset_path |

**离线验证层**
| 核对项 | 要检查什么 | 当前标准 |
| --- | --- | --- |
| GT vs Pred action 可视化 | 比较 `action` 与预测 action 序列 | 必须做 |
| rollout 合理 | pseudo rollout 中动作量级、方向、时序合理 | 必须做 |
| gripper 时序正确 | 第 7/15 维与图像事件对得上 | 必须做 |
| 输出量级正确 | 关节输出不能远超训练分布；gripper 不能异常饱和 | 必须做 |
| label 偏移正确 | 验证 `action[t]` 更接近 `joint_state[t+k]` 的哪个 `k` | 必须实测确认 |

| 核对项 | 要检查什么 | 当前标准 |
| --- | --- | --- |
| observation key/shape/range 一致 | `camera_0/camera_1/joint_state`，shape/range 与训练一致 | 必须一致 |

**你这条 `run_rm75_dp_realtime.py` 命令下，最该优先确认的 6 项**
1. `camera_0-color-order rgb` 和 `camera_1-color-order bgr` 是否真的对应训练数据口径，否则图像分布直接错。
2. `dataset-path` 是否就是训练这个 `latest4.11.ckpt` 时所用的同一份 `replay_buffer.zarr`，否则 normalizer 会漂。
3. `action` 是否仍然是 future joint target，而不是你后续某次转换里混成 delta。
4. 在线 `target-hz=6` 是否与离线数据采样频率一致，或至少足够接近。
5. safety gate 是否只是保护，而不是把大部分输出都拒掉或截断。
6. gripper 第 7/15 维的物理含义是否和真实手爪命令一致，不是“看起来能动但语义错”。
