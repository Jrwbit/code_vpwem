## assistant — 2026-05-07T14:07:04.388Z

不是“选一次作为基准，然后剩下的都跟它做差”。

你这个 `repeatability_summary.csv` 里的误差是这样算的：

对每个孔，比如孔 1，连续跑 N 次后会得到 N 个三维坐标：

```text
第1次: x1, y1, z1
第2次: x2, y2, z2
...
第N次: xN, yN, zN
```

脚本先算这 N 次的平均值：

```text
mean_x, mean_y, mean_z
```

然后算每个方向相对平均值的标准差：

```text
std_x = x 的标准差
std_y = y 的标准差
std_z = z 的标准差
```

再合成：

```text
std_xy = sqrt(std_x^2 + std_y^2)
std_3d = sqrt(std_x^2 + std_y^2 + std_z^2)
```

所以它表示的是：**同一个静止孔位，系统多次识别出来的位置会抖动多少。**

你问“机械臂运动到这个点会差多少”，要分清两种误差：

1. **相机识别重复误差**
   你这次稳定 8 次结果大概是：
   ```text
   XY 平面重复误差 std_xy ≈ 0.35 mm
   XYZ 三维重复误差 std_3d ≈ 1.38 mm
   Z 方向 std_z ≈ 1.33 mm
   ```

2. **机械臂最终到点误差**
   机械臂实际会差多少不是只看相机，还要叠加：
   ```text
   相机识别误差
   手眼标定误差
   机器人本体重复定位误差
   夹具/末端安装误差
   TCP 标定误差
   深度方向接触/表面误差
   ```

如果你只问“这个视觉点本身传给机械臂会抖多少”，那就是：
