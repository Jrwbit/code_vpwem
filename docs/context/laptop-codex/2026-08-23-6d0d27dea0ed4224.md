## 1. 配方硬门限分别是什么意思

| 项目 | 实际含义 | 需要注意 |
| --- | --- | --- |
| 相机保留深度 250–1100 mm | 深度小于250 mm或大于1100 mm的像素先当成无效点，不参加计算 | 只是数据过滤窗口，不代表250–1100 mm都能识别 |
| 三孔最小直径 ≥16 px | 三个孔在RGB图像中的直径都必须至少有16个像素 | 距离太远、倾斜、遮挡或反光使孔变小时会失败；这是图像分辨率要求，不是孔的实际物理尺寸 |
| 三孔弦长CV ≤0.12 | 计算三个孔中心两两之间的三条边，检查它们是否接近等长 | CV是“三条边长度的标准差÷平均值”；越小越接近120°均布三孔。它检查形状，不检查实际尺寸 |
| BCD误差 ≤2 mm | 三孔所在螺栓分布圆的理论直径是172 mm，测量结果只能在170–174 mm之间 | CV通过说明“像等边三角形”，BCD通过才说明“大小也对” |
| 平面最少内点 ≥500 | 拟合端盖安装面后，至少要有500个深度点支持这个平面 | 防止仅靠少量偶然点计算法向 |
| 平面内点比例 ≥0.55 | 参与拟合的深度点中，至少55%必须与最终平面一致 | 太低说明区域里可能混入孔内壁、鳍片、台阶、背景或错误端盖区域 |
| 全端盖面RMSE ≤0.5 mm | 使用较大端盖表面拟合平面时，内点到平面的均方根距离不能超过0.5 mm | 数值越小，平面越平整、深度越一致 |
| 三孔安装支撑面RMSE ≤2.0 mm | 当全端盖方法失败、改用三个孔周围的环形支撑区域拟合时，允许RMSE到2 mm | 这是回退路线，采样区域小且分散，所以门限较宽；两项RMSE通常根据检测路线二选一，不是要求同一帧同时满足两个上限 |
| 相机绝对倾角 ≤15° | 安装面法向与相机光轴之间的夹角不能超过15° | 这是“相对相机的倾角”，不等于端盖相对电机、工作台或工装的真实装配倾斜 |

三孔的关系可以这样理解：

- 理论BCD：172 mm。
- 三孔相隔120°时，每条弦长约为 `172 × sin(60°) = 148.96 mm`。
- CV检查三条弦是否差不多长。
- BCD检查这组三孔是不是正确的实际大小。

因此，CV和BCD不能相互替代。一个很小的等边三角形也可能CV很好，但BCD明显错误。

另外，RMSE只反映“这些点像不像一个平面”，并不直接代表孔中心绝对误差。例如拟合到了错误台阶，它仍可能得到很漂亮的RMSE。

## 2. 110帧经验边界是什么意思

### “稳定区集中在718–726 mm、3.8–9.0°”

只有4个姿态做到了连续5帧全部通过，即5/5。这说明当前算法在这些具体姿态附近具备重复性。

但不能把它扩大解释成：

> 所有718–726 mm、3.8–9.0°的位置都稳定。

因为这4个姿态没有覆盖不同水平位置、垂直位置、端盖绕法向旋转、曝光和反光组合。

### “单帧通过覆盖562–729 mm、3.61–12.27°”

说明这个更大范围内曾经有个别帧成功，但部分姿态只有2/5、3/5或4/5。

这种状态可以用于算法调试，不能用于机器人自动运行，因为同一位置连续拍摄仍可能随机失败。

### “超过15°会按设计失败”

本批次18–22°的帧触发了倾角门限，程序按规则拒绝。这说明安全门确实生效。

它不表示相机硬件超过15°就看不见，也不表示算法技术上绝对无法扩展。若工艺允许更大倾角，可以重新设计和验收，但不能直接把15°改成更大来提高通过率。

### “低于15°也不保证通过”

倾角只是最后一道门。前面还有：

- 端盖ROI是否选对；
- 三个孔是否都进入预测区域；
- 端盖绕法向旋转是否覆盖；
- 高光是否把暗孔破坏；
- 是否把中央轴、孔内壁或其他圆形结构选成孔；
- 深度平面是否混入其他结构。

所以即使端盖几乎正对相机，也可能在候选检测阶段0/5。

### “不能给出真实距离和真实角度极限”

本次没有同步记录量具、编码器、机器人或高精度姿态仪的真值。报告里的“562 mm”“12°”都是当前视觉算法自己的估计。

它们可以用于比较成功帧和失败帧，但不能用来证明：

- 真实距离误差是多少；
- 真正俯仰/偏航到了多少度；
- 水平、垂直能移动多少毫米；
- 输出位姿的绝对精度是否满足锁付。

此外，5/5只能证明重复通过，不能证明绝对坐标正确。

## 3. 当前并不只有一种方案

这份110帧报告只验收了一条主算法链，但链内已经包含两个候选子路线：

1. 深度端盖ROI＋120°孔位预测＋RGB暗孔精修。
2. 第一条失败后，全端盖深度空洞搜索＋RGB外孔椭圆精修。

它们共享后面的三孔几何、BCD、平面、倾角和质量门，所以仍可视为同一个RGB-D几何方案的两种候选生成方式，不代表只能这样做。

可选技术路线如下。

| 方案 | 优点 | 主要代价 |
| --- | --- | --- |
| 改进当前RGB-D几何方案 | 不增加硬件、可解释、已有代码和数据基础 | 需要重做ROI、多假设候选和局部平面，仍受金属反光影响 |
| 孔关键点/分割模型＋深度平面 | 对位置变化、端盖旋转、亮度变化通常比暗孔阈值稳定 | 需要标注不同距离、角度、反光下的训练数据 |
| RGB关键点＋PnP，再与深度交叉校验 | 可以产生独立的位姿估计，两路不一致就拒绝 | 必须解决三孔120°旋转歧义，并标定相机 |
| CAD点云配准 | 可以利用整个端盖三维形状，不完全依赖三个孔 | 深度缺失、高光、鳍片和初值会影响配准，速度也更慢 |
| 固定治具＋非对称基准 | 工业稳定性最高，可解决三孔120°编号歧义 | 需要改造工位；基准必须与工件装夹关系可靠 |
| 多视角/相机移动后复拍 | 可绕开单视角反光、孔遮挡和深度空洞 | 增加节拍，并需要精确的多视角外参 |
| 更换结构光或激光轮廓硬件 | 金属表面三维质量有机会明显提高 | 成本、安装空间和重新标定工作较大 |

## 4. 我更推荐的实施路线

如果要求“不增加现场硬件”，我建议把现有方案升级为：

```text
整端盖检测或分割
→ 同时保留多个中心、旋转和三孔候选
→ RGB孔关键点/椭圆精修
→ 三个孔分别拟合局部环形支撑面
→ RGB-PnP与RGB-D平面位姿双路计算
→ BCD、重投影误差、局部平面一致性联合裁决
→ 连续多帧一致后才输出
```

这比简单放宽CV、RMSE或15°门限更可靠。当前32帧候选失败的主要问题发生在质量门之前，单纯改门限救不回来。

如果允许小幅改造工位，最稳妥的是：

- 固定相机和电机装夹范围；
- 增加漫反射、偏振照明；
- 在治具上增加非对称方向基准；
- 视觉仍直接检测三孔；
- 用治具基准进行方向消歧和结果交叉检查。

最后，无论选哪条路线，下一轮都应记录外部真值，并按“距离×水平位置×垂直位置×俯仰×偏航×端盖旋转×光照”建立测试矩阵。否则只能知道算法是否重复通过，仍不能得到真正可承诺的工作包络和绝对位姿精度。
