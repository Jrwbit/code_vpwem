## assistant — 2026-06-17T08:26:36.395Z

基本可以一直用，但有几个前提：

1. **Token 本身没有过期**
   有些平台创建个人访问令牌时会设置有效期。如果你设置了 30 天、90 天，到期后就不能用了。想长期用，要创建“不设置过期时间”或有效期尽量长的 token。

2. **Token 没有被你手动撤销**
   如果你在 GitCode 设置里删除/禁用了这个 token，本地保存的凭据就失效。

3. **账号仍有仓库权限**
   如果仓库权限被移除，即使 token 还在，也不能 clone/pull/push。

4. **本地 `~/.git-credentials` 没被删除**
   `credential.helper store` 会把凭据明文保存到本地这个文件里。文件存在就会自动使用。

所以：如果 token 不过期、不撤销、权限不变，本地文件不删，它就可以长期自动使用。  
注意这个方式是**明文保存 token**，只建议在自己的电脑上用。
