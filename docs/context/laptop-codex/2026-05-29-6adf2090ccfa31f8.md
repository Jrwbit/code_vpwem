  0 top_left_terminal
  1 top_mid_terminal
  2 top_right_terminal
  3 bottom_left_terminal

  5 bottom_right_terminal
  6 ground_screw

A. 自动检测接线盒 ROI

用户先点击接线盒四个角点，顺序：
top_left
top_right
bottom_right
bottom_left

y_norm = y / warped_height

  "warped_size": [800, 600]

load_teach_points(path)

window_size = config["terminal_grid"]["window_size"]

- 在窗口中找圆/椭圆

- predicted_center：示教预测位置
- refined_center：局部精定位位置
- valid
- score

格式：

{
  "id": "terminal_0",
