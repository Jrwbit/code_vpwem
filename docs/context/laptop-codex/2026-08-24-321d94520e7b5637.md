## 如何确保端盖三个孔识别准确

建议采用“逐孔语义检测＋组级末级校验＋时序确认”。

### 第一级：独立识别每个真实外孔口

每个孔必须单独满足：

- 检测到闭合外孔口椭圆；
- 圆周有效边缘覆盖率建议≥85%；
- 椭圆拟合残差经过标注数据验收；
- 孔口内外灰度梯度方向正确；
- 孔外存在连续端盖支撑面；
- 孔内相对孔外存在深度空洞或明显深度突变；
- 暗区中心、椭圆中心和边缘梯度中心不能相差过大；
- 高光覆盖严重、边缘缺失或出现多个等价内圆时直接拒绝。

重点是检测“外孔口边界”，而不是检测“孔里的黑色部分”。

### 第二级：RGB与深度联合求三维孔中心

- RGB确定外孔口像素中心。
- 深度只用于拟合端盖公共平面。
- 孔中心像素射线与端盖平面求交，得到三维孔口中心。
- 分别拟合三个孔附近的局部平面，并检查三个法向、高度是否一致。
- 不使用孔内无效深度计算孔中心。

### 第三级：图纸几何只能作拒绝门

JL100三孔应满足：

- BCD接近172 mm；
- 三孔相隔约120°；
- 三边长度一致；
- 孔径接近Ø10。

但这些条件只能用于拒绝错误结果，不能用于从大量候选中“拼出”三个孔。否则会再次出现三个错误边缘恰好组成Ø172/120°的情况。

### 第四级：连续帧稳定性

建议至少连续采集5帧，要求：

- 5帧全部通过；
- 每个孔通过跨帧匹配保持同一语义；
- 孔中心最大三维漂移控制在验收阈值内；
- 孔径、椭圆长短轴和边缘覆盖率稳定；
- 公共法向变化稳定；
- 任一孔发生候选跳变，整组拒绝。

真正进入生产前，应使用人工标注或量具真值确定具体阈值，不能仅靠算法内部重复性。

## 如何判断端盖孔与机座孔对齐

### 推荐主方案：装盖前后使用同一机座坐标系

装盖前：

1. 电机固定在不可移动的工装上。
2. 直接识别三个机座M8螺纹孔口。
3. 拟合每个机座孔中心和公共轴向。
4. 使用电机轴线＋固定治具上的非对称基准建立电机坐标系。
5. 保存三个机座孔在该坐标系中的坐标和不确定度。

装盖后：

1. 识别三个端盖Ø10真实孔口。
2. 拟合端盖平面和通孔插入方向。
3. 将端盖孔轴线传播到机座螺纹孔入口平面。
4. 对每一孔计算横向偏差：

```text
e_i = ‖端盖孔轴在螺纹孔平面的交点 - 机座螺纹孔中心‖
```

5. 计算轴线夹角：

```text
θ_i = angle(端盖孔轴, 机座螺纹孔轴)
```

必须比较三个独立对应孔，不能只比较两个孔组的中心或BCD。

如果拆装过程会移动电机，就必须增加一个永久可见的非对称标志，例如：

- 工装上的AprilTag/圆点靶标；
- 与机座刚性连接的定位销或加工基准；
- 电机底脚和轴线组成的已标定坐标系。

只有电机轴线还不够，因为三孔存在120°旋转对称性。

### 装盖后直接看第二层孔：只作为辅助验证

可以增加同轴环形光、偏振片和多曝光，让相机透过Ø10端盖孔观察M8孔口。如果每个位置都能看到完整的第二层闭合椭圆，可以直接比较：

```text
外层：端盖Ø10孔口
内层：机座M8孔口
```

但根据现有图片，三个孔的第二层可见性不稳定，而且深度缺失，所以目前不适合作为唯一放行依据。

| 端盖孔 | 三个真实外孔口逐孔独立验证通过 |
| 时序 | 连续至少5帧全部通过，无单孔跳变 |
| 机座孔 | 来自装盖前直接观测、独立标定或可靠第二层直接观测 |
| 坐标系 | 非对称电机/工装基准有效，三孔编号无120°歧义 |
| 对正 | 三孔逐孔偏心及轴线夹角均小于工艺阈值 |
| 不确定度 | 偏差上限加测量不确定度仍小于安全余量 |
| 端盖落座 | 无明显翘起，端盖相对机座基准的高度和倾角合格 |
| 机器人 | 手眼、TCP、批头长度、工作空间与路径验证有效 |
| 工艺 | 扭矩、转速、旋入深度、转角和异常停止门限已确认 |
| 物理确认 | 对孔探针通过，或柔顺低速起拧未出现异常 |

偏心允许值不能直接固定为1 mm。应按下式计算：

```text
允许视觉偏心
= (端盖通孔最小直径 - 螺栓最大外径) / 2
  - 视觉P95误差
  - 手眼误差
  - 机器人误差
  - 批头同轴误差
  - 安全余量
```

对于Ø10通孔和M8螺栓，理论径向间隙约1 mm，但所有误差都要从这1 mm里扣除。最终视觉偏心门限很可能要控制在0.3～0.5 mm量级，不过必须通过实际公差和探针试验确定，不能直接把这个建议值写成生产标准。

## 什么时候绝对不允许打螺丝

出现以下任一情况都必须保持 `robot_ready=false`：

- 任一端盖孔没有完整真实外孔口证据；
- 候选主要靠Ø172/120°组合评分选出；
- 任一孔存在两个以上等价内外圆，语义不明确；
- 孔内高光、阴影或深度空洞导致中心不确定；
- 只测到了端盖孔，没有独立机座孔位置；
- 使用理论机座孔代替真实机座孔；
- 三孔只能证明BCD正确，不能证明逐孔对应正确；
- 任一孔偏心或轴线角度超限；
- 偏差虽然未超限，但加上测量不确定度后超过安全余量；
- H01方向未确认或存在120°编号歧义；
- 电机在装盖前后发生移动且没有独立基准重新配准；
- 手眼/TCP失效；
- 端盖翘起、平面异常；
- 连续帧发生孔中心跳变；
- 探针不能低力顺畅通过；
- 起拧阶段出现扭矩突升、空转、深度不足或转角异常。

最终我建议采用“视觉测量＋专用对孔销＋柔顺锁付”的组合。视觉负责快速测量三孔偏心；带力传感的阶梯形/锥形对孔销负责在真正锁付前进行物理通止验证；锁付工具再用低速起拧、扭矩、转角和深度三重监控。这个组合比单纯提高图像算法置信度可靠得多。
