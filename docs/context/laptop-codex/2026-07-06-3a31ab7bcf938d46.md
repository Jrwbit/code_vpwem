```bash
chmod +x /tmp/MicrosoftEdgeDownloads/*/FreeCAD_1.1.1-Linux-x86_64-py311.AppImage
```

3. 然后双击运行，或终端运行：

```bash
/tmp/MicrosoftEdgeDownloads/*/FreeCAD_1.1.1-Linux-x86_64-py311.AppImage
```

更稳妥是把它移到常用目录：

```bash
mkdir -p ~/Applications
mv /tmp/MicrosoftEdgeDownloads/*/FreeCAD_1.1.1-Linux-x86_64-py311.AppImage ~/Applications/
chmod +x ~/Applications/FreeCAD_1.1.1-Linux-x86_64-py311.AppImage
~/Applications/FreeCAD_1.1.1-Linux-x86_64-py311.AppImage
```

如果运行时报 FUSE 相关错误，再执行：

```bash

```
