# 同一工装的坐标迁移链验证：发现活动标定与会话新解不一致

2026-10-20，北京时间20:37开始现场只读核查。用户明确工装及末端执行器在UR5与珞石之间相同；本轮验证其配置是否一致、右转左及腰姿转换是否算错，并检查活动标定来源。未发送运动、上电、采图、清警、标定导入、服务重启或参数修改指令。

已追加至[飞书全流程报告](https://feishu.cn/docx/I2GAdun3nofskUxAOjWcxVwjnJO)，保留原333个顶层块顺序；回读核对新增40个顶层块、三张表格共42个单元格及关键结论。本次没有新增图像或附件。

## 结论

1. **当前JL132工装几何矩阵与原UR工装表一致**，平移差0 mm、旋转差0°。不能再把“工装换了”作为解释；当前也没有独立证据证明法兰安装有偏心，先前提到的零平移限制只是支持范围，不是已发现的实物故障。
2. **右臂到左臂及腰姿转换的计算闭合通过**。从原始7组样本重算相机外参，再独立解析URDF做右转左，与活动标定一致；未发现漏乘、乘反或重复转换。闭合验证不能证明名义安装尺寸与真实装配完全一致。
3. **发现一个具体的来源差异：检测端实际仍使用原7组PARK标定，而同一会话当前保存的是15组ANDREFF解。** 两者不是同一个矩阵，仅看会话名称相同会误认为已经采用新结果。
4. 用已有同一相机盒位比较，新15组解相对活动7组解，会使接线盒目标在原局部XYZ移动约 **[+0.0485, −1.8030, +0.2759] mm**，姿态差约0.1013°。Y变化方向与抵消用户所述Y+偏差相符，量级值得优先核验，**但尚不能证明新解更准确，也不能宣称3 mm问题已经定位或解决**。

本轮没有直接左臂标定或独立实物测量，因而仍不能对跨臂名义安装的绝对误差作通过/不通过结论。

## 验证一：工装参数与坐标方向

读取UR交接`frames.yaml`中JL132的`^TCP T_box`，与现场`tcp_T_objects.JL132`比较：位置`[-43.75,75.78,29.23] mm`、绕Z旋转120°，两者完全一致。配置未出现一个用端子中心、另一个额外偏移3 mm的差别。

这确认的是共享工装几何表；原UR活动TCP和珞石法兰坐标之间仍需正确对应。同一硬件并不自动构成该坐标对应的计量证据，但本轮未找到它配置错误的直接证据，不将其认定为根因。

## 验证二：从样本重建活动外参及腰姿变换

使用现场原始7组`T_base_flange`与`T_cam_board`离线重算，得到PARK解，内部离散1.4036985 mm／0.2770179°，与原记录一致。用独立URDF解析器计算：

`left_T_camera = inverse(world_T_left_base(reference_waist)) × world_T_right_base(reference_waist) × right_T_camera`。

重建结果与活动标定位置差小于1e−9 mm、旋转差小于1e−9°，属于数值闭合。进一步检查：

- 标定腰姿与工作腰姿下，`inverse(world_T_left_base) × world_T_right_base`相同，符合两臂基座固定在同一躯干的模型定义。
- `world_T_camera = world_T_left_base(reference_waist) × active_left_T_camera`；转换到工作左臂基座再转换回世界，与原矩阵闭合，位置/姿态差均小于上述阈值。

因此，本次不支持“右转左用了错误乘法”或“腰姿转换漏乘/重复乘”为已发现的软件根因。该计算仍共享名义URDF，不能检验实际安装误差、挠曲和相机底盘移动。

## 验证三：7组活动解与15组现存解

根据会话指针选择15份原始样本重算，得到ANDREFF解，与现存`result.json`数值闭合。方法和样本集合都变了，不能把变化全部称为“多采8组的改善”。

| 指标 | 原7组活动解 | 当前15组会话解 |
| --- | ---: | ---: |
| 方法 | PARK | ANDREFF |
| 内部平移最大离散 mm | 1.40370 | 0.85802 |
| 内部旋转最大离散 ° | 0.27702 | 0.10529 |
| 是否检测活动标定 | 是 | 否 |
| 是否有独立实物验收 | 未通过 | 本次没有取得 |

在左臂参考基座中，两套相机外参位置差约2.57792 mm、姿态差约0.10134°。外参平移差不是接线盒的定位差，必须把同一`camera_T_box`分别变换后比较。

使用此前归档视觉`20261020_111400_108779`所对应的`camera_T_box`，保持标定参考腰姿及其他配置相同，15组解相对7组解的目标中心差为：

| 坐标表示 | 新减旧XYZ，mm |
| --- | --- |
| 原7组解确定的接线盒局部轴 | `[+0.04847, −1.80303, +0.27594]` |
| 世界轴 | `[−1.79651, −0.07225, −0.31103]` |

目标中心位置差模长1.82467 mm，朝向差0.10134°。这不是新拍照、不是法兰位置差，也不是实机改善量；未来对照必须绑定新旧矩阵、同一相机观测及真实工装参考点，不能直接认定现有3 mm会减少1.8 mm。

内部拟合离散更小不足以证明绝对精度更好。两组样本跨不同采集时段，仍需核对相机、底盘和标定板安装是否保持不变；不同样本与方法可能产生不同系统误差。不能不经独立验证就导入15组解并宣布修复。

## 验证四：历史SDK位姿口径的影响

历史标定采样保存了SDK法兰位姿，也保存了右臂反馈关节。用当前读取的本机有效DH回算原7组反馈角，与采样SDK法兰位置相差约0.388–0.569 mm。仅作为敏感性试算，替换采样法兰后重算，左臂相机外参相对活动解约变化0.508 mm；同一归档盒位的局部XYZ变化约`[+0.1327,+0.2169,−0.5112] mm`。

该试算假设本机有效DH自采样时至今未变；没有把它导入。它显示反馈口径可能影响标定，但本次变化也不能单独解释Y+约3 mm，且不是独立实物真值。

## 验证结论的下一步

本轮已经完成代码与来源层面的验证，发现的具体可复核问题是**检测活动结果仍为原7组，而会话已有另一份15组解，两者目标Y约差1.80 mm**。是否应改用15组，必须由同工况独立测量决定。

最小现场验证可以固定盒、相机、底盘和工作腰姿，用至少3个未参与拟合且非共线的实物点，分别计算两套外参的误差；真值不能用任一待测矩阵反算。先进行不需要机器人运动的离线点对照；若没有独立点坐标，就需要现场计量或在工作腰姿用左臂建立直接标定并作独立验证。本轮没有获得这些新测量，因此**尚未完成实物绝对精度验证，也没有更改活动标定**。
