# 06 如何修改网络结构并保证改对

## 1. 先写“改动假设”，再改代码

每次实验先用一句可证伪的话描述：

```text
因为 ______ 是当前瓶颈，
我只修改 ______，
预期 ______ 指标提高，
若 ______ 不发生，则假设不成立。
```

例：因为固定上下文读取会把无关历史也交给动作网络，我只增加读取门控；预期强记忆任务不降、近似马尔可夫任务更稳，并且门值随阶段变化。

## 2. 先判断应该改哪一块

| 想解决的问题 | 首选改动位置 | 典型文件 |
| --- | --- | --- |
| 图像特征丢了颜色/空间细节 | Condition Encoder | `nn_condition/multi_image_condition.py` |
| 关键历史没有写入或被淘汰 | Memory 写入/cache | `nn_memory/qformer_memory.py` 或新模块 |
| Tm 个 token 没总结出有效状态 | Q-Former 层/训练目标 | `qformer_memory.py`, `longmem_ddpm.py` |
| 动作不知道何时读取哪段历史 | memory read/decoder | `longmem_chitransformerptp.py` |
| 时间泄漏或动作错位 | mask / sampler / horizon | diffusion 网络、dataset、YAML |
| 训练有信息，rollout 忘了 | online inference/reset | `longmem_ddpm.py`, eval pipeline |

## 3. 只改宽度 D：牵一发而动全身

若从 `D=256` 改成 `D=384`，至少要保持：

```text
Condition Encoder 输出 D
= QFormer input_dim/d_model/output D
= diffusion obs_dim/d_model D
```

还要保证 Q-Former 和 decoder 的 `D % num_heads == 0`。当前 pipeline 多处把 256 写死，不能只改 YAML 的 `qformer_emb_dim`。

更安全的改法是先把公共参数贯通：

```python
model_dim = args.model_dim
nn_condition = ...(emb_dim=model_dim)
nn_memory = ...(emb_dim=model_dim)
nn_diffusion = ...(
    obs_dim=model_dim, d_model=model_dim)
```

## 4. 只改 Tm：需要同步哪些地方

```yaml
mem_compress_length: 4  # -> 8
```

pipeline 已把它同时传给 `QFormerMemory.n_queries` 和 `LongMemChiTransformerPTP.Tm`，基线通常可自动同步。但旧 checkpoint 的参数形状（query tokens、条件位置编码等）会不匹配，不能 strict 加载。

验证：

```python
assert compressed_memory.shape == (B, 8, D)
assert diffusion.cond_pos_emb.shape[1] >= 1 + 8 + To
assert diffusion.memory_mask.shape == (Ta, 1 + 8 + To)
```

## 5. 改 Q-Former 深度或头数

```yaml
qformer_num_layers: 1  # -> 2
qformer_num_heads: 8   # 注意：当前主 pipeline 的 QFormer 构造未传此字段
```

当前 `longmemdpptp_mikasa_image.py` 构造 `QFormerMemory` 时传了 `num_layers`，但没有传 `num_heads`，所以只改 YAML 的 `qformer_num_heads` 对 Q-Former 基线不会生效；需补：

```python
num_heads=args.qformer_num_heads,
```

这是“配置存在 ≠ 已接线”的典型例子。修改后打印模型结构或断言属性，不要只看 YAML。

## 6. 改动作 decoder 深度、头数、条件 encoder

- 深度：`diffusion_num_layers` 已传给 `num_layers`。
- 头数：主 pipeline 当前写死 `nhead=4`，若想实验需新增 YAML 参数并传递。
- 条件 encoder：构造函数支持 `n_cond_layers`，pipeline 当前未传，默认 0。

建议接线：

```python
nn_diffusion = LongMemChiTransformerPTP(
    ...,
    d_model=args.model_dim,
    nhead=args.diffusion_num_heads,
    num_layers=args.diffusion_num_layers,
    n_cond_layers=args.diffusion_cond_layers)
```

每新增一个 YAML 字段，都要通过打印最终对象确认它真的生效。

## 7. 改 memory 读取方式

仓库已提供最小接口：

```yaml
memory_read_mode: context         # 原基线
memory_read_mode: gated           # 门控
memory_read_mode: control_indexed # 当前状态再次检索
```

若自己加第四种方式，保持输入/输出 `mem_emb: [B,Tm,D] -> [B,Tm,D]`，这样后面的条件拼接和 mask 不用重写。若改变 token 数，必须同步 `cond_pos_emb` 和 `memory_mask`。

## 8. 替换整个 memory 模块

新模块至少遵守：

```python
class MyMemory(BaseNNMemory):
    def forward(self, memory, ep_step, **kwargs):
        # training: [B,Th,D] -> [B,Tm,D]
        ...

    def inference(self, new_memory, **kwargs):
        # online incremental update -> [B,Tm,D]
        ...

    def reset(self):
        # clear episode state
        ...
```

然后在 pipeline 的 `mem_compress_method` 分支注册。离线 `forward` 与在线 `inference` 都必须测，不能只让训练跑通。

## 9. 改 mask 是高风险操作

mask 的每一列语义依赖条件拼接顺序：

```python
cond_emb = cat([timestep, memory, observation], dim=1)
```

若改成 `[timestep, observation, memory]` 却不改 `memory_mask`，代码仍可能运行，但时间可见性已经错了。任何顺序/长度改动都应画出二维可见性表并写单元测试。

## 10. 改 horizon 的约束

PTP pipeline 明确断言：

```python
assert horizon == obs_steps + action_steps - 1
```

因此改 `obs_steps` 或 `action_steps` 时要同步 `horizon`。还要检查 rollout 切片、`inference_action_steps`、数据集 padding 与 checkpoint 形状。

## 11. 最小形状测试模板

```python
B, To, Th, Tm, Ta, A, D = 2, 2, 6, 4, 9, 8, 256
history = torch.randn(B, Th, D, device=device)
ep_step = torch.arange(Th, device=device).repeat(B, 1)
recent = torch.randn(B, To, D, device=device)
noisy_action = torch.randn(B, Ta, A, device=device)
t = torch.randint(0, 50, (B,), device=device)

memory.reset()
m = memory(history, ep_step)
assert m.shape == (B, Tm, D)

y = diffusion(noisy_action, t, recent, m)
assert y.shape == noisy_action.shape
assert torch.isfinite(y).all()
```

再做一次 `loss.backward()`，确认目标模块参数有非空、有限梯度。

## 12. 上线实验前的四级验证

1. 静态检查：形状、参数接线、mask、checkpoint 兼容性。
2. 烟雾测试：CPU/单 GPU 跑一个 batch 的 forward/backward。
3. 过拟合小样本：几十个样本上 loss 应明显下降。
4. 公平实验：同数据切分、seed、训练步数、动作预算，只改变目标因素。

## 13. 怎样证明网络真的用了历史

仅成功率上涨不够。至少比较：

```text
正确历史
zero memory
打乱 batch 的历史
同当前观测、不同历史分支
```

若动作和成功率对历史干预几乎不变，模型可能只靠当前观测或轨迹伪线索。强记忆正对照与近似马尔可夫负对照应一起报告。

## 14. 初学者推荐的前三个改动

1. 改 `Tm=2/4/8`：接口最清楚，学习容量与计算权衡。
2. 改 `qformer_num_layers=1/2`：理解记忆压缩深度；记得接通 heads 参数。
3. 比较 `context/gated`：理解“写记忆”和“读记忆”是两件事。

暂时不要第一个实验就同时改视觉 backbone、memory、decoder 和 loss，否则即使变好也无法知道原因。
