# 持续目标：可靠的单目标条件选择

用户2026-11-01明确要求设为目标，继续提出并实测想到的可行方法。本线程目标已创建为active，未设用户未要求的token预算。不是只做一轮失败后停止，也不把有限方法扫描写成穷尽所有可能方法。

验收方向：抓碗时错类下降，在统一标签协议、独立轨迹确认下提高选框精度，同时保持正确框召回和覆盖。开发目标为选中框precision>=90%、正确框召回不低于同协议旧指针，并报告抓碗错选、目标切换和缺框；开发阈值不冒充可靠性保证。弱代理评分不等于真实操作意图或闭环成功率。

先审计上轮标签：carry/place_unavailable把“持碗、但接收区域缺标签”当成空目标，会鼓励丢掉仍应追踪的碗。新subject协议保留当前持碗实例；释放/边界不确定帧单列未知，接收位置继续作为独立未完成任务，不伪造当前位置。协议变更后重新训练所有对照，旧百分数不混比。
