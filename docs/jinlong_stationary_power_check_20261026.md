## 相机抬高和手眼准确之后，还缺什么

结论：可以推进现场分阶段联调，不能仅凭相机抬高8cm和手眼标定准确，认定三型号完整插接／电测可直接运行。

1. **落实共同工位和工作腰姿。** 本轮现场腰姿模型角约`[−27.876,23.288,18.759,−1.197]°`，8cm候选为`[−30,20,10,−80]°`。本次上电没有移动到该候选腰姿；不能直接沿用视频轨迹。还需实测底座／台面／盒体关系，按真实起点和安装几何重规划并验证进入工作位。
2. **自动检测需要同一会话内保持腰部上电。** 现场原生自动关节路线仍只给左臂上电，非目标部件要求off／manual／idle；`--waist-hold`只用于示教保持，不能和自动路线组合。两个上电按钮共用busy所有权，不能通过先开腰保持、再启动另一左臂路线绕过集成。J4下电不保持是用户已确认的特性，不能再当作必须维修的故障；应适配自动路线及停止／结束的生命周期。
3. **真实插接配合和压入仍未验收。** 8cm方案仅到名义配合目标前40mm，再返回。160独立三柱拟合后地针跨槽约4.316mm残差仍待实际量测／配合核验；100、132也需实物对位。虽然分阶段规划有压入补偿参数，当前完整路线回执仍为`additional_press_mm=0`，没有已验收的真实接触闭环。
4. **电测设备握手尚未接入完整路线。** 现场`corridor_worker.py`明确记录`electrical_test_connected=false`；到位保持／等待操作员恢复不等于收到电测开始、完成和合格结果，需要接入并验证异常退出。

最终视觉状态仍为`motion_enabled=false`。除了标定独立实测精度未验收和当前腰姿不匹配，现场还报告TCP／工装／工作区／路径／方向／控制验收未确认，以及工作区、过渡净空、过渡方向和到位验收指标未配置。这些是软件当前拒绝自动执行的条件，不应直接把标志改为true绕过。

相机当前没有新鲜图像，HMI为`camera stopped`，视觉健康返回503及“相机已交接给检测任务”。不能据此确诊相机损坏；恢复实际采图与相机所有权、抬高后的外参和400–800mm目标成像均需在后续视觉联调中验收。预留二维码区通过仿真不代表实际贴码已识读。
