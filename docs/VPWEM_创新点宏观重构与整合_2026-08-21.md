# VPWEM 创新点宏观重构与整合

更新时间：2026-08-21

## 0. 核心结论

VPWEM 不应再被概括为“给 Diffusion Policy 加一个 Q-Former memory”，也不应继续把“工作记忆 + 情景记忆”“固定数量 token”或尚未成立的 delta-PER 当作全部创新。

更稳固的研究定位是：

> **VPWEM 研究固定记忆预算下的单回合任务状态维持：当决定动作的证据已经离开当前视野时，策略如何从持续增长的观测历史中保留跨时间证据，并把它们转化为可供低层动作生成使用的有界任务信念。**

这一定位把问题从“压缩更多历史”提升为“在有限预算下维持决策充分状态”。它包含三个不可分割的问题：

1. **覆盖（coverage）**：早期且延迟生效的证据不能因时间太久而必然消失；
2. **状态化（belief formation）**：历史不能只作为帧集合存在，还要被整合为当前任务状态；
3. **修正（revision）**：当新证据推翻旧状态时，记忆必须允许更新，而不是让历史永久支配动作。

当前证据首先支持“覆盖”问题的重要性，但尚未支持 delta-PER、learned retention 或完整的可修正 belief memory。论文应把**已成立贡献、已观察机制和下一代方法假设**严格分层。

## 1. 先宏观树立：VPWEM 到底研究什么

### 1.1 研究对象不是泛化的“机器人长记忆”

VPWEM 的边界应明确为：

- 时间边界：当前 episode 内，而非跨任务、跨用户或跨示范库；
- 信息来源：自身 observation history，而非外部轨迹检索、文本知识库或场景图；
- 决策层级：连续低层 visuomotor control，而非高层 LLM planner；
- 资源约束：固定 token / slot 预算，而非随 episode 增长的关键帧库；
- 目标：恢复当前观测中缺失、但动作仍然依赖的任务状态。

因此，VPWEM 的标准问题不是“能否使用历史”，而是：

> 在部分可观测、长延迟决策和固定在线资源约束同时存在时，什么样的历史表征才是动作决策的充分统计量？

### 1.2 核心矛盾：有限预算与延迟证据

非马尔可夫操作任务中的有效信息通常非常稀疏：目标颜色只出现一次、两个物体曾经交换、容器先前被打开、某个子任务已经完成。大量中间帧只是重复的控制过程。

固定窗口的问题是早期证据必然过期；增长式检索的问题是存储和计算随时长增长；无差别递归压缩的问题是关键证据会被重复帧稀释，并产生不可解释的 summary drift。

所以 VPWEM 的核心矛盾可以统一为：

```text
持续增长的观测历史
        ×
固定的在线记忆预算
        ↓
必须长期保留少量延迟生效的证据，
同时把它们更新为当前可用的任务状态。
```

### 1.3 总体论点：从 history compression 到 bounded belief maintenance

VPWEM v1 回答的是：

> 如何把越窗观测压缩成固定数量的 memory tokens？

下一步更强的统一命题应当是：

> **历史记忆的目标不是重建过去，而是在固定预算下维持对未来动作充分的任务信念。**

这使三类机制获得统一解释：

- 稀疏原始历史用于保持**时间覆盖和证据可回看性**；
- latent memory tokens 用于形成**紧凑任务信念**；
- conflict-aware update 用于保证**信念随新证据修正**。

“Remember Changes, Not Frames”仍可作为直观表达，但需要改得更准确：变化不是天然重要，真正重要的是**跨时间覆盖到的、会改变决策充分状态的证据**。

## 2. 三份材料与当前工作的统一关系

| 来源 | 原先提供的价值 | 整合后的角色 | 需要降级的内容 |
| --- | --- | --- | --- |
| 跨领域记忆机制迁移方案 | surprise、retention、object slots、anchors、reconsolidation、future prediction | 提供下一代记忆的机制库 | 不能把所有机制同时堆成贡献；预测误差目前没有在线结果支持 |
| “Remember Changes, Not Frames” | event gate、Evidence–Belief、skip/merge/overwrite/allocate、因果干预 | 提供从压缩到 belief maintenance 的叙事骨架 | delta 变化量不能等同于事件价值；完整 PER 方法仍是目标而非已验证结果 |
| P0 论文 Idea 地图 | 强竞争者、反例、因果评测、长度外推、anti-lookup | 确定 novelty 边界和 reviewer 需要的证据链 | working + long-term memory、固定容量、关键帧本身均不能单独作为新颖性 |

```text
        ↓
跨领域机制提供候选解法
        ↓

        ↓
保留“时间覆盖 → 任务信念 → 可修正状态”这一条主线
```

## 3. 当前最关键的新发现：Coverage First

### 3.1 已有结果改变了早期判断

在 Robomimic Transport/mh、统一评测 seed `20260814`、每个训练 seed 100 episodes 的筛选中：

| 方法 | 汇总成功率 | 相对 FIFO | 当前解释 |
| --- | ---: | ---: | --- |
| FIFO | 113/300，37.67% | — | 偏向最近历史，远期证据会被淘汰 |
| Reservoir-2 raw / Random retention | 153/300，51.00% | **+13.33 pp** | 三个 seed 均为正；配对 95% CI `[+5.7,+20.7] pp`，McNemar `p=0.0008` |

但机制拆分实验同时显示：

| 对照 | 结果 | 说明 |
| --- | ---: | --- |
| Recent-2 raw | 46% | 两个最近原始 token 已强于该轮 FIFO-QFormer |
| Reservoir-2 raw | 51% | 在同为两个 raw tokens 时，长历史覆盖进一步带来收益 |
| FIFO Q-Former bank8 | 38% | 历史经过 bank 和 Q-Former 压缩后效果较弱 |
| Q-Former random-evict bank8 | 38% | 仅改变 Q-Former bank 淘汰方式没有收益 |

这组结果不应被简化为“随机记忆是新方法”。它揭示的是更重要的机制事实：

> **收益来自固定 token 预算下的跨时域证据覆盖，而不是随机淘汰本身；原始证据的保真可能比在小 bank 上继续复杂压缩更重要。**

### 3.2 它否定了哪些过早假设

- delta-PER 在 Transport/mh 三 seed × 300 episodes 中只有 `+2.89 pp` 趋势，主检验不显著；跨 MIKASA/MoMaRT 后总体为 `-0.25 pp`。
- 当前 learned retention 在 seed 100 为 39%，FIFO 为 38%，没有在线收益。
- learned retention 虽能在离线 ranking 中保留 80.43% 的 oracle importance，高于 delta 的 60.92%，但标签相关性弱，且没有转化为 rollout 成功率。
- 因而“视觉变化大”“离线动作影响高”都不能直接作为在线保留价值的充分代理。

当前应采用的科学顺序是：

1. 先把 reservoir / uniform temporal coverage 作为必须超过的强基线；
2. 再证明结构化 belief 或 learned selection 在相同 token、参数和训练预算下额外有效；
3. 若复杂机制不能超过简单覆盖，就不把它包装成主创新。

### 3.3 当前结果的边界

Random retention 的正结果目前仍主要来自 Transport/mh，尚不能声称跨任务普遍成立。三个训练 seed 共用同一个评测 episode 集，适合配对检验，但跨任务泛化仍需 MIKASA、LongSquare 或 MoMaRT 的确认。

因此正确表述是：

> 我们在 Transport/mh 上发现并多 seed 验证了 temporal coverage 的强信号；它构成下一代 VPWEM 的设计依据，而不是已经完成的通用算法结论。

## 4. 重构后的创新体系

创新不应平铺成六七个模块，而应组织成“一条主命题、三项贡献、一个证据体系”。

### 4.1 主命题

> **Bounded state sufficiency under long delays：VPWEM 在固定在线预算下，从单回合观测历史中维持对低层动作充分的任务状态。**

### 4.2 贡献一：有界单回合观测记忆（当前已实现）

VPWEM 将近期观测与越窗历史分工：working memory 服务即时控制，episodic memory 将较早的 observation history 变成固定数量的 latent tokens，并共同条件化 diffusion action generation。

这项贡献的安全差异是：

- 不依赖跨示范动作检索；
- 不依赖显式语言推理或手工场景图；
- 服务连续低层动作生成；
- 在线 observation cache、summary cache 和输出 token 数均有界。

但必须收窄表述：训练 sampler 默认最多保留 16 个分段历史观测，不能说训练时使用了任意长完整历史；“双记忆”和“固定容量”也不能脱离具体问题单独宣称新颖。

### 4.3 贡献二：Coverage-Preserving Evidence（已有单任务多 seed 证据，待跨任务确认）

最值得从当前结果中提炼的新原则是：

> 固定预算记忆首先要防止 delayed evidence 被 recency bias 淘汰；在此基础上才值得讨论 learned importance。

方法层的最小形态不是继续扩大 Q-Former，而是保留少量跨 episode 时间轴分布的 raw evidence tokens。Reservoir sampling 提供无偏覆盖基线；后续可比较 uniform strata、first–recent anchor、event-aware reservoir，但所有方案必须保持相同 token 数。

这项贡献若要进入论文，需要补：

- 至少两个额外 memory-intensive tasks；
- reservoir、uniform、first–recent、FIFO 的同预算比较；
- retained-token age / temporal span / cue recall 与成功率关联；
- 排除仅由训练实现、位置编码或 token 数不一致造成的收益。

### 4.4 贡献三：Evidence-to-Belief and Revision（目标方法，尚未被当前结果证明）

跨领域方案和 PER 叙事中真正值得保留的不是 delta gate，而是 Evidence–Belief 分工：

```text
Working memory：当前看到了什么
Coverage evidence：过去哪些证据仍可能在未来生效
Belief tokens：这些证据意味着当前任务状态是什么
Revision controller：新证据是否推翻了旧状态
```

推荐的下一代最小架构应保持总预算固定：

```text
K = K_evidence + K_belief

evidence：reservoir / stratified coverage 保留的少量原始历史 token
belief：Q-Former 或 recurrent updater 形成的紧凑状态 token
```

先验证 evidence + belief 是否优于“全 raw”和“全 compressed”；只有通过后，再加入 task-conditioned utility 或 conflict-aware overwrite。预测 surprise、object slots、future prediction、trajectory adversary 均属于可选支撑机制，不应一次性加入。

### 4.5 贡献四：因果与资源约束评测（证据贡献）

记忆论文不能只用平均成功率证明 memory 有效。VPWEM 应形成四类证据：

- **Memory Necessity**：正确 memory 替换为空后下降多少；
- **Memory Specificity**：替换成其他 trajectory 的 memory 后下降多少；
- **State Sufficiency**：当前视觉受损时，正确 memory 能否继续支持动作；
- **Bounded Extrapolation**：test horizon 增长时，成功率、延迟和显存如何变化。

再用 trajectory-ID probe、history shuffle、状态冲突注入和 recovery steps 排除动作查表及 memory trap。

这不是附属实验，而是把“memory token 是任务状态”从命名提升为可证伪主张。

## 5. 建议的方法收敛：CPB-VPWEM（暂名）

为避免继续沿用已经被 delta 结果削弱的 `PER-VPWEM` 名称，可暂用：

> **CPB-VPWEM: Coverage-Preserving Belief Memory for Bounded Non-Markovian Visuomotor Control**

它只表达一条主线：先保证跨时间证据覆盖，再把证据整合成固定预算任务信念。

### 5.1 第一阶段：最小可发表方法

1. `K_evidence` 个 raw evidence tokens：reservoir 或分层时间覆盖；
2. `K_belief` 个 Q-Former belief tokens：整合 evidence 与近期观测；
3. 总 token 数与 FIFO、Random、Q-Former 基线严格相等；
4. action loss 仍为唯一主损失，先隔离架构收益。

这一阶段回答：raw coverage 与 compressed belief 是否互补。

### 5.2 第二阶段：任务相关保留

只有第一阶段成立后，才在 coverage 约束上增加 task-conditioned score：

```text
retention utility
= long-horizon coverage
+ future decision utility
+ state-change evidence
- redundancy
```

与早期 PER 不同，learned score 不能自由淘汰全部旧证据；应保留 coverage floor，避免当前不相关但未来关键的信息被提前删除。

### 5.3 第三阶段：可修正状态

若状态突变任务证明 stale memory 是主要失败源，再加入：

```text
keep / update / reset / allocate
```

以对象状态、任务阶段或 next-observation consistency 监督 revision。此时“Remember Changes, Not Frames”才可升级为“Update Beliefs When Evidence Changes”。

## 6. 论文叙事的推荐版本

### 6.1 一句话

> VPWEM 不是为了保存更多历史，而是为了在固定资源下，让低层视觉运动策略持续拥有对当前动作充分的单回合任务状态。

### 6.2 问题—洞察—方法—验证

**问题。** 当前帧或有限窗口无法表示早期提示、物体交换和任务进度；增长式历史库又使在线成本随 episode 增长。

**洞察。** 固定预算记忆首先面临 temporal coverage 问题：决定未来动作的证据可能很早出现、长期不相关、最后才生效。局部变化量和离线 importance 不一定能识别这种证据。

**方法。** VPWEM 将近期观测与有界 episodic state 分离；下一代版本进一步用稀疏 evidence 保持长时覆盖，用 belief tokens 形成紧凑任务状态，并在冲突证据到来时修正状态。

**验证。** 除任务成功率外，使用同预算强基线、memory interventions、cue delay / horizon scaling、状态 probe、恢复时间和资源曲线验证状态充分性。

### 6.3 三条贡献的写法

若以当前 VPWEM 为主体：

1. 提出面向低层 visuomotor control 的有界单回合观测记忆，将近期 working context 与越窗 episodic state 分离，并以固定数量 token 条件化 diffusion policy。
2. 系统揭示固定预算记忆中的 temporal coverage 问题：在 Transport/mh 的多 seed 配对实验中，简单 reservoir evidence 显著优于 FIFO，而 delta 与当前 learned retention 未形成在线优势，说明长期覆盖是任务相关选择之前必须满足的约束。
3. 建立同预算、因果干预与 horizon extrapolation 评测协议，用于区分任务状态记忆、最近窗口收益、轨迹查表与增长式存储。

若下一代 CPB-VPWEM 完成验证，则第二条改为方法贡献：

2. 提出 coverage-preserving evidence–belief memory，在固定总 token 预算下联合保留跨时间原始证据与递归任务信念，并通过受覆盖约束的更新避免 delayed evidence 被提前遗忘。

### 6.4 不再使用的表述

- “首次把 working memory 和 episodic memory 用于机器人策略”；
- “将任意长完整历史无损压缩为两个 token”；
- “delta 变化代表任务关键事件”；
- “PER 显著、稳定或普遍优于 FIFO”；
- “预测误差、evidence token、反事实损失已经被正式验证”；
- “越复杂的 learned retention 越能提升控制”。

## 7. 实验整合：每个创新必须对应可证伪问题

| 主张 | 必须比较 | 关键任务/操控变量 | 成立标准 |
| --- | --- | --- | --- |
| 有界 memory 优于有限窗口 | Recent-K、HAMLET-style、xLSTM、VPWEM | cue-to-action delay | delay 超窗后仍保持优势 |
| temporal coverage 有效 | FIFO、uniform、reservoir、first–recent | horizon、cue position | 多任务多 seed，等 token 下稳定正向 |
| evidence 与 belief 互补 | all-raw、all-belief、hybrid | identity / count / stage | hybrid 在状态 probe 和 rollout 同时提升 |
| task-conditioned selection 有效 | random/uniform 与 learned | 同写入率、同 temporal span | 超过简单覆盖基线，而非只超过 FIFO |
| revision 有效 | append/merge/overwrite | swap、target relocation、rollback | stale-state recovery steps 明显减少 |
| memory 被因果使用 | none、zero、shuffle、wrong-trajectory | 公共 paired episodes | necessity 和 specificity 跨 seed 稳定 |
| 资源真正有界 | growing keyframes、window、VPWEM | 1×/2×/4×/8× horizon | token、显存和单步延迟达到稳定上界 |

主图建议围绕一个关系绘制：

```text
x：关键证据与最终动作之间的时间间隔
y：任务成功率

Recent/window：超窗后快速下降
Growing retrieval：性能较稳，但资源持续增长
Reservoir evidence：固定预算、覆盖较强，但状态整合有限
CPB-VPWEM：固定预算，同时保持覆盖与任务信念
```

## 8. 当前证据分级

### A. 可以写成事实

- VPWEM 的 working memory、Q-Former episodic tokens、在线有界 cache 和 diffusion conditioning 有真实调用链。
- 2-layer、2-token、256-d Q-Former memory 约 2.24M 参数。
- Robomimic 四个标准任务的本地 4-layer 变体及 ShellGameTouch、绝大多数 MoMaRT 任务已有合理结果。
- Transport/mh 上 reservoir/random retention 的三个训练 seed 均高于 FIFO，汇总配对区间不跨 0。
- 当前 delta-PER 和 learned retention 没有稳定在线优势。

### B. 只能写成观察或候选解释

- temporal coverage 可能是 Transport/mh 提升的主要来源；机制拆分支持该解释，但仍需更多任务验证。
- raw evidence 可能比小 bank 上的 Q-Former 压缩更能保持关键历史；目前还不能推广到所有任务。
- 正确/错配 memory 会影响策略的方向性诊断，需要正式多 seed 干预矩阵。

### C. 仍是待实现、待验证假设

- Evidence–Belief hybrid 优于全 raw 或全 belief；
- coverage-constrained learned retention；
- predictive surprise 真能发现决策关键事件；
- conflict-aware belief revision；
- object/type-routed slots；
- trajectory adversary 和 future prediction 提升 OOD 状态保真。

## 9. 最务实的执行顺序

### P0：先闭合现有发现

1. 在至少两个额外 memory-intensive tasks 上复验 reservoir vs. FIFO / Recent-2；
2. 记录每回合 retained steps、平均 age、temporal span、早期 cue recall；
3. 使用统一 token 数、位置编码、backbone、训练预算和 paired episodes；
4. 修复并冻结 RememberColor3 / LongSquare 的配置和数据链后再纳入主结果。

### P1：只做一个最小新方法

实现固定总预算的 `raw evidence + Q-Former belief` hybrid，并只用 action loss。先回答“覆盖与状态压缩是否互补”，不要同时加入 predictor、object slots、counterfactual loss 和 reconsolidation。

### P2：根据失败模式选一条增强路线

- 如果早期 cue 仍丢失：做 coverage-constrained task utility；
- 如果 evidence 保住但状态混淆：做 typed/object belief slots；
- 如果新状态出现后仍坚持旧状态：做 conflict-aware revision；
- 如果 ID probe 过高且 OOD 脆弱：做 anti-lookup representation。

每次只让一个机制通过同预算 gate，再进入多 seed 主表。

## 10. 最终整合后的判断

VPWEM 最有价值的创新不应被某个 compressor 名称定义，而应由一个更稳定的科学问题定义：

> **如何在固定在线资源下，让低层机器人策略从持续增长的单回合观测中维持对未来动作充分、跨长延迟且可被新证据修正的任务状态。**

现阶段最扎实的路线是：

```text
原 VPWEM：证明 bounded within-episode memory 的架构价值
        ↓
当前新发现：证明 temporal coverage 是固定预算记忆的首要约束
        ↓
下一代方法：coverage-preserving evidence + compact belief
        ↓
条件成熟后：task-conditioned retention + conflict-aware revision
```

因此，建议暂时停止以 delta-PER 为中心的创新叙事，把论文主线改为：

> **From Compressing History to Preserving State: Coverage-Preserving Bounded Memory for Non-Markovian Visuomotor Control.**

“Remember Changes, Not Frames”可以保留为传播性副标题，但方法论底座应改为：

> **Preserve delayed evidence first; compress it into belief second; revise the belief when evidence changes.**
