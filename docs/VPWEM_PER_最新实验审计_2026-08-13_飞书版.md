# VPWEM / PER 最新实验审计与论文定位

更新时间：2026-08-13

## 一、结论先行

1. 原 VPWEM 的代码和方法链条基本成立：近期观测作为 working memory，更早历史由 Q-Former 递归压缩为固定数量的 episodic tokens，并与当前观测共同条件化 diffusion policy。
2. VPWEM 已在 Robomimic 标准任务、MIKASA ShellGameTouch 和大部分 MoMaRT 任务上得到合理结果，但 RememberColor3、LongSquare 和 RMBench 是明确失败点。
3. 当前 PER-delta 不能作为“稳定提升 VPWEM 性能”的论文核心创新。Transport/mh 有弱正向趋势，但跨 MIKASA/MoMaRT 后总体持平，并在 ShellGameTouch 上显著退化。
4. 论文最安全的核心贡献是“固定容量的单回合观测历史压缩”。不应继续声称“机器人策略很少使用记忆”或训练时使用“任意长的完整历史”。
5. 建议保留 VPWEM 为主方法，将 delta-PER 降级为探索性机制或消融；先修复 LongSquare/RememberColor3 的论文配置复现，再决定下一代 memory retention 方向。

## 五、创新点判断

### VPWEM：可以保留为主创新

- bounded within-episode observation memory；
- working memory 与 episodic memory 分离；
- Q-Former 将持续增长的历史压缩成固定数量 latent tokens；
- memory 与当前观测共同条件化动作扩散模型；
- compressor 与 policy 联合训练；
- 不依赖外部示范轨迹库或手工场景图。

需要收窄：训练 sampler 默认最多保留 16 个采样历史观测，因此“任意长完整历史”比实际训练证据更强；“memory remains largely unexplored”也已被 2026 年相关工作削弱。

### PER：当前只适合探索性贡献

正式验证过的部分只有固定容量事件 bank、相邻 embedding cosine delta 写入、阈值跳过、最大等待写入、低效用槽替换，再由原 Q-Former 输出固定 token。预测惊讶、Evidence/Belief token 和反事实损失未在正式实验中获得支持。

目前 delta-PER 更像“视觉变化保留启发式”，还没有证明视觉变化等价于动作决策需要的长期信息。因此可以写机制与负结果分析，不能写普遍性能提升。

## 六、与相关论文的定位

| 方法 | 保存的过去 | VPWEM 的安全差异 |
| --- | --- | --- |
| OptimusVLA | 跨示范动作先验＋近期动作块 | VPWEM 保存当前 episode 的观测历史，不检索外部轨迹 |
| TRM-VLA | 关键帧推理特征 | VPWEM 连续端到端压缩交互状态，不依赖 CoT |
| Scene Graph Memory | 对象、位置、可见性显式图 | VPWEM 是隐式固定 token，不依赖检测跟踪 |
| HiF-VLA | 历史运动向量 | VPWEM 理论上还能保存身份、遮挡前状态和容器状态等非运动信息 |
| CycleManip | 成本感知历史采样＋周期/进度监督 | 与 PER 较接近，但 PER 当前证据明显更弱 |
| PALM | 显式任务进度 | 提醒实验必须区分记忆过去与识别进度 |
| AFI | 检测并逃离 memory trap | ShellGameTouch 退化说明事件记忆也可能强化错误历史依赖 |

推荐论文主张：VPWEM 提供有界的单回合观测记忆，将持续增长的交互历史在线压缩为固定数量的潜在情景 token，以恢复当前观测中缺失的任务状态；它不依赖外部轨迹库或手工场景图。

## 七、下一步优先级

1. 优先修复 LongSquare 和 RememberColor3，核对数据版本、episode 边界、采样历史、8-layer 配置和 eval wrapper。
2. 冻结一份论文级配置与结果 manifest：commit/diff hash、YAML、checkpoint hash、训练 seed、评测 seed、逐 episode 结果。
3. 暂停扩展当前 delta-PER 的大规模 seed 矩阵；把它降级为消融或负结果分析。
4. 若继续 memory innovation，改做 query/task-conditioned retention，用当前 policy query、动作不确定性或未来 action/value prediction error 评价历史槽位。
5. 补 memory zero/shuffle、history shuffle、任务进度 probe、物体状态 probe，以及 motion-history/关键帧/显式进度基线。
