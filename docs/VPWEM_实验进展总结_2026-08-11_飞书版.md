# VPWEM 实验进展总结（截至 2026-08-11）

## 结论摘要

**实验尚未完全完成，也还不能形成“创新方法稳定优于 VPWEM”的结论。**

当前最可靠的新增证据来自本机 Robomimic Transport/mh 的正式对照：PER-VPWEM（事件选择记忆）相对 FIFO VPWEM 有 **+2.89 个百分点**的平均成功率趋势，并且累计奖励稳定提高；但成功率主检验未显著。因此，PER 可以作为“有前景、待确认的创新候选”，不能写成已证实的性能提升。

原 VPWEM 方面，本机已有 Robomimic 的可追溯结果，但多数 checkpoint 是 **4-layer diffusion**，与论文 Table I 的 **8-layer** 主配置不一致；MIKASA、MoMaRT 和 MaIL-VPWEM 仍缺少完整的、本地可复核的正式结果链。LongSquare 复现当前失败。因此，原论文的全基准复现同样未完成。

## 创新方法：PER-VPWEM 对比结果

### 方法

PER-VPWEM 在不增加策略输出 memory token 预算的前提下，把 FIFO 历史写入替换为固定容量的事件库：按相邻表征的 cosine delta 计算事件效用，保留 episode 起点锚点，合并相似事件，并在容量满时淘汰低效用槽位；之后仍由原 Q-Former 将事件库压缩成 2 个 belief tokens 供扩散策略使用。

正式运行配置：Robomimic Transport/mh，4-layer diffusion、2-layer Q-Former、2 memory tokens、event-bank=8、delta score；FIFO 与 PER 都从同一训练 Seed 对应的基础 VPWEM checkpoint 继续适配 10k steps，学习率均为 `1e-5`。

### 正式成功率结果（公共 300 个环境初始状态）

| 训练 Seed | FIFO VPWEM | PER-VPWEM | PER − FIFO |
| ---: | ---: | ---: | ---: |
| 100 | 40.67% | 39.33% | -1.33 pp |
| 200 | 37.67% | 42.00% | +4.33 pp |
| 300 | 40.67% | 46.33% | +5.67 pp |
| **三 Seed 汇总** | **39.67%** | **42.56%** | **+2.89 pp** |

主检验结果：配对 bootstrap 95% CI 为 **[-1.33, +7.11] pp**，exact McNemar **p=0.203**；以训练 Seed 为单位的 95% t 区间为 **[-6.34, +12.12] pp**。三个 Seed 的方向也不完全一致。

因此，严格结论是：**观察到 PER-VPWEM 的正向平均趋势，但现有证据不足以证明成功率存在稳定、统计显著的提升。**

### 次要指标与诊断

累计 reward 从 FIFO 的 **7.191** 提高到 PER 的 **8.918**（+1.727；配对 bootstrap 95% CI `[+0.821, +2.628]`），三个训练 Seed 均为正向。这说明 PER 可能使成功更早发生或维持更久，但它不能取代未通过的成功率主检验。

Seed 200 的小规模记忆干预（30 episodes）显示：正确事件记忆 46.7%，全零记忆 40.0%，跨 batch 错配记忆 10.0%。这支持策略在使用轨迹相关记忆，但样本小且只覆盖一个 Seed，属于诊断性证据。

### 已筛选掉的创新组件

LongSquare proxy 的低成本筛选中，预测惊讶写入、Evidence–Belief token 拆分、反事实 margin loss 都没有正结果；当前唯一值得继续的是 delta 事件选择写入。它们不得被表述为已验证有效的组合模块。

### 论文配置一致性风险

论文 Table I 使用 8-layer diffusion 和 2-layer compressor；发布版及多数已保存 Robomimic checkpoint 存在 4-layer diffusion 或配置漂移。故本机 Robomimic 数字不可与论文主表做严格横向比较，也不能用来证明论文主配置已复现。

此外，训练 sampler 会将历史截断到 `maximum_memory_length`（默认 16 个分段），因此“任意长度完整历史”强于当前训练代码实际支持的范围。

## 服务器核查说明

仓库中的远端脚本与预注册记录显示：MIKASA 4 个任务和 MoMaRT 10 个配置的 PER Seed-100 跨基准筛选曾被安排，且评测协议已冻结。但截至本总结，工作区未同步这些远端运行产生的 `result.npy`、逐 episode 明细或完成标记；本次尝试连接 `bhr-server` 也因主机名解析失败而无法取得实时状态。

所以服务器部分的准确表述只能是：**已有队列/脚本与计划证据，尚无本地可审计的完成结果证据。** 在同步服务器产物或恢复连通性之前，不能将其计为完成。

## 现在可以与不可以对外表述的内容

可以：

- VPWEM 以有界 observation cache 和逐层 summary cache 将历史压缩为固定数量 memory tokens，并与近期观测共同条件化扩散动作模型。
- 本机 4-layer VPWEM 变体已得到上述 Robomimic 三 Seed 结果。
- PER-delta 在 Transport/mh 上观察到 +2.89 pp 的平均成功率趋势，并有更高的累计 reward。
- 记忆干预提供了策略使用样本匹配记忆的初步证据。

不可以：

- PER-VPWEM 已显著、稳定或普遍优于 FIFO VPWEM。
- 已完成 MIKASA、MoMaRT 或 MaIL-VPWEM 的完整复现。
- 当前发布配置可直接复现原论文所有数字。
- LongSquare 已被复现。
- 预测误差、hybrid、Evidence token、反事实损失等已被正式验证有效。

## 下一步（按优先级）

1. 恢复服务器连通性并同步每个 MIKASA/MoMaRT run 的配置、checkpoint、逐 episode result、日志和完成标记；先判定 Seed-100 筛选到底完成了多少。

4. 将 PER 的冻结候选扩展至至少第二个 memory-intensive 任务，并采用独立公共评测集、至少 5 个训练 Seed；同时把 none/zero/shuffle 记忆干预纳入同一正式矩阵。
