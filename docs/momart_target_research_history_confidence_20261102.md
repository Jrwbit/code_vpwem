# 单目标条件：自身历史信息与监督置信度实验

目标保持active。本轮完成24个历史信息模型拟合及9个监督置信度模型拟合；两类实验均保留原监督、数据划分和完整评估分母。原可用性模型继续作为跨实验冻结结果，第五组未评分。

## 公开且因果的机器人历史

从既有74条已查看episode的5494个唯一物理帧提取6维双指信息及31维动作历史。机器人状态格式只保存关节位置，没有关节速度；本轮使用位置变化，不冒充实测速度。机器人自身双指为记录状态从0计数的列465、466；依据既有机器人布局验证，并在全部episode重新比对head关节与proprio，最大RMSE约0.001647弧度。未读取场景物体位姿作为模型特征。

双指6维：当前左右指位置、与t-8位置之差、平均绝对开度、实际历史步数/8。动作31维：严格在t之前、最多8条已执行10维命令的末条/均值/标准差及历史长度；使用actions[max(0,t-8):t]，不含当前或未来示范命令。部署时必须改用策略实际执行的历史命令，不能沿用示范命令；因果可获取不代表闭环分布一致。

固定均匀64帧从原始HDF自己的关节列及历史命令重新计算，结果与归档数组完全一致。归档SHA-256：a44fa6d7ffea4c660e3055dc04924dd398260f9e4e383c90da6fac322b010eb3。

## 载体冲突的训练置信度

使用全量物理审计中既定的冲突标记，统一映射所有训练/开发帧。训练1519个明确标签中14帧待复核（取碗4、持碗10），开发421帧中7帧待复核。审计标记仅用于训练置信度和旁路分组，不进入推理特征；不能由冲突直接断言应改成Rack或操作者真实意图。

只对14个训练帧比较原权重、0.5倍、0.25倍；不允许0权重，不删帧、不改目标；开发权重和标签完全不变。固定geometry MLP64、种子100/200/300，共9次拟合；每个比较原空槽和+4偏置，加控制共19条记录。

## 跨实验冻结与后续

使用此前登记的select_final规则：先满足V4，再最大正确框召回，再比较原始取碗错类；不在看到单帧差异后追加精度破平规则。汇总六个相同开发集V4搜索共573条记录（155+192+126+32+49+19），仍选geometry_v4_bias4.0。历史累计1047条比较记录含配置、种子、重复控制，不是1047种算法。

第五组16条episode/1345待对齐帧的manifest在搜索前冻结。新冻结结果保存在frozen_for_confirm5；未渲染对齐或评分该组，所有16条仍只能称源非valid的选择器未见轨迹。本轮没有新确认集性能结论。

这两项消融表明：单加自身状态或历史命令，以及降低少量弱标签权重，都没有增加正确框数。下一步转向候选实例的因果时序关联，以及动作策略自身的目标/计划查询；不继续用硬类别过滤放大阶段错误。若用真实未来动作做上限对照，必须与策略自己预测的计划严格分开，不能把前者当部署输入。四源范围、真实意图监督与动作策略闭环收益仍未完成。
