## 1. 结论先行

结构图见：`docs/VPWEM与PER结构图说明_2026-09-07.md`。

### 1.1 严格结论

截至本次盘点，**没有一条修改方案已经证明能跨任务、跨训练 seed、统计稳定地提高 VPWEM 的成功率**。

有若干局部正向结果，但都至少存在一项限制：主检验不显著、只跑了一个训练 seed、基线接近机会水平、比较中混入了表示差异，或没有超过 random/unmatched 强控制。因此，对外最准确的说法是：

- **已确认的稳定成功率涨点：无。**
- **最可信的正向趋势：PER-delta 在 Transport/mh 上成功率 `+2.89pp`，累计 reward `+1.727`；但成功率 `p=0.203`，95% CI 跨 0。**
- **最大的表面涨点：Random retention 三 seed pooled `+13.3pp`；但后续拆分证明主要混入 raw/Q-Former 表示差异，不能归因于随机保留。**
- **NCM 的最好局部点：ShellGameTouch Transfer-100 中 Matched-CF 相对 VPWEM `+6pp Success / +9pp BranchAcc`；但与 Unmatched-CF 完全相同，缺少方法特异性。**
- **六类 memory 迁移的最好点：RememberColor5 上 GMP `+4pp`；只有 1 个训练 seed，VPWEM 基线仅 9%，配对检验不显著。**
- **最可靠的新发现不是性能涨点，而是机制结论：ShellGameTouch 上正确与错误 memory 会造成很大的决策和成功率差异，证明策略确实会使用 memory。**

### 1.2 “涨点”分级

| 等级 | 含义 | 当前实验 |
| --- | --- | --- |
| A：稳定涨点 | 多训练 seed、严格同协议、主指标显著、跨任务或至少强复验成立 | **无** |
| B：可信趋势 | 严格配对、多训练 seed，但主检验未显著 | PER-delta / Transport-mh `+2.89pp` |
| C：筛选正信号 | 单 seed、小样本、低基线或未超过强控制 | NCM Transfer-100；GMP/Chameleon/AEM/VQ/Cycle；个别 PER 跨任务点 |
| D：已被复验否定 | 初看上涨，严格拆分或跨任务后消失/转负 | Random/Reservoir retention；PER 跨 benchmark |
| E：协议或诊断变化 | 数字变化来自 evaluator、episode length、action chunk 等，不是方法涨点 | RememberColor3 chunk/60-step；LongSquare evaluator 诊断 |

## 2. 原始 VPWEM 基线：复现到了什么程度

VPWEM 的共同底座是：保留最近观测作为 working memory，把更早的单回合历史经过带时间位置编码的 Q-Former 压缩为固定数量 episodic tokens，再与近期观测共同条件化 diffusion action model。主设置通常为 2 个近期 token、2 个 memory token、容量 8。

| 任务 | 论文 DP-VPWEM | 当前复现 | 判断 |

## 3. 在 VPWEM 基础上做过哪些修改，结果如何

### 3.1 PER-delta：事件选择记忆

**改了什么**

- 原 VPWEM：历史按时间进入容量 8 的 FIFO bank，满后淘汰最老槽位。
- PER：用相邻 embedding 的 `1-cosine_similarity` 作为事件分数；保留 episode 起点 anchor；相似事件更新；容量满后替换低分事件；最长等待间隔保证写入。
- 输出 token 预算不变：bank 之后仍由原 Q-Former 压成 2 个 memory tokens。
- 正式版没有启用 Evidence token、predictive auxiliary 或 counterfactual loss；它们只做过低成本筛选。

**主结果**

| 数据块 | FIFO VPWEM | PER | 差值 | 结论 |
| --- | ---: | ---: | ---: | --- |
| Transport/mh，3 train seeds × 300 paired episodes | 39.67% | 42.56% | **+2.89pp** | 正向趋势；p=0.203，95% CI `[-1.33,+7.11]pp` |
| 同上累计 reward | 7.191 | 8.918 | **+1.727** | 次指标 CI `[+0.821,+2.628]`，稳定为正 |
| MIKASA 3 任务宏平均 | 37.67% | 36.33% | -1.33pp | 不涨；Shell 退化 12pp |
| MoMaRT 9 个完整配对任务宏平均 | 62.33% | 62.44% | +0.11pp | 实质持平 |
| 跨 benchmark 12 任务 pooled | 56.17% | 55.92% | -0.25pp | p=0.916，无整体收益 |

**局部正点与负点**

| Benchmark / 任务 | PER−FIFO | 判断 |
| --- | ---: | --- |
| MIKASA RememberColor3 | +6pp | 失败基线 6%，不足以说明方法有效 |
| MIKASA RememberColor5 | +2pp | 小幅正向 |
| MIKASA ShellGameTouch | **-12pp** | 明确负结果，p=0.0018 |
| MoMaRT cleanup→sink / suboptimal | +9pp | 单任务正信号，p=0.176 |
| MoMaRT setup←dishwasher / suboptimal | +4pp | 小幅正向 |
| MoMaRT setup←dresser / suboptimal | +1pp | 持平 |
| MoMaRT unload→dresser / suboptimal | **+12pp** | 最大局部正点，p=0.096，未显著 |
| 其余 MoMaRT 完整项 | -1/-5/-4/-6/-9pp | 正负高度异质 |

**最终判断：B/D。** Transport/mh 有可信趋势，但跨 benchmark 不成立；PER 不能作为稳定涨点主贡献，可作为负结果/消融和后续 query-conditioned retention 的出发点。

### 3.2 Random / Recent / Reservoir / Anchor-Recent

**改了什么**

- Random retention：固定容量下随机淘汰或抽样历史。
- Recent-2 raw：不使用 Q-Former，直接保留最近 2 个 raw embeddings。
- Reservoir-2 raw：同样输出 2 个 raw embeddings，但用无偏 reservoir sampling 扩大长历史覆盖。
- Anchor-Recent：保留 episode 首帧和最近帧。

**结果演化**

| 比较 | 结果 | 正确解释 |
| --- | --- | --- |
| 最初 Random vs FIFO，Transport/mh 3 seeds | 51.0% vs 37.7%，**+13.3pp** | 混入 raw/Q-Former 表示差异，不能归因 retention |
| Q-Former random-evict bank8 vs FIFO bank8 | 38% vs 38%，0pp | 只改淘汰规则没有提升 |
| Reservoir-2 raw vs Recent-2 raw | 51% vs 46%，+5pp | 单任务小信号 |
| 严格跨任务：LongSquare/ph | 0% vs 0%，0pp | 无收益 |
| 严格跨任务：Square/mh | 72% vs 71%，+1pp | 持平 |
| 严格跨任务：Transport/ph | 82% vs 84%，-2pp | 负向 |

**最终判断：D。** “长历史覆盖本身可以稳定涨点”被严格跨任务复验否定。

### 3.3 Learned retention

**改了什么**

- 为每个历史槽计算 `[embedding, temporal delta, cosine delta, age]` 特征。
- 用离线 leave-one-out action-denoising loss 训练 retention head，预测未来动作影响度。
- 固定容量选高分事件，再交给 Q-Former 压缩；保留起点 anchor。

| 方法（Transport/mh，seed100，10k adaptation，100 ep） | Success | 相对 FIFO |
| --- | ---: | ---: |
| FIFO Q-Former | 38% | 0 |
| delta-PER | 35% | -3pp |
| Learned retention | 39% | +1pp |
| Random retention | 51% | +13pp（后证实有混杂） |

Oracle 离线可保留 99.56% 的未来动作重要度，learned retention 为 80.43%，但 learned head 与标签验证相关系数仅约 0.035，在线成功率也只 `+1pp`。

**最终判断：C/D。** 离线排序能力没有转化为在线控制涨点，停止扩 seed。

### 3.4 NCM / Counterfactual memory supervision

**改了什么**

- 构建固定、可审计的 counterfactual pair manifest。
- 在保持当前观测和动作样本不变时，替换 memory donor；比较 random、matched、unmatched-branch 三类负样本。
- 在 diffusion loss 上加入 correct/wrong memory ranking loss，另试验 donor-action objective。
- 新增 correct、zero、random、matched-wrong 等在线 memory intervention，并记录 BranchAcc、wrong attraction、首次动作方向和离线 ΔCF。
- 为 ShellGameTouch/RememberColor 重新实现真实执行前 10 步 neutral hold 的评测协议。

**结果**

| 设置 | VPWEM | Matched-CF | 表面变化 | 强控制比较 | 判断 |
| --- | ---: | ---: | ---: | --- | --- |
| Shell Stage-1 初始 10k | 17% / Branch 39% | 13% / 30% | -4/-9pp | 不如 random/unmatched | NO-GO |
| Shell Transfer-100 20k | 56% / 65% | 62% / 74% | **+6/+9pp** | 与 Unmatched-CF 62%/74% 相同；Random 61%/72% | NO-GO，缺特异性 |
| Shell Full-base-600 20k | 46% / 59% | 46% / 65% | 0/+6pp | 不优于 unmatched Branch 67% | NO-GO |
| Shell donor-action 20k | 56% / 65% | 57% / 66% | +1/+1pp | 基本持平 | NO-GO |
| RememberColor5 Transfer-100 | 18% / 24% | 15% / 23% | -3/-1pp | 基础策略接近机会水平 | NO-GO |

机制上，Shell Transfer-100 的 VPWEM correct success 为 56%，matched-wrong 仅 11%，产生 45pp gap；物理 scratch 强模型 correct 可达 97%–98%，matched-wrong 约 3%。这证明 memory 会因果改变动作，但不证明当前 Matched-CF 训练优于普通适配或其他负样本控制。

**最终判断：C。** 问题定义和因果评测有价值，当前训练方法没有成立。

### 3.5 六类 memory 机制迁移

共同协议：以 VPWEM-DP 为底座；RememberColor5；同一个 400k base checkpoint；seed100；5k adaptation；正确 physical hold；同一组 100 episodes。

| 方法 | 相对 VPWEM 改动 | Success | 相对 VPWEM | BranchAcc | 判断 |
| --- | --- | ---: | ---: | ---: | --- |
| VPWEM | 原 Q-Former/context read | 9% | 0 | 14% | 基线 |
| GMP | 对 memory read 加 learned gate | **13%** | **+4pp** | 17% | 当前最好筛选点，p=0.125 |
| Chameleon | control-indexed/action-relevant memory read | 12% | +3pp | 16% | 小正信号 |
| AEM | 动作历史条件的 recurrent memory；预测 action effect 辅助损失 | 11% | +2pp | **18%** | Branch +4pp |
| VQ-Memory | recurrent state 离散量化；codebook/commitment loss | 11% | +2pp | **18%** | Branch +4pp |
| Cycle | recurrent history state；训练时预测 episode progress | 10% | +1pp | 15% | 基本持平 |
| DSSP | recurrent/SSM 风格历史状态；预测未来 embedding | 8% | -1pp | 15% | 负向 |

所有与 VPWEM 的配对 McNemar 检验均未显著；而且 9% 基线低于五分类机会水平附近，`+1pp`–`+4pp` 不能视为成立的性能贡献。

**最终判断：C。** GMP 是下一轮候选，不是已确认涨点。

### 3.6 评测协议、action chunk 与失败诊断

| 实验 | 数字变化 | 含义 |
| --- | --- | --- |
| RememberColor3 默认 evaluator | 1/30 = 3.33% | episode/action 执行协议有问题 |
| 固定 60-step，chunk 1/2/4 | 6/30 = 20% | 协议修正后表面分数上升 |
| 固定 60-step，chunk 3 | 4/30 = 13.33% | chunk 会显著影响结果 |
| LongSquare paper-strict 8-layer | 7/30 = 23.33% | 单次诊断评测 |
| LongSquare 本地 4-layer 变体 | 5/30 = 16.67% | 与上项模型/协议不同，不是公平涨点 |

这些实验用于解释失败和冻结 evaluator，**不属于相对 VPWEM 的方法改进**。早期没有执行真实 neutral hold 的 30 回合 paper-transfer/NCM 结果已经作废，不应引用。

## 7. 当前最值得保留的论文叙事

可以可靠表述：

1. VPWEM 的固定容量 Q-Former memory 调用链真实存在，并能在部分 MIKASA、MoMaRT、Robomimic 任务上工作。
2. ShellGameTouch 的干预结果证明 memory 内容会因果改变动作与成功率；这比单纯比较平均 success 更强。
3. 仅依据视觉变化、随机覆盖或离线重要度排序来管理 memory，不能稳定转化为在线控制收益。
4. Counterfactual supervision 的问题方向有价值，但当前 matched 方案没有超过 random/unmatched 控制。
5. GMP 是六类迁移中最值得在强基线任务上复验的候选，但现在不能声称有效。

暂时不能表述：

- “某个新 memory 方案已稳定显著优于 VPWEM”；
- “Random retention 提升 13.3pp”而不说明表示混杂；
- “NCM 提升 6pp”而不说明它与 unmatched 控制相同；
- “GMP 提升 4pp”而不说明单 seed、低基线和不显著；
- 已严格复现 RememberColor3、LongSquare、MaIL-VPWEM 或 Real-Zarr 实机结果。

## 8. 建议下一步

1. 不再扩纯 retention 方案；它们已经有充分负结果。
2. 把主战场从 RememberColor5 移回 ShellGameTouch：先用 97%–98% 的强 VPWEM base，避免 motor/base-learning 瓶颈掩盖 memory 效应。
3. 下一轮只保留 `VPWEM + GMP/action-relevant read` 与 NCM 问题设定，并固定 VPWEM、Random-CF、Unmatched-CF 三个强控制。
4. 单 seed 筛选至少达到 `+8pp`–`+10pp`，且超过全部强控制，再扩到 3–5 个训练 seed；否则及时停止。
5. 每轮固化 commit/diff hash、Hydra config、checkpoint SHA256、公共 episode 列表和逐 episode JSON，避免再次出现配置/评测口径漂移。
