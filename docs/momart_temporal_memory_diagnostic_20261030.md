# MoMaRT 检测器在线可用性的时序与 Memory 诊断

2026-10-30。按用户提出的 First-hit、Miss Streak、Critical-window Recall、Memory 新鲜度与身份关联标准，完成真实 RGB / ROI 特征回放。使用物理卡4标注、卡1只读检测推理，不执行机械臂动作，不修改旧红碗主视觉路径，不启动策略训练。延续 [第二轮检测报告](https://feishu.cn/docx/IQaxdP91gojjrlxSCIIcJmcdn3d)。

## 结论与对旧判据的更正

六类逐帧 Precision 全部达到95%，不再作为允许只读在线集成、时序回放和 Memory 诊断的前置条件。此前“暂不放行A1”的表述应细分：级别一诊断可以推进，本轮已完成；级别二需要对象输入一致性、关键窗口、身份和完整控制时延证据；级别三正式替换仍没有依据。

本轮时序小样本中 Mask 明显优于 YOLO640，值得优先继续做集成诊断。不能仅用旧的全场景 Precision 排序决定在线候选。然而 IoU-only 实例关联已经出现身份切换、碎片化和关键目标关联槽位淘汰；完整 DP 的端到端时延未测，因此本轮不自动启动250k策略训练。暂停依据是这些具体缺口，而非单一的六类95%规则。

## 数据、物理时刻与代理窗口

完整回放两条此前保留测试轨迹：table_setup_from_dresser_expert/demo_18（593帧）和 unload_dishwasher_to_dresser_suboptimal/demo_56（852帧），共1445帧。它们与第二轮32帧确认集来自同两个episode，不是新增独立测试episode。没有用本轮测试重新训练模型、选checkpoint或调阈值。冻结使用第二轮补标后的YOLO640、Mask权重及原dev选择的阈值。

核实服务器实际 EnvGibsonMOMART 包装器 action_timestep=1/20秒，当前配置没有覆盖：每物理帧0.05秒，执行8步为0.4秒。策略读取时刻0、8、16…；每次仅使用最近两帧[0,0]、[7,8]、[15,16]…，reset帧只更新一次。稠密1445帧结果与策略实际可见帧分别统计，不能把每帧检测结果灌入策略Memory。

数据没有人工子任务边界。本轮从记录状态的抽屉/门关节运动生成7个代理事件：抽屉逐帧变化>=0.5mm、门>=0.002rad，间隔不超过4帧合并；区间运动范围至少1cm或0.03rad。关节GT只用于离线评分，完全不进入检测器、ROI或Memory。运动可能来自碰撞、抖动或反向调整，事件不等于真实操作意图；没有运动的失败抓取也不会被覆盖。只作为诊断代理，不能替代人工关键阶段标注。

First-hit窗口为运动开始前16帧（0.8秒，两次动作块）；关键窗口为开始前后各8帧（各0.4秒）。这些是依据当前控制节奏固定的首轮窗口，不是已证明最优的容忍范围。First-hit必须命中指定GT实例，检测到同类另一个把手不算成功。7个事件的前窗口均存在可见机会，统计同时保留可观测分母。事件之间及相邻帧不独立，不报告总体可靠性的显著性保证。

所有1445帧通过原RGB对齐检查；沿用之前的CAD可见像素参考。抽样复核7个事件附近35帧，未做1445帧独立人工逐像素标注。

## Memory 状态与空间含义

生产bank按冻结检测+类别IoU匹配更新，GT在更新后才用于评分，不参与关联。特征来自归档500k EMA主RGB ResNet18的冻结layer2：原始未画框90x120 RGB、[-1,1]、stride8、ROIAlign 3x3/aligned/sampling2/均值128维。当前没有新增TTL或3D定位，诊断分别检查0.4/0.8/1.6秒的新鲜度。

| 语义 | 当前实现中的对应 | 限制 |
|---|---|---|
| seen | 保留槽位曾初始化；A2/A3的valid | A1故意屏蔽不可见历史，A1 valid不能解释为曾见过 |
| visible | 当前物理采样检测通过阈值 | 不是真实可见性分类器，画面内漏检也会为0 |
| box_valid | 当前visible且槽位有效 | 离屏/漏检框立即归零，不沿用旧2D位置 |
| age | 距最近有效检测的物理秒数 | 不是距最近真实正确检测的时间，错误检测也会更新age |
| 可读性 | 当前arm的valid和注意力mask | 旧外观可读不代表有有效当前位置 |

A2/A3离屏后保留外观，当前box始终无效；不会把上一次2D框当成相机移动后的当前位置。历史特征目前可一直保留至reset/淘汰，没有硬TTL；不能据此声称任意长时间都可靠。TTL扫描仅统计保留轨迹的最新观测确实匹配指定GT且足够新，不是A1/A2/A3策略成功率，也不把早期正确、最新已错误的轨迹算作正确。

## 关联、容量与新鲜度

身份切换：同一保留轨迹先后正确匹配不同GT实例的次数。碎片化：同一GT实例被新的轨迹接续的次数。是诊断计数，不是标准IDF1或归一化错误率；GT只辅助评分。保留更多槽位不会自动解决错误关联。

| 模型/槽位 | 身份切换 | 碎片化 | 槽位淘汰 | 未来0.8秒代理目标关联槽位淘汰 | 关键读取时刻最新正确且age<=0.4秒 |
|---|---|---|---|---|---|
| yolo/8 | 27 | 151 | 167 | 1 | 4/14 |
| yolo/16 | 31 | 148 | 140 | 0 | 4/14 |
| mask/8 | 30 | 251 | 314 | 5 | 13/14 |
| mask/16 | 41 | 255 | 299 | 2 | 14/14 |

关键目标关联槽位淘汰不等于整个目标完全丢失：可能另有重复轨迹，或稍后重新检测成功。Mask在16槽的14次关键读取均有最新正确且不超过0.4秒的观测，但同样有41次身份切换，因此不能据14/14就宣称Memory身份可靠。YOLO放宽新鲜度至1.6秒也仅6/14次；延长TTL不能凭空初始化从未发现的目标。

位置稳定性采用连续物理帧正确匹配同一GT时，预测框中心误差的变化（像素）。已减去GT中心变化，避免将相机/物体运动直接记为抖动；仍受GT可见mask边界变化影响，不能解释成静止世界坐标误差。原始残差分位数保存在结果JSON。

## ROI缓存、Token一致性与时延

每个模型使用真实检测和真实冻结ROI特征，调用生产write_cache，回放所有训练相位；再将phase0与在线ObservationStream逐query对比。8/16槽各有182个query，对A1/A2/A3逐项比较8个对象数组：每个模型、每个容量4368项完全一致，546次Token编码完全一致；两模型两容量共2184次Token比较通过。Token编码器固定seed100、未训练，仅证明输入与计算一致性，没有证明学会目标切换。生产bank检查到的所有不可见框均为0。

未把模拟器GT或关节事件传给检测器、ROI、bank或Token。未比较原图重新在线推理与离线独立GPU运行的逐比特浮点结果；这里验证的是同一冻结前端输出经离线缓存与在线因果流的一致性。

## 统计解释与后续准入

32TP/1FP的precision点估计为96.97%。假定33个预测独立时，Wilson双侧95%区间为[84.68%,99.46%]。实际相邻帧相关，不能将此当作episode级保证。两条轨迹、七个运动事件同样不能提供稳定任务成功率估计。

级别一：真实冻结前端只读推理、完整轨迹回放、时序和Memory诊断已完成。级别二：已补上真实特征的缓存/Token一致性证据；仍需更稳的实例关联、人工或经验证的关键阶段窗口、独立episode复核和完整DP时延。可在明确限定范围下安排策略小样本对照，但不把本轮诊断写成已满足全部准入。级别三：未达到正式替换要求，缺少下游策略任务成功率。
