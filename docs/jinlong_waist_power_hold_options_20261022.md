# 腰部下电后不锁止：保持方案与现有软件边界

日期：2026-10-22。用户补充：“腰部没有下电锁死，所以会自己转”。本轮据此讨论保持方案，并只读核对源码和官方SDK；未操作真机、未改变控制或急停逻辑。用户说明确认了现场关注的下电失去保持现象，尚不能据此区分未配置抱闸、抱闸未闭合或保持能力不足。

## 结论

**正常作业期间可评估用伺服持续上电保持腰姿；真正断电后仍要保持位置，必须有可靠的机械保持措施。** 两者解决的条件不同，不能把“上电保持”称为“下电锁死”。

| 目标 | 对应办法 | 本项目边界 |
|---|---|---|
| 检测与短暂停顿期间腰部不转 | 腰部停止运动后保持位置伺服上电，由控制器闭环保持；持续检查姿态、电源和故障 | 现有示教会话已有类似能力，自动检测尚未接入 |
| 正常关机后不转 | 核实并恢复原厂抱闸；若设计确无可靠失电保持，采用厂家评估的失电制动器、机械锁止或承托 | 软件下电后不能继续提供电机保持力矩；需要机械／电控方案 |
| 急停、故障或断电后防止运动 | 厂家安全回路与独立机械保持措施共同确定失效状态 | 普通应用进程、网页心跳或UPS不能独立保证这一点 |

推荐近期方向：先与厂家确认本体允许的持续伺服保持方式、负载与温升条件，同时把正常作业从“每段退出即下电”改为“一次受监护的腰部保持会话覆盖整次检测”。断电保持问题仍单独闭环，不因为正常运行暂时稳定就关闭。

## 当前程序到底做了什么

1. `native/xcore_motion.cpp::shutdown()`依次执行stop、等待idle、moveReset、power_off、确认off、切Idle控制模式及manual。正常动作收尾会主动撤去伺服电源；接口成功不等于机械锁已闭合。
2. `motion.py::enable_waist_power()`和`native/xcore_motion.cpp::waist_button_session()`已实现腰部在当前姿态上电保持，供示教／拖动使用，持续核对关节、电源、错误和心跳。暂停拖动时腰部继续保持；会话最长900秒。
3. 该会话占用HMI执行所有权。现有自动左臂路线又要求非运动部件off/manual/idle，因此**不能先打开现有腰部保持按钮，再直接启动完整检测**；会被所有权及状态守卫拒绝。
4. 现有保持会话的结束、停止、失联或超时会进入清理并给腰部下电。`safe_exit_confirmed`表示现有退出状态判据通过，不证明抱闸长期锁住。

源码根目录：`/home/wjr/code/jinlong-motor-arm-control/arm_control/helios_hmi/`；核对版本`829b9f7c9d18c7b1e6af5d1e7047d50ff8fdfa32`。相关入口为`motion.py`、`plan_runner.py`及`native/xcore_motion.cpp`。

珞石官方SDK把`stop()`定义为暂停运动，把`setPowerState(false)`定义为下电，两者是独立操作；这支持区分“停止”和“断电”，但通用API说明不能替代这台TaiHu本体的持矩与制动能力确认。本次查阅的通用接口表未列出独立强制闭合抱闸接口，不能据此断言厂家定制控制器没有相关能力。[官方API](https://docs.rokae.com/en/docs/SDK/cpp/cpp_API/)、[方法说明](https://docs.rokae.com/en/docs/SDK/cpp/cpp_method/)。

## 自动检测应怎样接入

建议增加一个由HMI单一所有者管理的“腰部保持＋左臂检测”会话，而不是让两个进程分别控制：

```text
确认本体可在当前负载保持／故障已处理
→ 腰部到工作姿态并停稳
→ 腰部继续伺服保持，记录实际腰姿
→ 左臂接近、检测停留、撤离、返回
→ 正常短暂停顿仍保持腰部，监护继续
→ 整次作业结束，在经验证的停放／机械支撑条件下正常下电
```

- 将现有自动路线的被动腰部检查改为该会话内的“上电、位置保持、反馈新鲜”检查，其他非参与部件仍保持既定策略。
- 让正常暂停、结束并下电、急停／故障分别有明确状态；上电保持不能被标为已经安全下电。
- 腰部偏移、失去伺服、电源变化或反馈异常时，先停止左臂动作、保留故障证据，交由经验证的故障策略处理；不得自动反复清警重新上电追位置。
- 进程崩溃、通信丢失、急停和供电中断的结果必须由厂家控制器安全功能与机械保持措施覆盖，不能靠删除`power_off`或无限延长网页会话解决。

这些是建议的实现边界，本轮没有改动生产程序。腰部保持即使成功，也不直接解决100／160的末端净空问题，仍需按上一版总报告分别验证。

## 断电保持应向厂家确认的具体事项

先核对J4是否配置制动器、是否允许在当前负载／姿态可靠保持，以及使能撤去与抱闸闭合的时序。如果原设计有制动器，应查闭合命令／实际反馈、保持力矩与传动情况并恢复其能力；如果原设计不提供失电保持，评估与关节匹配的失电制动器或机械锁止／承托。配重或平衡只能减小驱动力矩，不能单独视为可靠锁止。

不用凭空指定电磁铁电压、制动力矩、安装位置或延时，也不把某个角度叫作天然安全位。需要依据本体图纸、重力负载和厂家允许条件确定。

验收应分别记录正常保持、正常结束、故障停止与断电四种条件：实际腰角是否稳定、保持期间温升／负载是否合格、失去驱动力后的机械运动是否受控。全部通过前，不把“程序停止”或“短时间没有动”写成“下电锁死已解决”。
