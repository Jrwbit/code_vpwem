# 2026-10-28 新标定下如何确定三型号共用工作腰姿

已得到一组新标定下的**离线共用腰姿候选**：模型角 `[-30,20,10,-80]°`。本轮不仅检查终点，还重新生成并验证了160、132、100从同一个等待位接近、撤离和返回的非接触路线。此结果推进了上一轮“仅终点通过”的结论，但尚未证明现场完整插接和电测可行。

## 怎样得到现场可用腰姿

手眼标定给出相机与机器人之间的坐标关系，不单独决定哪组腰角适合三型号。需要将以下条件一起求解：新活动标定、三型号在同一个固定底座上的实测盒位、真实工装、右臂停放位置、同一个工作腰姿及共同等待位、完整接近／撤离路线。循环中保持工作腰姿，换型不移动底座或垫高。

现场依次进行：

1. 相机和底座保持固定，160、132、100依次按正常方向就位，各保存一组新RGB-D、型号、采集时间、同步实际腰姿及标定SHA。保留原始相机坐标，不拿旧基座坐标直接复用。
2. 核对三型盒口、端子及实际二维码的可见性和深度，确认接线盒与整机／台面的真实关系。将新实测位置替换本轮设计位置，明确右臂和标定板在生产时的停放状态。
3. 优先复核本轮共腰候选；若任一型号失败，联合搜索另一组共同腰姿和共同等待位，三型号全部通过才保留。不能为每型分别改变腰姿来代替共用解。
4. 检查从实机当前位置进入工作腰姿的路径及退出路径，再按现场确认进行低速非接触验证。腰部J4失电不保持，自动过程需要受监控的持续持腰，不能把下电姿态当固定基座。
5. 在独立实物精度通过后验证轻触、补偿压入及电测握手／结果记录，完成连续三型号流程验收后才称“可用于三型号检测”。

用户已确认三种实物齐全、可以依次放到同一底座采集；本轮已请求先放160。随后用户确认先采132且已放好。采集前实时检查右臂为上电／拖动模式且姿态已变化，腰J4也与先前归档不同；正在等待用户退出拖动并下电。完整候选采用的是先前归档静态姿态，实际新姿态需另行复核。现场任务接口返回的最近已完成任务仍为10月22日160，预览亦为该缓存，不计入本次采样。

## 本轮离线验证结果

活动标定SHA `76d7613ccb761512b1609e86e53b7269cac3b2cce97c971d6a82c70c2331bd41`，相机固定在新标定世界位姿，不额外升高。沿用研究共同底脚定位 `[375,0,500]mm`，真实−90°工装和分型号扫描碰撞几何；右臂／头部采用上一轮采集的实际反馈。三型号整机底脚至盒体平移仍是待实物配准的设计关系。

求解耗时95.147秒；原设计等待位和历史折臂等待位的部分连接在有限搜索中未通过，随后采用160局部等待位作为新的共同等待位，三型全部连接通过。最终路线使用0.25°关节插值、普通8mm及局部3mm净空策略，保留模型碰撞掩码和全部障碍。

共同等待位左臂模型角（rad）：`[-1.7519411324,-1.1844066016,0.2028458238,1.5348694908,-2.9344423782,-0.2947644871,1.4268112147]`。这些数据仅用于复现离线研究，不是直接下发给示教器的动作指令；特别是腰J2模型角与控制器角相差90°，还需验证从当前实机姿态进入的路线。
