# 检测终点无法独立复位：规则差异核对（2026-10-19 22:11）

用户质疑“检测到达的位置不能生成复位路线，是否意味着该位置不可达或执行错误”。本轮只读检查现场状态、失败任务和原完整计划，并在工控机独立规划环境运行离线模型校验；没有发上电、运动、清警、加载计划或修改保护参数。

## 现场与失败来源

当前全身下电／手动／空闲，busy=false、latched=false；左臂仍接近原检测终点。复位任务`5d42c6d8d48a491e8ec5a54f964023ca`失败，原错误为“连不上（0个中间点从起点可达，2个可到终点）”。前两次复位求解有同类记录。

失败调用链为`detection_initial_segments()` → `fewest_connect(current, home)`。该函数默认`adjust=True`，使用普通区域和碰撞规则直接搜索收臂；没有识别当前处于检测对位区域，也没有先沿原插接路径撤离。

原完整路线`91774a0ad5d6402cbe4cda672a061c2e`仍保存在HMI，前6段完成，第7–10段撤离返回未执行。其第7段使用`role=insert/contact=True/motor=JL132`，第8段继续退出，随后经中转收臂。原检查调用`adjust=False、contact_motor=JL132`，使用既有插接区域配合件豁免；不是普通自由空间收臂规则。

## 判断与处理方向

“当前独立复位搜索失败”不等于“该姿态运动学不可达”，也不直接证明到达动作错误。已确认两套入口对检测终点采用不同规则：完整路线包含专门的退出步骤，独立复位尝试直接收臂，缺少对检测区域的撤离处理。

用户提出应沿原路线返回的方向成立。后续软件应在保留视觉、工具、现场场景与起点绑定检查的前提下，复用并重新校验原撤离段，再连接home；不能通过全局忽略碰撞、直接跳段或调大门限解决。当前检测侧任务已被新复位任务替换，不能直接把原暂停任务当作仍可续跑；需要显式的返回计划恢复与校验。本轮未实施这一功能，也未执行撤离。

本问题与此前约3 mm左右定位误差分别处理：复位入口规则差异不能解释或关闭实物定位偏差。
