# Robotiq Hand-E / FT 300-S 分体夹环相机支架

本目录包含两套非承力相机支架：

- `HandE`：夹在原装 Hand-E 金属耦合器（名义外径 75 mm）外部；
- `FT300S`：夹在原装 FT 300-S 金属耦合器（名义外径 89 mm）外部。

两套都保留原装金属耦合器直接贴合 UR5 法兰。打印件不应插入 UR5 法兰、
金属耦合器、FT 300-S 或 Hand-E 的承力接触面。

## 相机与紧固件

- D435：后部两颗 M3，45 mm 孔距；用 M3×8，旋入相机最多 3 mm。
- D455：后部两颗 M4，95 mm 孔距；用 M4×8，旋入相机最多 4 mm。
- 每个夹环：2 × M4×30 螺钉和 2 × M4 防松螺母。仅拧到夹环不滑动，
  不得压迫金属耦合器。

## 首件验证

用卡尺量实际黑色耦合器外径后再切片。当前内径分别为 75.8 mm 和 89.8 mm，
为 FDM 装配留出 0.4 mm 单边间隙。若你的实物比名义尺寸大，必须先修改脚本的
`DIAMETRAL_CLEARANCE` 或相应耦合器外径。

推荐 PA-CF、PETG 或 ABS，0.2 mm 层高、5 层壁、40% 以上填充。相机板朝下打印并
在悬空桥臂下加支撑。初次装机需低速运动并检查相机、USB 线和夹爪完整工作空间
没有碰撞。
