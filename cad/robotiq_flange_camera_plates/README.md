# UR5 × Robotiq 法兰相机板

两块圆盘式相机板均使用原装 Robotiq 金属耦合器和 UR5 的四颗 M6 螺钉固定：

```text
UR5 法兰 → Hand-E 圆盘板 → 原装 GRP-CPL-062 → Hand-E
UR5 法兰 → FT 300-S 圆盘板 → 原装 FTS-300-S-CPL-014 → FT 300-S
```

圆盘上的 4 × Ø6.8 孔位于 PCD 50，另有 Ø6.6 的定位销孔。相机侧板为 D435
（2 × Ø3.4、45 mm 中心距）与 D455（2 × Ø4.5、95 mm 中心距）共用。

## 重要安全要求

此设计会处在法兰与金属耦合器之间。FDM 的 STL 只能用于实物试装、相机视野和走线
验证；长期运行件应采用 3 mm 6061-T6 铝板 CNC/水切割后机加工孔位。原装 M6 螺钉
需增加 3 mm 长度，定位销也需要对应加长 3 mm，同时必须保持足够的定位销啮合深度。

不建议把 PETG、ABS、PA-CF 等打印件作为 Hand-E 或 FT 300-S 的法兰承力垫片。塑料
会随预紧力发生蠕变，影响螺钉预紧和 FT 300-S 的刚度/测量稳定性。

## 相机紧固件

- D435：M3×8，螺纹旋入相机最多 3 mm；
- D455：M4×8，螺纹旋入相机最多 4 mm。

相机背面朝向圆盘，光轴与 UR 工具 +Z 轴平行。安装后应重新标定 TCP；装有 FT 300-S
的配置还应在最终相机/板材装好后重新清零力传感器。
