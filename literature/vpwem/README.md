# VPWEM Literature

This directory contains the VPWEM paper, research workflow, related-paper
reports, conference indexes, deep readings, and their supporting assets.

## Entry points

- [`vpwem.pdf`](vpwem.pdf): original VPWEM paper.
- [`vpwem_research_workflow.md`](vpwem_research_workflow.md): research workflow.
- [`vpwem_related_papers.md`](vpwem_related_papers.md): related-paper overview.
- [`cross_domain_memory_transfer_to_vpwem.md`](cross_domain_memory_transfer_to_vpwem.md): cross-domain memory transfer analysis.
- [`vpwem_p0_2024_2026/deep_reading_and_ideas.md`](vpwem_p0_2024_2026/deep_reading_and_ideas.md): priority-paper deep reading and research ideas.

Conference and yearly source bundles remain in their own subdirectories so
their reports, metadata, PDFs, extracted text, and images stay together.
